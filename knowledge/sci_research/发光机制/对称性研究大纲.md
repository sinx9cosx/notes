# 研究内容

## 核心问题

为什么 TBR 的高激发态能够发生反 Kasha 发光？这种现象是否与分子对称性及振动耦合有关？

## 初步假设：

|研究方向|初步假设|想要回答的问题|
|---|---|---|
|对称性|TBR 的对称性可能有利于反 Kasha 发光|对称性是否影响不同电子态之间的跃迁和耦合？|
|振动耦合|TBR 的振动模式可能影响高激发态的辐射与非辐射跃迁|哪些振动模式参与了态间耦合？|

需要研究的是：

- 对称性如何影响电子态的性质？
    
- 对称性是否会限制某些跃迁？
    
- 对称性是否会影响内转换？
    
- 振动是否会破坏这些对称性限制？



# 研究路线

### 第一阶段：两个分子的结构和电子态性质


首先整理两个分子的基态结构。

|分析内容|TBR|TBRs|
|---|---|---|
|基态优化结构|已有/检查|已有/检查|
|分子点群|待确定|待确定|
|主要键长|整理|整理|
|关键二面角|整理|整理|
|平面性|分析|分析|
|激发态能级|整理|整理|
|NTO|已有部分结果|整理|
|振子强度|整理|整理|

<mark style="background: #FFB86CA6;">注意事项</mark>

第一，不能只看二维结构图判断点群。
需要使用实际优化得到的三维坐标，检查旋转轴、镜面、反演中心等。
可以使用 GaussView 查看结构，也可以使用专门的分子对称性分析程序。

第二，基态对称性和激发态结构对称性要分开考虑。
例如：

- S0 优化结构可能属于某个高对称点群。
    
- S9 优化之后可能发生结构畸变。
    
- S1 和 S9 的几何结构可能具有不同的对称性。
    

第三，检查激发态的对称性是否发生变化。
如果 TBR 的 S9 保持较高的对称性，而 TBRs 的对应激发态出现明显的对称性破缺，那么这个结果就值得进一步分析。

### 第二阶段：系统比较两个分子的电子态

建立一张电子态性质表。

| 性质          | TBR | TBRs |
| ----------- | --- | ---- |
| S1 能量       |     |      |
| S9 能量       |     |      |
| 发光态与 S1 的能隙 |     |      |
| 发光态振子强度     |     |      |
| NTO 局域/离域特征 |     |      |
| 电子-空穴分离程度   |     |      |

<mark style="background: #FFB86CA6;">注意两个问题：</mark>

1. 高激发态的振子强度是否足够大？
    
2. 高激发态与低激发态之间的电子性质是否存在明显差异？
    

进一步比较电子-空穴分布。
例如：

- 电子和空穴是否局域在不同的结构片段？
    
- 两个分子的电子-空穴空间分布是否不同？
    
- 对称性是否导致某些轨道组合具有不同的电子态性质？
    
这样就能把分子结构、电子态和发光性质联系起来。
