# 注意

1. 研究背景：简要介绍 TBR 的高激发态发光现象，以及 TBR 与 TBRs 的实验发光行为差异。实验光谱可以直接使用老师提供的图片，并注明“实验数据由课题组提供”。
    
2. 计算方法：介绍实际完成的基态结构优化、激发态计算、NTO 分析、发射光谱和跃迁速率计算等工作。
    
3. TBR 计算结果：重点展示计算得到的 S9 态相关结果，包括 NTO、发射光谱和辐射跃迁速率、内转换速率，并与老师提供的实验发射光谱进行对照。
    
4. TBRs 计算结果：展示计算得到的 S1、S9 等态的相关性质，与实验中主要观察到 S1 发光的现象对照。
    
5. 比较与讨论：结合计算结果，讨论两个分子的激发态性质和发光行为差异。注意区分已经得到计算支持的结论与尚待验证的机制假设。
    
6. 总结与展望：概括你的计算工作及主要发现，提出后续可以拓展其他分子、进一步研究反 Kasha 发光机制的方向。
    

还有两个细节值得注意：

- 你可以展示实验光谱，但不需要声称自己测量或处理了实验数据。 如果你只拿到了老师提供的图片，就把它作为实验对照图使用，不要从图片中提取过多精确数值，也不要将它称为自己获得的实验结果。
    
- 分子结构图也可以使用。 你发的图里有原始分子结构和简化后的结构，可以用来介绍研究对象。但如果简化结构只是为了突出分子的骨架，最好说明这是结构简化示意，而不是另一个实际计算模型。
    

汇报最适合采用的叙述主线是：实验上观察到了什么现象 → 通过哪些理论计算研究这一现象 → 计算结果为解释这一现象提供了哪些证据
