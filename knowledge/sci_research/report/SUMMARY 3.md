# DHR

DHR 分别计算了水相、气相和 THF 条件下的 S1/S2/S9 发射谱，三种条件下的结果都没有与文献 394 nm 的峰对应上，因此溶剂差异大概不是主要原因，可能还是计算方法的问题。

| 态   | 计算发射峰  | 文献发射峰  | 辐射速率 kr     | 内转换速率 kic    |
| --- | ------ | ------ | ----------- | ------------ |
| S1  | 648 nm | 658 nm | 4.3×10⁷ s⁻¹ | 1.3×10¹⁰ s⁻¹ |
| S2  |        | 394 nm | 4.1×10⁸ s⁻¹ | \            |
| S9  | 299 nm | 394 nm | 4.1×10⁸ s⁻¹ | \            |
