# 自然轨道跃迁NTO

## 物理意义

NTO的核心思想：将一个复杂的、由多个轨道跃迁组成的激发态，通过奇异值分解SVD，提取出少数几对特殊的轨道。
空穴与电子：在NTO图像中，电子激发被 描述为电子从空穴轨道跃迁到电子轨道。
本征值：NTO的本征值就是量化描述纯度的指标，本征值越大，代表这对NTO对激发态的贡献越大。

NTO计算提取数据的步骤：
1. 从跃迁密度矩阵出发：NTO的计算基于跃迁密度矩阵，这个矩阵描述了电子在基态和激发态之间如何重新分布。
2. 数学变换：Gaussian对这个矩阵进行奇异值分解SVD。
3. 得到NTO：SVD分解后，会得到两套新的正交轨道：一套代表空穴的占据NTO，一套代表电子的非占据NTO。而分解得到的奇异值的平方就是.log文件中看到的NTO的本征值。

| NTO的输出标签                | 物理意义 | 激发过程中的含义 |
| ----------------------- | ---- | -------- |
| alpha occ. eigenvalues  | 空穴轨道 | 电子离开的地方  |
| alpha virt. eigenvalues | 电子轨道 | 电子到达的地方  |
每一对占据值（空穴）和虚值（电子）的数值必须相等，这个数值是权重。最大的数字乘以100%就是这一对空穴->电子跃迁占整个激发态的百分比。

## 计算步骤

1. 进行TD-DFT激发态计算：首先需要用一个标准的TDDFT任务计算感兴趣的激发态并保存好.chk文件。
	[[激发态和光谱计算#计算步骤|TD-DFT计算步骤]]
2. 再进行NTO单点计算
	关键词：
	```
	%oldchk=TBR-s1-td.chk
	%chk=TBR-s1-NTO.chk
	# CAM-B3LYP/6-31g(d,p) geom=allcheck guess=(read,only) density=(check,transition=1) pop=(minimal,nto,savento) scrf em=gd3bj
	```

`density=(check,transition=1)`指定分析第1个激发态
`pop=(minimal,NTO,saveNTO)`：NTO命令Gaussian进行NTO计算；saveNTO将NTO保存到chk文件中，方便可视化。

## 输出文件

1. TD-DFT中关注激发态信息和组态系数：搜索关键词`excited state`
2. NTO本征值，直接给出每一对NTO轨道对激发态的贡献大小。搜素关键词：`alpha virt. eigenvalues`
	找到格式如下：
	```
	Alpha occ. eigenvalues --    0.00476   0.00856   0.02189   0.02224   0.94429
Alpha virt. eigenvalues --    0.94429   0.02224   0.02189   0.00856   0.00476
	```
	只要这两行数字左右对称且数值相同，且都是正数，就找到了NTO本征值。
	找最大的数字（第一个），若$\geq{0}.9$，则只需要看一对轨道
	若$0.5\leq max \leq 0.9$，则激发态有混合，需要看前两对或三对NTO
	若$max\leq 0.5$，则激发态高度复杂，用简单的单轨道图像很难解释

3. 用Gaussview打开.chk文件，查看MOs，本征值相同的轨道为一对

## 如何判断 ππ* 还是 nπ*

按优先级依次检查：

1. **分子组成（最优先，大多数情况一步终结）**：n 轨道来自孤对电子，只有 N、O、S、卤素等杂原子才能提供。纯碳氢化合物不存在 n 轨道，物理上不可能有 nπ* 跃迁，所有跃迁必为 ππ*。例：DHR（C30H14 纯烃）无杂原子 → 全部 ππ*。
2. **态对称性（有对称性时最干净）**：平面分子属 Cs 点群，对称面 = 分子平面。π 轨道对 σh 反对称（A″），σ/n 轨道对称（A′）。因此 ππ* 跃迁 = A″×A″ = A′；nπ* 跃迁 = A′×A″ = A″。TD 输出中的 `Excited State N: Singlet-A'` 直接给出态对称性：A′ 对应 ππ*，A″ 对应 nπ*。例：DHR S9 输出 `Singlet-A'` → ππ*。
3. **轨道形状（可视化）**：平面分子中 π 轨道是垂直于分子平面的 pz 瓣（上下两朵云）；n 轨道是躺在分子平面内、朝外的孤对型轨道。用 GaussView 打开 .fchk 看 NTO 空穴轨道的形状即可区分。
4. **轨道成分（定量）**：分析空穴轨道的 AO 组成（px/py/pz 占比），pz 主导 = π，平面内 sp² 孤对 = n。需 Multiwfn 等工具辅助。

## 如何判断 LE 还是 CT

核心判据：空穴轨道与电子轨道的空间位置关系。对含多个发色团片段的分子（如双薁单元）：

| 空穴位置 | 电子位置 | 判断 |
| --- | --- | --- |
| 同一片段 | 同一片段 | LE（局域激发） |
| 片段 A | 片段 B | CT（电荷转移） |
| 部分跨片段分离 | 部分跨片段分离 | LE/CT 混合 |

不用工具的辅助线索：
1. **振子强度**：纯 CT 态的空穴-电子空间重叠小、跃迁偶极矩小，通常 f < 0.1。f 大暗示 LE 特征明显（或 LE 主导的混合）。注意这只是倾向性证据，不是充分条件。
2. **偶极矩变化**：CT 态伴随大电荷分离，激发态偶极矩相对基态显著变化。

定量判据（空穴-电子重叠指数、质心距离等）需 Multiwfn 空穴-电子分析。
