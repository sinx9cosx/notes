# 简介

## 光吸收过程

光吸收对应哪些计算量：一次吸收过程常用4个量描述
1. 激发能
2. 激发波长
3. [[电磁波照射下的跃迁概率公式#连续谱|跃迁偶极矩]]
4. [[振子强度]]

在原子单位下：跃迁偶极矩和振子强度满足：
$$
f=\frac{2}{3}\Delta E_{0n}R_{0n}^2
$$
因此，跃迁偶极矩越大，通常对应越强的光吸收。

## TD-DFT

TD-DFT计算的物理量：
- 各激发态的激发能与波长
- 振子强度和跃迁偶极信息
- 主要轨道跃迁分量（？）
- 指定数量的单重态或三重态能级（？）

输出中的`Excited state`行会列出激发态序号、能量、波长和振子强度。其后的轨道跃迁系数可以帮助判断这个激发态主要由哪些轨道跃迁组成。

TD-DFT得到的是一组离散跃迁，即棒状普贤，谱线位置和高度由激发能和振子强度决定。

## 后处理

连续的理论UV-Vis或荧光曲线由离散谱线展宽得到，峰形和[[偶极强度与吸收系数的关系#^54baeb|半峰宽]]属于后处理设置。
一般用高斯展宽，半峰宽为0.1-0.3eV.。

# 计算步骤

## UV-Vis光谱

| 步骤  | 计算          | 得到                 |
| --- | ----------- | ------------------ |
| 1   | S0 opt freq | 基态平衡结构             |
| 2   | S0 TD       | 激发能、波长、振子强度、主要跃迁分量 |
| 3   | 展宽          | 连续的理论UV-Vis光谱      |

第2步的输入：

```
%chk=s0-td.chk
%nprocshared=16
%mem=32GB
#p B3LYP/def2SVP EM=GD3BJ TD=(Singlets,NStates=20)

excitations at s0 geometry

0 1
<s0平衡结构下的坐标>


```
