# 光谱分类总览

光谱分类没有唯一标准，同一张光谱可以从不同角度归入不同类别。本文按五个维度分述，最后给出计算化学的实用清单。

## 1. 按电磁波段划分（实验视角）

不同波段的光子能量对应不同能级的跃迁：

| 波段 | 能量范围 | 对应的能级跃迁 | 谱学 |
| --- | --- | --- | --- |
| X射线 | $>10^3$ eV | 内层电子 | XPS/XAS |
| 紫外-可见 | 1.5-6 eV | 价电子 | UV-Vis吸收/荧光/磷光/ECD |
| 红外 | 0.05-0.5 eV | 分子振动 | IR/VCD |
| 微波 | $10^{-4}$-$10^{-2}$ eV | 分子转动 | 转动光谱 |
| 射频 | ~$10^{-6}$ eV | 核/电子自旋 | NMR/ESR（严格说已不属于光学光谱） |

## 2. 按光与物质的相互作用划分（测量方式视角）

- 吸收光谱：光被吸收、透射光减弱。例：UV-Vis吸收、IR吸收。
- 发射光谱：
  - 荧光：自旋允许（S1→S0），寿命纳秒级；
  - 磷光：自旋禁阻（T1→S0），寿命毫秒到秒级。
- 散射光谱：
  - Rayleigh散射：弹性散射，波长不变；
  - Raman散射：非弹性散射，波长移动等于振动能级差，分为Stokes（波长红移）与反Stokes（波长蓝移）。

## 3. 按分子能级结构划分（理论化学核心）

在Born-Oppenheimer近似下，分子总能量可写为

$$E = E_{电子} + E_{振动} + E_{转动}$$

三级能量尺度依次相差约百倍：电子跃迁为eV量级（UV-Vis区），振动跃迁约0.1 eV（红外区），转动跃迁约$10^{-3}$ eV（微波区）。

- 电子光谱：位于UV-Vis区，呈带状——电子跃迁叠加振动精细结构；理论计算的离散跃迁需经展宽才成为连续谱带（见[[激发态和光谱计算]]）。
- 振动光谱：位于红外区。
- 转动光谱：位于微波区；溶液中转动结构被碰撞抹平，仅气相可测。
- 按谱形补充分类：
  - 线状光谱：孤立原子、低压气体；
  - 带状光谱：分子电子光谱（振动精细结构叠加）；
  - 连续光谱：环境展宽足够大时（如室温溶液UV-Vis）。

## 4. 按研究对象划分

- 原子光谱：只有电子跃迁，永远是线状光谱；
- 分子光谱：含振动/转动叠加，呈带状或连续。

## 5. 计算化学视角的实用清单

| 光谱类型 | 计算方法 | 工具 |
| --- | --- | --- |
| UV-Vis吸收 | TD-DFT | Gaussian |
| 荧光发射 | S1优化 + TD | Gaussian |
| 磷光发射 | T1优化 + TD + 自旋轨道耦合 | ORCA更方便 |
| 振动分辨光谱 | FC/HT/Duschinsky | Gaussian FCHT / ezFCF / FCclasses3 |
| IR | 基态freq（谐频 + 标度因子） | Gaussian |
| Raman | freq + 极化率导数 | Gaussian |
| ECD | TD-DFT旋光强度 | Gaussian/Multiwfn |
| VCD/ROA | freq + 磁场微扰 | Gaussian |
| 光电子能谱 | 电离能/电子亲和能 | Gaussian |
