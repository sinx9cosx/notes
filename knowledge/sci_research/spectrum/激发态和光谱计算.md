# 简介

## 光吸收过程

光吸收对应哪些计算量：一次吸收过程常用4个量描述
1. 激发能
2. 激发波长
3. [[电磁波照射下的跃迁概率公式#连续谱|跃迁偶极矩]]
4. [[振子强度]]

在原子单位下：跃迁偶极矩和振子强度满足：
$$
f=\frac{2}{3}\Delta E_{0n}R_{0n}^2
$$
因此，跃迁偶极矩越大，通常对应越强的光吸收。

## TD-DFT

TD-DFT计算的物理量：
- 各激发态的激发能与波长
- 振子强度和跃迁偶极信息
- 主要轨道跃迁分量
- 指定数量的单重态或三重态能级

输出中的`Excited state`行会列出激发态序号、能量、波长和振子强度。其后的轨道跃迁系数可以帮助判断这个激发态主要由哪些轨道跃迁组成。

TD-DFT得到的是一组离散跃迁，即棒状谱线，谱线位置和高度由激发能和振子强度决定。

## 后处理

连续的理论UV-Vis或荧光曲线由离散谱线展宽得到，峰形和[[偶极强度与吸收系数的关系#^54baeb|半峰宽]]属于后处理设置。
一般用高斯展宽，半峰宽为0.1-0.3 eV。

展宽的物理意义：
1. 量子力学内禀属性：根据海森堡不确定性原理，激发态寿命$\Delta t$与能量$\Delta E$不能同时精确，寿命越短，能级就有一定的宽度（$\Delta E\approx\frac{\hbar}{\Delta t}$）
2. 实际环境的统计效应：实际样品中每个分子的环境不同，导致跃迁能量有微小差异，观测到的光谱是所有分子贡献的统计叠加。当这些差异呈高斯分布后，叠加后的总包络呈现为[[偶极强度与吸收系数的关系#^b63559|高斯线型]]

半峰宽可以自己设置的原因是：
1. 它是多种因素的表现，计算只给出理想气态分子结果，无法自动包含这些因素。因此需要根据实际情况设置
2. 通过调整半峰宽可以让计算谱与实验谱更好吻合。设置通常参考实验值或文献。

# 计算操作流程

## 计算UV-Vis光谱

### 计算步骤

| 步骤  | 计算          | 得到                 |
| --- | ----------- | ------------------ |
| 1   | S0 opt freq | 基态平衡结构             |
| 2   | S0 TD       | 激发能、波长、振子强度、主要跃迁分量 |
| 3   | 展宽          | 连续的理论UV-Vis光谱      |

结构优化后检查：
1. 是否优化成功：最后一轮四个`Converged?`都是`YES`
2. 是否有虚频：`NImag=0`

第2步的输入：

```
%chk=s0-td.chk
%nprocshared=16
%mem=32GB
#p B3LYP/def2SVP EM=GD3BJ TD=(Singlets,NStates=20,Root=1)

excitations at s0 geometry

0 1
<s0平衡结构下的坐标>


```

TD关键词的选项

| 选项        | 含义                                   |
| --------- | ------------------------------------ |
| TD        | 激发态计算，默认计算前三个                        |
| Singlets  | 只计算单重激发态；对于闭壳层单重基态是默认                |
| NStates=N | 求前N个激发态，默认3                          |
| Root=N    | 指定后续密度、性质、结构优化或振动分子关注第N个激发态，默认Root=1 |
| 50-50     | 同时计算单重态和三重态                          |

### 读取激发态信息

在输出文件中搜索Excited State，可以读到激发态序号、激发能、波长和振子强度。后面给出主要轨道跃迁分量。

![[excitation.jpg]]

箭头左侧是占据轨道编号，右侧是空轨道编号，后面的$c_{i}$是该分量的组态系数，正负号反映分量之间的相位关系。列出的只是主要分量。

对于闭壳层单重基态，Gaussian通常只打印一组自旋分量，因此某一轨道跃迁的近似贡献估算：
$$
P_{i}\approx 2c_{i}^2\times 100\%
$$
原因：闭壳层单重基态下，一个单电子激发组态实际由两个自旋通道等权叠加：
$$
\Psi_{CSF}=\frac{1}{\sqrt{ 2 }}(D_{\alpha\to \alpha}+D_{\beta\to \beta})
$$
而Gaussian打印出来的系数c是单个自旋分量的系数。

## 后处理

### 高斯展宽

在Gaussview中打开TDDFT输出文件后，在分子窗口进入Results -> UV-Vis，即可打开电子光谱绘制界面。

在光谱窗口中，可以通过Plots -> Properties设置横纵坐标，波长范围和半峰宽，也可以通过Plots -> Save Data或曲线的右键菜单导出文本数据，用于后续重新绘图。

## 计算荧光发射

| 步骤  | 计算             | 得到            |
| --- | -------------- | ------------- |
| 1   | S0 opt freq    | 基态平衡结构        |
| 2   | S1 opt freq TD | S1平衡结构        |
| 3   | S1 TD          | S1->S0发射      |
| 4   | 展宽             | 连续的理论UV-Vis光谱 |

第2步输入文件：

```
%chk=s1-opt.chk
%nprocshared=16
%mem=32GB
#p B3LYP/def2SVP EM=GD3BJ TD=(Singlets,NStates=10,Root=1) opt freq

s1 opt and freq

0 1
<s0平衡结构下的坐标>

```

优化过程中还应检查激发能、振子强度和主要轨道跃迁是否连续；若这些性质突然改变，说明可能发生了态混合或态翻转，不能只凭Root编号认定始终是同一个激发态。

第3步输出文件示例：

```
Excited State 1:Singlet-A 4.1127 eV 301.47 nm f=0.5989
    41 -> 42  0.70196
```

因此垂直发射波长为301.47 nm，相较于S0结构上250 nm附近的第一组强吸收，发射发生红移。这是激发态结构弛豫在光谱上的表现。

把这个发射能和对应f作为一根离散发射线，再采用Gaussian函数作经验展宽，可以得到一个以S1->S0垂直发射能为中心的简化电子谱带，它不等于包含振动精细结构、构象平均和环境展宽的真实荧光光谱。
要计算包含振动精细结构的荧光光谱可以使用[[MOMAP 7 QC准备]]。
