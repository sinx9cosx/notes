# 安装软件


**更新**
   
   ```bash
   sudo apt update
   ```
   

**安装**

   ```bash
   sudo apt install 软件名字
   ```


# 运行软件

装好之后，**直接在黑框里输入它的名字，按回车**，它就跑了。

**分两种情况**

**情况A：这个软件是“占着黑框”的**（比如刚装的`vim`编辑器，或者游戏）

输入 `vim` 按回车，黑框瞬间变成编辑界面。**想退出来**？按键盘左上角 `Esc` 键，然后敲 `:q` 再按回车，就回到原来的黑框了。
  
**救命键**：如果软件卡住或死循环，按住 `Ctrl` 不松手，再按 `C` 键（即 `Ctrl + C`），强制把它关掉，回到黑框提示符。

**情况B：这个软件是“后台服务”**（比如跑个网站服务器）
输入名字回车后，黑框就卡在那里不动了，日志一行一行往外蹦。
**想让它继续运行，但自己腾出黑框干别的事？** 按 `Ctrl + Z` 把它挂起，或者**更简单的办法**：在Windows终端顶部点 **加号“+”** 新建一个黑框标签页，原来的让它自己跑着就行。
