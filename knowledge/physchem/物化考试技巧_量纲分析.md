# 量纲与证明分析总纲

> [!note] 核心思想
> 1. **量纲是公式的语法**：任何等式两边、积分测度、微分变量必须量纲一致。
> 2. **证明是结构的复用**：分离变量、对称性论证、Legendre 变换、拉格朗日乘数法、反证法——这五种武器贯穿三大章。

# Part II 量子力学 —— 公式量纲逐条验证

> [!tips] 本节将逐条验证你笔记中的核心公式。特别注意：你的笔记中有多处 $\hbar$ **漏写平方**的笔误，量纲分析可一眼识破。

## 1. 基本假设与算符

| 公式/算符 | 量纲验证 | 结果 |
|-----------|----------|------|
| $\hat{p}=-i\hbar\frac{d}{dx}$ | $[\hbar]/[L]=[M L^2 T^{-1}][L^{-1}]=[M L T^{-1}]$（动量） | ✅ |
| $\hat{T}=-\frac{\hbar^2}{2m}\frac{d^2}{dx^2}$ | $[\hbar]^2/([M][L]^2)=[M L^2 T^{-2}]$（能量） | ✅ |
| $\hat{H}\psi_n=E_n\psi_n$ | 两边同乘 $\psi$：$[E][\psi]=[E][L^{-3/2}]$，一致 | ✅ |
| $\langle O\rangle=\int\psi^*\hat{O}\psi d\tau$ | $[L^{-3/2}][O][L^{-3/2}][L^3]=[O]$ | ✅ |

## 2. 一维无限深势阱

你的笔记中一维势阱（$0\leq x\leq a$）给出：
$$\textcolor{red}{E=\frac{\hbar}{2m}\frac{n^2\pi^2}{a^2}} \qquad \text{（笔记原文）}$$

<mark style="background: #FFB86CA6;">量纲警报</mark>：
- 右边：$[\hbar]/[M][L]^2 = [M L^2 T^{-1}]/[M L^2] = [T^{-1}]$（频率量纲！不是能量）
- **正确应为**：$E_n=\frac{\hbar^{\mathbf{2}}\pi^2n^2}{2ma^2}$
- 修正后：$[\hbar^2]/[M][L^2]=[M^2L^4T^{-2}]/[ML^2]=[ML^2T^{-2}]$ = **能量** ✅

> [!error] 常见笔误
> 二维势阱笔记中 $E=\frac{\hat{h}}{2m}(k_x^2+k_y^2)$ 同样疑似 $\hbar^2$ 漏写。$\hbar^2k^2/2m$ 才是能量。

## 3. 谐振子

| 公式 | 量纲验证 |
|------|----------|
| $E_v=(v+\frac12)\hbar\omega$ | $[\hbar][\omega]=[M L^2 T^{-1}][T^{-1}]=[M L^2 T^{-2}]$ ✅ |
| $\omega=\sqrt{k/\mu}$ | $[k]/[\mu]=[M T^{-2}]/[M]=[T^{-2}]$，开方得 $[T^{-1}]$ ✅ |
| $\Phi_v(x)=N_v H_v(\alpha^{1/2}x)e^{-\alpha x^2/2}$ | $\alpha$ 必须有 $[L^{-2}]$ 才能使 $\alpha x^2$ 无量纲。由 $\alpha=\frac{m\omega}{\hbar}$ 验证：$[M][T^{-1}]/[M L^2 T^{-1}]=[L^{-2}]$ ✅ |
| 经典转折点 $(v+\frac12)\hbar\omega=\frac12kx^2$ | 左边能量，右边 $[M T^{-2}][L^2]=[M L^2 T^{-2}]$ ✅ |

## 4. 环上粒子与刚性转子

| 公式 | 量纲验证 |
|------|----------|
| $E=\frac{\hbar^2m^2}{2I}$（环上） | $[\hbar^2]/[I]=[M^2L^4T^{-2}]/[ML^2]=[ML^2T^{-2}]$ ✅ |
| $E=l(l+1)\frac{\hbar^2}{2I}$（球面/转子） | 同上 ✅ |
| $J=\sqrt{l(l+1)}\hbar$ | $[\hbar]$ 是角动量量纲 ✅ |
| $J_z=m_l\hbar$ | 同上 ✅ |

> [!note] 磁量子数 $m$ 的陷阱
> 环上粒子笔记中同时出现了质量 $m$ 和量子数 $m$。量纲上，**量子数永远无量纲**，若公式结果是能量而分子出现 $m^2$，结合分母 $I$ 立即知道此 $m$ 是量子数。

## 5. 氢原子

| 公式 | 量纲验证 |
|------|----------|
| $a_0=\frac{4\pi\varepsilon_0\hbar^2}{m_ee^2}$ | $[\varepsilon_0][\hbar]^2/([m_e][e]^2)$。由库仑力 $F=\frac{e^2}{4\pi\varepsilon_0r^2}$ 得 $[e^2/\varepsilon_0]=[F][L^2]=[M L^3 T^{-2}]$。代入得 $[M L^2 T^{-1}]^2/([M][M L^3 T^{-2}])=[L]$ ✅ |
| $E_n=-Z^2\frac{\hbar^2}{2m}\frac{1}{a_0^2}\frac{1}{n^2}$ | $[\hbar^2]/([M][L^2])$ = 能量 ✅ |
| 离心势能项 $\frac{\hbar^2}{2mr^2}l(l+1)$ | $[\hbar^2]/([M][L^2])$ = 能量 ✅ |

# Part III 热力学 —— 公式量纲逐条验证

## 1. 第一定律与状态函数

| 公式 | 量纲验证 |
|------|----------|
| $\Delta U=Q+W$ | 三项均为能量 ✅ |
| $H=U+pV$ | $[p][V]=[M L^{-1}T^{-2}][L^3]=[M L^2 T^{-2}]$ = 能量 ✅ |
| $A=U-TS$ | $[T][S]=[\Theta][M L^2 T^{-2}\Theta^{-1}]$ = 能量 ✅ |
| $G=H-TS=U+pV-TS$ | 同上 ✅ |
| $C_p-C_V=nR$ | $[nR]=[N][M L^2 T^{-2}\Theta^{-1}N^{-1}]$ = $[M L^2 T^{-2}\Theta^{-1}]$，即热容量 ✅ |

## 2. 绝热过程方程式

$$pV^\gamma=K \qquad TV^{\gamma-1}=C_1 \qquad p^{1-\gamma}T^\gamma=C_2$$

- $\gamma=C_p/C_V$ 无量纲，故 $pV^\gamma$：$[M L^{-1}T^{-2}][L^3]^\text{无}$ = $[M L^2 T^{-2}]$？**不对**，$pV$ 是能量，但 $pV^\gamma$ 量纲是 $[M L^{-1}T^{-2}][L^{3\gamma}]$。
- **纠正**：$pV^\gamma$ 并非能量！它的量纲是 $[M L^{3\gamma-1}T^{-2}]$。这里的常数 $K$ 只是积分常数，不要求有物理量纲意义。但 $TV^{\gamma-1}$：$[\Theta][L^3]^{\gamma-1}$ 同样奇怪。
- **更严谨的理解**：这些公式只在特定单位制下以比例形式出现，或理解为 $p_1V_1^\gamma=p_2V_2^\gamma$。若单独写 $pV^\gamma=K$，$K$ 量纲依赖 $\gamma$。

> [!attention] 量纲陷阱
> 绝热方程是**比例等式**，不宜单独讨论 $pV^\gamma$ 的量纲。考试中若让你推导，应从微分式 $\frac{dT}{T}+(\gamma-1)\frac{dV}{V}=0$ 出发，该式各项无量纲，安全无误。

## 3. 克劳修斯不等式与熵

| 公式 | 量纲验证 |
|------|----------|
| $dS=\frac{\delta Q_{rev}}{T}$ | $[S]=[\text{能量}]/[\Theta]$ ✅ |
| $\Delta S_{sys}-\frac{Q_{sys}}{T_{sur}}\geq0$ | $[S]-[\text{能量}]/[\Theta]=[S]-[S]\geq0$ ✅ |
| 等容 $\Delta S=C_V\ln\frac{T_末}{T_始}$ | $[C_V]=[M L^2 T^{-2}\Theta^{-1}]$，对数无量纲，结果 = 熵 ✅ |
| 等压 $\Delta S=C_p\ln\frac{T_末}{T_始}$ | 同上 ✅ |

## 4. 热力学基本方程与 Maxwell 关系

基本方程：
$$dU=TdS-pdV \Rightarrow [M L^2 T^{-2}]=[\Theta][M L^2 T^{-2}\Theta^{-1}]-[M L^{-1}T^{-2}][L^3]$$
两边均为能量，且交叉项均为能量 ✅

Maxwell 关系示例：
$$\left(\frac{\partial S}{\partial V}\right)_T=\left(\frac{\partial p}{\partial T}\right)_V$$

- 左边：$[S]/[V]=[M L^2 T^{-2}\Theta^{-1}]/[L^3]=[M L^{-1}T^{-2}\Theta^{-1}]$
- 右边：$[p]/[T]=[M L^{-1}T^{-2}]/[\Theta]=[M L^{-1}T^{-2}\Theta^{-1}]$ ✅

> [!note] 速记技巧
> 一对共轭变量 $(X,Y)$ 的微分 $\partial Y/\partial X$ 量纲 = $[Y]/[X]$。Maxwell 关系本质上是**共轭变量交叉配对后量纲恰好一致**。

## 5. 化学势

| 公式 | 量纲验证 |
|------|----------|
| $\mu_B=(\partial G/\partial n_B)_{T,p}$ | $[G]/[n]=[M L^2 T^{-2}]/[N]=\mathrm{J/mol}$ ✅ |
| $d\mu=-\bar{S}dT+\bar{V}dp$ | $[\bar{S}][\Theta]=[M L^2 T^{-2}\Theta^{-1}N^{-1}][\Theta]$ = $\mathrm{J/mol}$；$[\bar{V}][p]=[L^3N^{-1}][M L^{-1}T^{-2}]$ = $\mathrm{J/mol}$ ✅ |
| $\mu^*=\mu^\ominus+RT\ln\frac{p}{p^\ominus}$ | $[RT]=[M L^2 T^{-2}\Theta^{-1}N^{-1}][\Theta]$ = $\mathrm{J/mol}$；对数项无量纲 ✅ |

# Part IV 统计力学 —— 公式量纲逐条验证

## 1. 熵与微观状态数

| 公式 | 量纲验证 |
|------|----------|
| $S=k\ln\omega$ | $[k]=\mathrm{J/K}$，$\omega$ 无量纲 → $[S]=\mathrm{J/K}$ ✅ |
| 吉布斯熵 $S=-k\sum p_i\ln p_i$ | $p_i$ 无量纲 → $[S]=[k]$ ✅ |
| $dS=\frac{1}{T}dU+\frac{p}{T}dV-\frac{\mu}{T}dN$ | $[dU/T]=[\text{能量}]/[\Theta]=\mathrm{J/K}$；$[p/T][V]=([M L^{-1}T^{-2}]/[\Theta])[L^3]=\mathrm{J/K}$；$[\mu/T][N]=\mathrm{J/K}$ ✅ |

## 2. 玻尔兹曼分布与配分函数

| 公式 | 量纲验证 |
|------|----------|
| 玻尔兹曼因子 $e^{-\varepsilon/kT}$ | $[\varepsilon]=[kT]$ = 能量 → 指数无量纲 ✅ |
| $n_i=N\frac{g_ie^{-\varepsilon_i/kT}}{\sum g_ie^{-\varepsilon_i/kT}}$ | 右边 $N\times$ 无量纲 = $[N]$（粒子数），若 $N$ 是物质的量则右边也是物质的量，与左边一致 ✅ |
| $q=\sum g_ie^{-\varepsilon_i/kT}$ | 各项无量纲 → $q$ 无量纲 ✅ |
| 平动 $q_t=(\frac{2\pi mkT}{h^2})^{3/2}V$ | 内部：$[mkT]/[h^2]=[M][M L^2 T^{-2}]/[M^2 L^4 T^{-2}]=[L^{-2}]$；开 $3/2$ 次得 $[L^{-3}]$；乘 $[V]=[L^3]$ → **无量纲** ✅ |
| 转动 $q_r=\frac{T}{\Theta_r\sigma}$ | $\Theta_r$ 定义为 $\frac{\hbar^2}{8\pi^2Ik}$，其量纲为 $[\hbar^2]/[I][k]=[M^2L^4T^{-2}]/([ML^2][ML^2T^{-2}\Theta^{-1}])=[\Theta]$ → 无量纲 ✅ |
| 振动 $q_v^0=\frac{1}{1-e^{-\Theta_v/T}}$ | 指数无量纲 → 整体无量纲 ✅ |

## 3. 统计热力学量（由配分函数导出）

| 公式 | 量纲验证 |
|------|----------|
| $U=NkT^2(\frac{\partial\ln q}{\partial T})_V$ | $[NkT^2][T^{-1}]=[NkT]$ = 能量（每摩尔用 $R$ 则为 $\mathrm{J/mol}$）✅ |
| $p=NkT(\frac{\partial\ln q}{\partial V})_T$ | $[NkT][L^{-3}]=[M L^{-1}T^{-2}]$ = 压强 ✅ |
| $S=\frac{U}{T}+Nk\ln\frac{q}{N}+Nk$（离域） | $[U/T]=\mathrm{J/K}$；$[Nk]=\mathrm{J/K}$（因为 $k$ 是每粒子的）✅ |
| $A=-NkT\ln\frac{qe}{N}$（离域） | $[NkT]=\text{能量}$ ✅ |
| 标准摩尔吉布斯自由能函数 $\frac{G_m^\ominus-U_{0,m}}{T}=-R\ln\frac{q^0}{N}$ | 左边 = $\mathrm{J/(mol\cdot K)}$；右边 = $[R]\times$ 无量纲 = $\mathrm{J/(mol\cdot K)}$ ✅ |

> [!note] 定域子 vs 离域子
> $U,H,p$ 与 $q$ 的微分有关，不涉及 $N!$ 修正，故**不区分**定域/离域。
> $S,A,G$ 涉及 $\ln q$ 的绝对值，需要 $N!$ 修正，故**区分**定域/离域。这是量纲分析无法直接看出的结构差异，需记住。

# Part V 证明方法体系梳理

你的笔记中隐藏了**五种核心证明/推导范式**，考试中万变不离其宗。

## 范式一：分离变量法（空间解耦）
> 适用：多自由度体系、球坐标/直角坐标薛定谔方程

**步骤骨架**：
1. **假设乘积形式**：$\Psi(x,y)=X(x)Y(y)$ 或 $\Psi(r,\theta,\phi)=R(r)Y(\theta,\phi)$
2. **代入方程**：两边同除以 $\Psi$，将不同坐标项分离到等号两侧
3. **引入分离常数**：令各自等于同一常数（如 $E_x, E_y$ 或 $l(l+1)$）
4. **分别求解**：利用边界条件（$\psi=0$、周期性、有限性）**量子化**
5. **叠加能量**：$E=E_x+E_y$ 或 $E=E_r+E_{angle}$

<mark style="background: #ADCCFFA6;">对应笔记</mark>
- 一维/二维势阱：$X(x)Y(y)$，边界 $\psi=0$ 给出 $n_x,n_y$
- 氢原子：$R(r)Y(\theta,\phi)$，角度部分给出 $l,m_l$，径向部分给出 $n$
- 刚性转子：$\psi(\phi)\Theta(\theta)$，$m_l$ 来自周期性边界条件 $\psi(\phi)=\psi(\phi+2\pi)$

## 范式二：对称性论证与对易算符
> 适用：宇称、简并、共同本征态

**步骤骨架**：
1. **定义对称算符** $\hat{P}$（如空间反演 $\hat{p}\psi(x)=\psi(-x)$）
2. **证明对易** $[\hat{H},\hat{P}]=0$
3. **利用定理**：对易算符有共同本征函数完备集
4. **确定本征值**：$\hat{P}^2=1 \Rightarrow \lambda=\pm1$（偶/奇函数）

<mark style="background: #ADCCFFA6;">对应笔记</mark>
- 一维对称势 $V(x)=V(-x)$：$\hat{p}$ 与 $\hat{H}$ 对易，故能量本征态必有确定宇称
- 环上粒子简并：$m$ 与 $-m$ 能量相同，源于 $\phi\to-\phi$ 的旋转对称性

> [!tips] 易错点
> 简并子空间内可以重新组合本征态。如环上粒子的 $\cos m\phi,\sin m\phi$ 是能量的本征态，但不是 $\hat{J}_z$ 的本征态（它们没有确定的 $m$ 值）。

## 范式三：Legendre 变换（热力学辅助函数构造）
> 适用：$U\to H\to A\to G$ 的构造与自然变量转换

**步骤骨架**：
1. **写出全微分**：$dU=TdS-pdV+\sum\mu dn$
2. **识别自然变量**：$U(S,V,n)$
3. **目标**：将不易测的 $S$ 换成易测的 $T$（或 $V$ 换成 $p$）
4. **操作**：$g=f-\sum u_i x_i$（减去共轭变量对的乘积）
   - $H=U-(-p)V=U+pV$（$p$ 与 $V$ 共轭，但符号注意！）
   - $A=U-TS$
   - $G=H-TS=U+pV-TS$
5. **重写全微分**：新函数的新自然变量自动显现

<mark style="background: #ADCCFFA6;">对应笔记</mark>
- $dH=TdS+Vdp$（$H$ 的自然变量 $S,p$）
- $dA=-SdT-pdV$（$A$ 的自然变量 $T,V$）
- $dG=-SdT+Vdp$（$G$ 的自然变量 $T,p$）

## 范式四：极值/变分法（拉格朗日乘数 & 变分原理）
> 适用：玻尔兹曼分布推导、H₂⁺ LCAO、基态能量近似

**A. 拉格朗日乘数法（统计力学）**
1. **目标函数**：$\ln\omega$（极大化微观状态数）
2. **约束条件**：$\sum n_i=N$，$\sum n_i\varepsilon_i=U$
3. **构造拉氏量**：$Z=\ln\omega+\gamma(\sum n_i-N)+\beta(\sum n_i\varepsilon_i-U)$
4. **对 $n_i$ 求偏导 = 0** → 玻尔兹曼分布 $n_i\propto g_ie^{-\beta\varepsilon_i}$
5. **识别乘子**：$\beta=-1/kT$（通过与热力学 $1/T=(\partial S/\partial U)_V$ 对比）

**B. 变分法（量子力学）**
1. **尝试波函数** $\psi_{\pm}=\varphi_A\pm\varphi_B$（LCAO）
2. **计算能量期望值**：$\langle E\rangle=\frac{\int\psi^*\hat{H}\psi d\tau}{\int\psi^*\psi d\tau}$
3. **定义核心积分**：$S,J,K$（重叠、库仑、交换）
4. **得到成键/反键能级**：$E_{\pm}=E_1+\frac{1}{R}+\frac{J\pm K}{1\pm S}$

<mark style="background: #ADCCFFA6;">对应笔记</mark>
- 统计力学最大法推导玻尔兹曼分布
- $H_2^+$ 的 LCAO-MO 与成键/反键态分析
- 变分原理核心思想：任何尝试波函数给出的能量 $\geq$ 真实基态能量

## 范式五：反证法（热力学第二定律应用）
> 适用：卡诺定理、克劳修斯不等式、过程不可逆性证明

**步骤骨架**：
1. **假设反面成立**：如假设不可逆热机效率 $\eta_S > \eta_C$（可逆热机）
2. **构造联合循环**：将假设热机与可逆制冷机耦合
3. **推导矛盾**：得出从单一热源吸热全部做功（违反 Kelvin 表述）或热量自发从低温传向高温（违反 Clausius 表述）
4. **否定假设**：原命题得证

<mark style="background: #ADCCFFA6;">对应笔记</mark>
- 卡诺定理证明：$\eta_S\leq\eta_C$
- 克劳修斯不等式：$\oint\frac{\delta Q}{T}\leq0$

## 🚦 三秒红灯检测法

| 看到公式中... | 立即检查 | 红灯信号 |
|---------------|----------|----------|
| 指数上有量纲 | 如 $e^{-x}$ 中 $[x]\neq1$ | ❌ 公式必错 |
| 对数内有量纲 | 如 $\ln p$（而不是 $\ln(p/p^\ominus)$） | ❌ 公式必错 |

## 🎯 证明题答题模板

**若遇到“证明能量本征态具有确定宇称”**：
> 1. 定义宇称算符 $\hat{P}$，给出本征值 $\lambda=\pm1$。
> 2. 计算对易子 $[\hat{H},\hat{P}]$。
> 3. 利用 $V(x)=V(-x)$ 证明对易子为零。
> 4. 结论：$\hat{H}$ 与 $\hat{P}$ 有共同本征态，故能量本征态必为奇或偶函数。

**若遇到“推导玻尔兹曼分布”**：
> 1. 写出微观状态数 $\omega$（定域/离域要说明）。
> 2. 用 Stirling 近似处理 $\ln n_i!$。
> 3. 列出约束：粒子数守恒、能量守恒。
> 4. 设拉格朗日函数，对 $n_i$ 求偏导。
> 5. 解出 $n_i\propto e^{-\beta\varepsilon_i}$，并通过热力学关系 $\beta=1/kT$。

**若遇到“由麦克斯韦关系证明某偏微分等式”**：
> 1. 识别适用的热力学基本方程（$U,H,A,G$）。
> 2. 写出对应的全微分形式。
> 3. 直接应用 Schwarz 定理（混合偏导相等）写出 Maxwell 关系。
> 4. 将目标式子通过 $C_p=T(\partial S/\partial T)_p$ 等定义转化为含 $S$ 的偏导。
> 5. 代入 Maxwell 关系，整理得证。
