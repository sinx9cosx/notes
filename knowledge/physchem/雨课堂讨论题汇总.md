## 1. 波函数的叠加

波函数的叠加与线性组合是波的相互作用的基本形式。我们课上用实函数展示了波的叠加
$$
f(t)=\sum A_{n}\cos(\omega_{n}t)
$$

我们也可以用复函数的线性组合表达波的叠加
$$
f(t)\sum S_{n}e^{i\omega_{n}t}
$$

当用复函数做线性组合的时候，函数前的系数 $S_n$ 不一定是实数。那么复数 $S_n$ 的意义是什么？

```
复系数可以写成模长乘以e的iθ次方。模长是振幅，θ是初相位。
```

## 2. 球面粒子

我们在推导球面粒子的波函数的时候得到过一个中间方程，

$$
\hat{H}_\theta \Theta(\theta) + \Theta(\theta) \frac{\hbar^2}{2I_\theta} m_l^2 = E\Theta(\theta)
$$

尝试解释这个方程的意义。方程中左边第二项是势能项么？什么意义？

```
这个方程是球面粒子分离变量后在θ方向上满足的薛定谔方程。方程的第二项是动能，但在θ方向的方程中起势能的作用，记为V_{theta}。在sinθ趋近0的时候，V_{theta}趋近无穷，因此粒子靠近两极会受到排斥，使θ的运动范围受ml和l的限制。
```

## 3. 波函数的意义

波函数是真实存在的还只是某种数学描述？经典力学中的路径呢？结合实际的证据和逻辑阐述你的观点。

```
我认为波函数是一种数学工具，用于计算和预测系统的行为。波函数通过Born规则定义了概率分布。波函数给出了粒子的概率密度，而不是粒子本身的位置。 双缝干涉实验显示，单个粒子表现出波动性（如干涉条纹），但大量粒子的统计结果才与波函数预测一致。这表明波函数不是“真实存在”的波，而是用于计算概率的数学构造。如果波函数是物理实体，单个粒子应直接显示确定路径，但实验否定了这一点。 在经典力学中，路径是确定性的，例如牛顿定律给出精确轨迹。但量子系统受Heisenberg不确定性原理限制： 这意味粒子无法同时具有确定位置和动量，因此经典路径概念失效。波函数作为数学描述，提供了处理这种不确定性的框架。
```

## 4. 概率是无知的度量

依据你学习过的量子力学和统计力学的基本原理，谈谈你对"概率是无知的度量"这个 statement 的观点。

注意：要结合两个学科的原理，要有自己的思考，言之有物。

```
概率是无知的度量是贝叶斯学派的观点，他们认为概率不是物体内在的属性，而是观察者基于有限信息对其不确定性的一种度量。如果一个人对某个事件完全了解，那么概率对他而言就退化为0或1的确定性。与之相对的，频率学派认为概率是事件在长期重复中发生的客观频率，与观察者的知识无关，是内在随机性。两种解释都满足概率公理，在数学上同样“正确”。 在统计力学尤其是经典统计里，概率确实是无知的体现，因为无法求得所有粒子的动力学方程，只能转而去描述它们的整体宏观性质。经过大量实践的验证，这一观点在经典统计框架下是十分合理的。 但从量子力学的角度去看，概率真的是物质的本质属性，这一点由贝尔不等式得到了证明，同样是经过大量实践的检验，是十分合理的观点。 综合来看，在适合的场景持有适合的观点是最合适，最有性价比的。频率学派在物理科学、临床试验、质量控制等需要“客观可重复”的领域很成功。贝叶斯学派在决策理论、机器学习、贝叶斯推断中极为有效，尤其当无法做大量重复实验时。具体场景决定合适的观点，我认为这样是更为方便的做法。
```

这个统计与量子力学的多粒子系统的交换对称反对称是什么关系？

```
在统计微观状态数时，经典力学认为粒子是可区分的，量子力学里粒子是不可区分的。因为全同粒子不可区分，要求波函数必须具有交换对称性，从而消除了经典统计中N!种不同的微观状态计数。
```

## 2. 最可几分布的微观状态数

我们研究统计体系的一个核心方法是用最可几分布来代表整个体系，因为最可几分布的状态数远高于其他分布，特别是随着体系的增大。
但是我们也发现最可几分布的微观状态数在全部微观状态数中的比例是随体系的增大而降低的。为什么我们仍然可以用最可几分布来描述整个统计体系？
从熵的数学表达和"涨落"的概念去解释。

```
虽然最可几分布的微观状态数在全部微观状态数的比例减小，但是几乎全部集中在它和它附近的值上，系统最终平衡，只在峰值附近涨落，而熵正比于lnω，偏离峰值较多的微观状态数经过对数压缩后对总熵的贡献很小，因此可以用最可几分布的微观状态数代替
```

### 3. 信息熵与 SoftMax 函数

什么是 softmax 函数？机器学习中为什么要用 softmax 函数？它与信息熵有什么关系？

```
Softmax函数是把一组任意实数(z1,z2,…,zn)转换成一组概率(p1,p2,…,pn)。输出的每个pi满足在零一之间，所有pi的和为1。 机器学习使用softmax函数的原因有三点:1.将原始输出数值压缩并归一化，为每个类别输出一个概率值，使得模型预测具有明确的统计意义。 2.可微且适合优化，能与机器学习中广泛使用的交叉熵损失函数配合，利于模型稳定训练。 3.放大输入间的差异，得分较高的类别概率会被进一步放大，得分较低的被抑制，让模型的决策边界更清晰。 与信息熵的关系:在满足概率归一化和给定的期望值的约束下，满足最大熵原理，让信息熵保持最大的概率形式就是softmax函数的形式。
```

### 2. Clausius 不等式与熵的状态函数性质

在讨论 Clausius 不等式时，常把体系与环境合在一起看作一个隔绝的"宇宙"。设体系与一个恒温环境发生热交换，体系吸收热量为 $dq$，环境温度为 $T_{\mathrm{env}}$。若将环境近似为无限大热库，则环境熵变可写为

$$
\mathrm{d}S_{\mathrm{env}} = -\frac{dq}{T_{\mathrm{env}}}
$$

因此体系与环境的总熵变为

$$
dS_{\mathrm{univ}} = dS_{\mathrm{sys}} + dS_{\mathrm{env}} = dS_{\mathrm{sys}} - \frac{dq}{T_{\mathrm{env}}} \geq 0
$$

由此可得 Clausius 不等式的一种形式：

$$
dS_{\mathrm{sys}} \geq \frac{dq}{T_{\mathrm{env}}}
$$

有教材或课件进一步说：

> 对于同一个体系初态和终态，不同过程中的热量 $q$ 不同，因此环境熵变不同，从而整个 universe 的熵变与过程有关。

**问题**

熵是状态函数。既然体系加环境可以看作一个更大的隔绝体系，甚至称为"宇宙"，那么为什么还说 $\Delta S_{\mathrm{univ}}$ 与过程有关？这是否与"熵是状态函数"矛盾？

```
这并不矛盾：宇宙虽然是一个隔离体系但是并不是处处均一的。也就是说某处和另一处的熵是不同的。内部是可以按照某种条件划分为体系和环境的。宇宙总熵变是体系熵变与环境熵变的和。对于体系而言，熵是状态函数，只由体系的始末态决定；环境熵变和过程的实际传热量直接相关。所以对于宇宙而言不同过程产生的熵变是不同的。总的来说矛盾产生于把宇宙当作处于平衡态的一般隔离体系来处理，这个处理是有问题的。
```

### 3. 热力学基本方程与自发过程判据

热力学基本方程中的自然变量变换通过Legendre transform实现，但是在推出A和G这些量作为自发性判据的时候的一个基本前提是系统热变化与环境熵变直接的对应关系，即要求系统无限大，且温度恒定。这个前提在Legenderal transform那里并不需要。

那么，从Legendre transform得到A和G与从系统热变化与环境熵变直接的对应关系得到A和G的一致是巧合么？要是环境不满足无限大与等温呢？

```
不是巧合。勒让德变换让公式里的变量S和V换成T和P，他们在任何条件下都成立。而恒温条件下，热力学第二定律保证了A和G从系统热变化与环境熵变直接的对应关系，dS环=-dq系统T。如果环境不满足系统无限大和等温，因为A和G判据的前提条件不满足，所以不能使用这个判据。
```
