[[统计力学]]
# 1. 等概率假定
- **条件**：所有满足系统边界条件的微观状态，出现概率相等
- **性质**：这是统计力学最基础的 **公理级假设**，不依赖于具体系统类型，是整个理论大厦的地基喵。

# 2. 遍历态假定
- **条件**：时间尺度必须 **足够长**
- **内容**：系统无论从哪个初始状态出发，最终一定会遍历所有微观状态，且在每一个状态上停留的时间相等。

# 3. 玻尔兹曼熵公式 $S = k\ln\omega$
- **条件**：等概率原理成立时有效
- **适用系综**：微正则系综（孤立系统，$N, U, V$ 固定）
- **本质**：这是将 **微观状态数的对数** 与宏观热力学量 **熵** 联系起来的桥梁，是一条基本假设喵。

# 4. 熵增加原理

| 系统类型              | 熵 $\Delta S$ 是否必须 ≥ 0？ | 正确表述                                           |
| ----------------- | :--------------------: | ---------------------------------------------- |
| **孤立系统**（或绝热封闭系统） |           必须           | $\Delta S \geq 0$，自发 > 0，平衡 = 0                |
| **非孤立系统**         |          可升可降          | **唯一普遍要求是**：系统内部熵产生 $d_iS \ge 0$（热力学第二定律最核心形式） |

> 关键点：笔记中特别强调，**系统熵可升可降**，但内部熵产生不得为负。对于孤立系统，因为没有外界交换，$dS = d_iS \ge 0$ 才直接成立。

# 5. 玻尔兹曼分布

- **前提条件**：系统与 **恒温热库** 接触并达到平衡（对应正则系综）
- **成立时的性质**：
  - 系统分子在不同能级上满足 $P \propto e^{-\varepsilon/kT}$
  - 给定温度下，玻尔兹曼分布是 **最可几分布**
  - 对孤立系统，玻尔兹曼分布对应于 **熵最大** 的宏观状态
  - 是 **严格定域的指数分布**

# 6. 能量均分原理

- **前提**：**经典统计力学**的推论（量子效应可忽略时）
- **具体条件**：哈密顿量中某个自由度以 **平方项** 形式出现（如 $\frac{p_i^2}{2m}$ 或 $\frac{1}{2}kq_i^2$），则该自由度在热平衡时平均能量 $= \frac{1}{2}kT$
- **失效情况**：
  - 转动：$T \ll \Theta_r$ 时转动自由度被冻结，不符合均分
  - 振动：$T \ll \Theta_v$ 时振动能级不开放，不符合均分
  - 电子/核运动：通常都不开放

# 7. 负温度

必须 **同时满足** 两个条件喵：
1. 系统能级存在 **有限上限**（不能无限延伸）
2. 系统处于 **非平衡激发态**，高能级粒子数 > 低能级粒子数（粒子数反转）

典型例子：核自旋系统的粒子数反转。

# 8. 吉布斯熵 $S = -kN\sum p_i\ln p_i$

- **适用条件**：**任意系统，甚至非平衡态**
- **核心假设**：**无**——$p_i$ 可以是符合任意条件的概率分布
- **与 Boltzmann 熵的关系**：在等概率条件下，Gibbs 熵退化为 Boltzmann 熵；在玻尔兹曼分布下（$p_i = e^{-\varepsilon_i/kT}/q$），Gibbs 熵 = Boltzmann 熵

# 9. 配分函数中各运动形式的适用条件

| 运动形式 | 适用条件 | 积分近似的条件 |
|----------|----------|:---:|
| **平动** | 仅适用于 **理想气体**（液体/固体无分子平动） | 能级间距极小，常温下可积分 |
| **转动** | 刚性转子模型（双原子），需除以对称数 $\sigma$ | $T \gg \Theta_r$（室温通常满足）；$T \ll \Theta_r$ 则冻结 |
| **振动** | 一维谐振子模型，通常温度下处于基态 | $T \gg \Theta_v$ 时开放，$T \ll \Theta_v$ 时 $q_v \approx 1$ |
| **电子** | 假设全部处于 **基态** | — |
| **核运动** | 假设全部处于 **基态** | — |
