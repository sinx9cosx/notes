### 第一部分：填空题 & 选择题（按概率从高到低）

#### 🔥🔥🔥 必考级（出题老师的最爱，共6组）

1. **精密度 vs 准确度（第1章）**
   - **考眼**：**精密度（Precision）** 看标准偏差（SD/RSD），衡量**重复性**；**准确度（Accuracy）** 看与真值的差异，衡量**系统误差**。
   - **挖坑**：如果打靶子弹全在一个点但偏离靶心——**精密度高，准确度低**。

2. **LOD、LOQ、LOL（第1章）**
   - **考眼**：**LOD（检出限）= 3倍信噪比**（能定性，不能定量）；**LOQ（定量限）= 10倍信噪比**。信号在LOD和LOQ之间只能判断“有”，不能报准确浓度。

3. **朗伯-比尔定律的最佳读数范围（第9章）**
   - **考眼**：**吸光度 A = 0.434**（即透光率 **T = 36.8%**）时，浓度测量的**相对误差最小**。
   - **挖坑**：问“A控制在什么范围误差较小？” 答 **0.2 ~ 0.8**（这是操作范围，最佳点是0.434）。

4. **荧光光谱仪的特殊光路（第8章）**
   - **考眼**：荧光仪的**检测器与激发光源成 90°（垂直）**。
   - **原因**：为了**避免激发光源的透射光直接进入检测器**干扰荧光测定。

5. **原子吸收（AAS）为什么用“锐线光源”（第4章）**
   - **考眼**：必须满足 **Δνₑ（发射线宽度） << Δνₐ（吸收线宽度）**。
   - **原因**：因为原子吸收线极窄（积分吸收测不了），只能用**峰值吸收**代替积分吸收，所以必须用**空心阴极灯（HCL）**这种锐线光源。

6. **核磁共振（NMR）的参比物（第12章）**
   - **考眼**：**TMS（四甲基硅烷）**，化学位移 **δ = 0**。
   - **优点挖空**：**12个H化学环境完全相同**（单峰）；**屏蔽强**（处于高场，绝大多数峰在它左边）。

#### 🔥 高频级（极大概率出2-3道，共8组）

7. **紫外（UV）的溶剂效应（第9章）**——**极爱考！**
   - **考眼**：极性溶剂增大时，**π→π* 跃迁 → 红移（长波）**；**n→π* 跃迁 → 蓝移（短波）**。
   - **口诀**：极性推π下红海，推n上蓝天。

8. **三种校正方法的适用场景（第1章）**
   - **标准曲线法**：样品组成**简单**，无干扰。
   - **标准加入法**：样品**基体复杂**（有干扰），能消除基体效应。
   - **内标法**：**仪器波动**或**进样量不准**时用（看比值）。

9. **原子发射（AES）中的“自吸与自蚀”（第3章）**
   - **考眼**：浓度增大 → 产生**自吸**（谱线中心变弱）；严重时 → **自蚀**（谱线中心完全被吸收，像裂开）。
   - **后果**：标准曲线在高浓度区**弯向浓度轴**（线性范围变窄）。

10. **红外（IR）产生红外活性的条件（第10章）**
    - **考眼**：分子振动时必须伴有**偶极矩（dipole moment）的变化**。
    - **挖坑**：同核双原子分子（如O₂、N₂）振动时偶极矩不变 → **非红外活性**。

11. **分子荧光与磷光的本质区别（第8章）**
    - **考眼**：荧光是**单重态→基态（S₁→S₀）**，寿命短（10⁻⁸ s），关灯即灭；磷光是**三重态→基态（T₁→S₀）**，寿命长（可达秒级），关灯还亮。
    - **重原子效应（I、Br）**：增强磷光，猝灭荧光。

12. **火焰原子化 vs 石墨炉原子化（第4章）**——**优缺点必有一空**
    - **火焰**：优点→**快、精密度高（RSD<1%）**；缺点→**灵敏度低**（原子化效率低，停留时间短）。
    - **石墨炉**：优点→**灵敏度极高**（可测10⁻¹⁴ g）；缺点→**精密度差（RSD 3~5%）**、**慢**。

13. **化学干扰的消除方法（第4章）**
    - **释放剂**（如加锶盐，把待测元素从干扰物中释放出来）；**保护剂**（如加EDTA，把待测元素包起来）；**消电离剂**（加CsCl/KCl，抑制电离干扰）。

14. **紫外-可见的电子跃迁类型（第9章）**
    - **挖空**：**σ→σ*** 在**真空紫外区**（常用作溶剂）；进入UV-Vis区的主要是 **π→π*** 和 **n→π***。
    - **芳香族特有带**：**B带**（精细结构）和 **E带**。

#### 📖 保底级（以防出偏题，看一眼留印象）

15. **ICP光源用氩气的优点**（第3章）：惰性氛围（化学干扰小）、温度高、趋肤效应（自吸小）。
16. **红外指纹区与官能团区**（第10章）：**4000~1300 cm⁻¹** 为官能团区（人脸），**1300~400 cm⁻¹** 为指纹区（指纹，独一无二）。
17. **NMR裂分规律（n+1规律）**（第12章）：仅对 **I=1/2** 的核（如¹H），与n个等价H偶合，裂分为 **n+1** 重峰。
18. **偏离朗伯-比尔定律的因素**（第2章）：**样品因素**（浓度过高、化学变化、折射率）；**仪器因素**（非单色光、杂散光、非平行光）。

#### ✅ 简答押题1（已知必考）：氢谱中影响化学位移的主要因素
**如果你只背一道简答，就背这个完美框架（考场上直接默写5点）：**

1. **诱导效应**：连**吸电子基**（-O, -X）→ 去屏蔽 → **低场（δ变大）**；连**给电子基** → 屏蔽 → **高场（δ变小）**。
2. **共轭效应**：**p-π共轭**（如苯胺）→ 电子云密度↑ → **高场**；**π-π共轭**（如苯甲醛）→ 电子云密度↓ → **低场**。
3. **磁各向异性效应**：苯环（π电子环流）→ 外围H**去屏蔽（低场）**，上下方**屏蔽（高场）**；双键、三键同理有各自的空间屏蔽区。
4. **氢键效应**：形成氢键（如-OH）→ 去屏蔽 → **低场（δ变大）**；稀释后氢键减弱，峰向**高场**移动。
5. **溶剂效应**：溶剂极性改变或改用苯作溶剂，会引起化学位移变化。

#### ✅ 简答押题2：为什么原子吸收光谱法（AAS）必须使用锐线光源？（对应计算里的AAS基础）
**答题框架（3句话拿满分）：**
1. 原子吸收线的宽度极窄（约10⁻³ nm），单色器无法获得如此窄的入射光。
2. 理论上应采用积分吸收（吸光度与吸收系数积分成正比），但积分吸收难以测量。
3. 因此采用**峰值吸收**代替积分吸收。**前提条件**是：光源发射线的**中心频率**与吸收线完全一致，且**发射线半宽度远小于吸收线半宽度**（Δνₑ << Δνₐ）。空心阴极灯恰好满足此条件。

### 第三部分：五道计算大题的“考点急救包”

既然大题固定，我把每个计算题的**必用公式**和**易错单位**给你列出来，明天动笔前先看这个：

1. **误差计算**：求 **标准偏差（s）**、**相对标准偏差（RSD%）**。注意区分 **s（样本标准差）** 和 **σ（总体标准差）**，公式里分母是 **n-1** 还是 **n**（样本是n-1）。
2. **检出限（LOD）**：**LOD = 3S_b / m**（S_b是空白信号的标准偏差，m是校准曲线的斜率）。记住**信噪比3:1**对应LOD，**10:1**对应LOQ。
3. **紫外吸收（UV）**：朗伯-比尔 **A = κbc**。常考**最大吸收波长（λmax）选择原则**（选吸收大、干扰小的波长），或给透光率T反算A（**A = -lgT**）。
4. **核磁共振（NMR）**：大概率给一个结构式，让你算**裂分数目（n+1）**和**积分面积比（氢数比）**。比如乙醇 CH₃CH₂OH：CH₃裂分为3重峰（邻接CH₂），CH₂裂分为4重峰（邻接CH₃），积分比3:2:1。
5. **红外解谱（IR）**：必给几个关键峰，让你推结构。看到 **~3300 cm⁻¹ 宽峰** → **醇/酚（O-H）**；**~1700 cm⁻¹ 强峰** → **羰基（C=O）**；**~1600 & 1500 cm⁻¹** → **苯环骨架**；**~2200 cm⁻¹ 尖峰** → **氰基（C≡N）或炔烃（C≡C）**。
