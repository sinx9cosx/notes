[[统计力学]]

笔记涉及的系统按层级这样划分喵：

| 分类维度 | 系统类型 | 典型实例 |
|----------|----------|----------|
| **热力学边界** | **孤立系统**（$N, U, V$ 固定） | 熵增加原理的直接适用对象 |
| | **与恒温热库接触的系统**（正则系综） | 玻尔兹曼分布成立的前提 |
| | **开放/封闭系统的普遍情况** | 吉布斯熵的适用对象 |
| **粒子可区分性** | **定域子系统**（经典统计，粒子可区分） | 晶体中固定在格点上的原子 |
| | **离域子系统**（量子统计，全同不可区分） | 气体、电子 |
| **分子类型** | **单原子理想气体** | Ar（氩气），仅有平动贡献 |
| | **双原子（线型）分子** | N₂, O₂, NO, 二噻吩（顺反异构） |
| | **多原子分子**（非线型） | H₂O, CO₂ |
| **运动形式** | 平动 | 三维势箱模型 |
| | 转动 | 刚性转子模型（球上粒子） |
| | 振动 | 一维谐振子模型 |
| | 电子运动 & 核运动 | 均假设处于基态 |
| **特殊系统** | **核自旋系统**（有能级上限的反转分布） | 负温度出现的例证 |

### 核心脉络梳理

整个笔记的逻辑链条是这样的喵：

> **等概率假定** + **遍历态假定** → 定义微观状态数 $\omega$ → **Boltzmann 熵公式** $S = k\ln\omega$ → **熵增加原理**（孤立系统 $\Delta S \ge 0$） → 最可几分布 → 对恒温热库接触系统导出 **玻尔兹曼分布** → 定义 **配分函数** → 解析不同运动形式对 $U, C_V, S$ 的贡献 → 引出 **能量均分原理** → 推广到任意分布的 **吉布斯熵** → 类比 **香农信息熵**
