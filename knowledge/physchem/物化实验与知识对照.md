# 实验与知识对照总览

本学期7个物理化学实验与热力学、统计力学、量子力学三门课程知识存在深浅不一的对应关系。以下按实验逐一对照，标注笔记中已学的知识点与实验原理的交叉之处。

> [!note]
> 整体规律：所有实验均以**热力学**为核心理论基础；**统计力学**为若干实验（平衡常数、反应焓）提供了微观解释；**量子力学**作为统计力学的上游知识，提供能级模型（势阱、谐振子、刚性转子），不直接对应任何一个实验，但间接通过配分函数→热力学函数这条路径支撑了所有涉及分子能级的计算。

# 实验一：凝固点降低法测定摩尔质量

## 实验原理

稀溶液中，当溶质与溶剂不生成固态溶液时，溶液凝固析出纯固态溶剂的温度低于纯溶剂的凝固点。凝固点降低值 $\Delta T_f$ 与溶质的质量摩尔浓度 $b_B$ 成正比：

$$\Delta T_f = K_f \cdot b_B$$

通过测量 $\Delta T_f$，结合已知的 $K_f$（凝固点降低常数），可计算溶质的摩尔质量。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| 凝固点降低是稀溶液的依数性 | [[热力学#化学势]] | ★★★ 核心 |
| 凝固点降低常数的热力学推导 | [[统计力学#玻尔兹曼分布]] | ★★ 微观解释 |
| 稀溶液极限行为 | [[热力学#热力学基本方程]] | ★ 辅助 |

### 详细解释

1. **化学势与相平衡**（[[热力学#化学势]]，核心对应）
   - 凝固点降低的**根本驱动力**是溶质的加入降低了溶剂在液相中的化学势：$\mu_A(l) = \mu_A^*(l) + RT\ln x_A$（$x_A < 1$ 时 $\ln x_A < 0$，化学势降低）
   - 而纯固态溶剂的化学势 $\mu_A^*(s)$ 不变。平衡条件 $\mu_A(l) = \mu_A(s)$ 被打破，必须降低温度使液相化学势回升至与固相相等，故凝固点降低
   - 由此可以完整推导 $\Delta T_f = K_f b_B$，其中 $K_f = \frac{R T_f^{*2} M_A}{\Delta_{fus}H_m^*}$ 完全由溶剂性质决定

2. **玻尔兹曼分布视角**（[[统计力学#玻尔兹曼分布]]）
   - 溶质粒子的存在使溶剂的微观状态数发生变化，进而影响溶剂的熵。凝固点降低本质上是一个熵驱动的依数现象
   - 从 $S = k\ln\omega$ 理解：溶质分子的存在增加了液相的可及微观状态数，降低了液相→固相的转变驱动力

3. **热力学第一定律的边界**（[[热力学#热力学第一定律]]）
   - 实验要求 $K_f$ 公式在**稀溶液**条件下成立——浓度过高时溶液偏离理想行为，化学势公式 $\mu = \mu^* + RT\ln x$ 不再精确成立
   - 这与笔记中"理想气体/理想溶液是热力学推导的共同起点"一致

> [!warning] 笔记未直接覆盖
> 笔记中的化学势部分聚焦于**理想气体的化学势** $\mu = \mu^\ominus + RT\ln(p/p^\ominus)$，未展开讨论液态溶液中化学势的表达式 $\mu_A = \mu_A^* + RT\ln x_A$。但两者的形式完全类似：理想气体以 $p/p^\ominus$ 为活度，理想溶液以摩尔分数 $x$ 为活度。

# 实验二：恒温槽的调节及黏度测定

## 实验原理

恒温槽通过感温元件、控温元件、加热元件三者配合，实现温度的闭环控制。黏度测定则基于 Poiseuille 定律，采用乌氏黏度计以相对法（与参考液体比较）测定被测液体的绝对黏度。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| 温度的定义与测量 | [[热力学#热力学第零定律]] | ★★ 理论基础 |
| 温度的热力学意义 | [[统计力学#温度]] | ★★ 深化理解 |
| PID控制原理（比例-积分-微分） | — | ☆ 工程知识，笔记未涉及 |
| Poiseuille定律与黏度 | — | ☆ 流体力学，笔记未涉及 |

### 详细解释

1. **热力学第零定律**（[[热力学#热力学第零定律]]）
   - 恒温槽能"恒温"的前提是温度作为一个**状态函数**存在——热力学第零定律保证了温度可以被定义和测量
   - 笔记指出第零定律的两条推论："温度这个状态函数的存在"和"比较温度的方法"，正是恒温槽设计和使用的理论根基

2. **温度的统计力学诠释**（[[统计力学#温度]]）
   - 统计力学中 $T = (\partial U/\partial S)_{V,N}$，即温度是"系统增加熵所耗费的能量"
   - 恒温槽的恒温原理可以用统计语言重新表述：恒温槽维持系统与热浴之间的 $\partial S/\partial U$ 相等，阻止热量在二者间的净流动
   - "从低温到高温的过程，系统总熵减小，不会自发发生"——这解释了为什么恒温槽必须主动加热来维持高于环境温度的恒温状态

3. **黏度与分子间作用力**
   - 黏度本身属于**传递性质**（transport property），笔记中的热力学三大定律和统计力学配分函数理论均未专门讨论传递性质（黏度、热导、扩散）
   - 但从分子层面，黏度反映了分子间相互作用势能——乙醇的黏度比水小，与氢键网络强度有关
   - 温度对黏度的影响（温度升高→黏度降低）可以从玻尔兹曼分布理解：温度升高使更多分子获得足以克服分子间势垒的能量

> [!warning] 关联较弱
> 本实验的黏度测定部分与三门课程的笔记关联较弱——笔记未涵盖传递性质的理论。恒温槽部分的热力学关联相对扎实。

# 实验三：液体饱和蒸气压的测定

## 实验原理

在一定温度下，纯液体与其蒸气达到平衡时的压力即为饱和蒸气压。通过动态法测定不同外压下乙醇的沸点，间接得到不同温度下的饱和蒸气压。利用克劳修斯-克拉贝龙（Clausius-Clapeyron）方程的积分形式：

$$\ln\frac{p}{[p]} = -\frac{\Delta_{vap}H_m^*}{RT} + C$$

以 $\ln p$ 对 $1/T$ 作图，由斜率求得摩尔蒸发焓 $\Delta_{vap}H_m^*$。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| Clausius-Clapeyron 方程推导 | [[热力学#热力学基本方程]] | ★★★ 核心 |
| 相平衡条件（$\mu$ 相等） | [[热力学#化学势]] | ★★★ 核心 |
| 理想气体近似（$V_g \gg V_l$） | [[热力学#热一对理想气体的应用]] | ★★ 关键近似 |
| Maxwell 关系式应用 | [[热力学#Maxwell 关系式]] | ★★ 推导工具 |
| 统计力学与蒸气压力 | [[统计力学#配分函数]]、[[统计力学#辅助热力学函数与配分函数的关系]] | ★ 微观解释 |

### 详细解释

1. **Clausius-Clapeyron 方程的热力学推导**
   - 起点：两相平衡时化学势相等 $\mu_l(T,p) = \mu_g(T,p)$（[[热力学#化学势]]）
   - 由于 $\mathrm{d}\mu = -\bar{S}\mathrm{d}T + \bar{V}\mathrm{d}p$（[[热力学#热力学基本方程]]），沿相平衡线移动时 $\mathrm{d}\mu_l = \mathrm{d}\mu_g$，即：
     $$-\bar{S}_l\mathrm{d}T + \bar{V}_l\mathrm{d}p = -\bar{S}_g\mathrm{d}T + \bar{V}_g\mathrm{d}p$$
   - 整理得 Clapeyron 方程：$\frac{\mathrm{d}p}{\mathrm{d}T} = \frac{\Delta_{vap}S_m}{\Delta_{vap}V_m} = \frac{\Delta_{vap}H_m}{T\Delta_{vap}V_m}$

2. **从 Clapeyron 到 Clausius-Clapeyron——三个关键近似**
   - ① $V_g \gg V_l$，故 $\Delta_{vap}V_m \approx V_g$（笔记[[热力学#热一对理想气体的应用]]：理想气体 $V = nRT/p$）
   - ② 蒸气视为理想气体：$V_g = RT/p$
   - ③ 温度间隔较小时 $\Delta_{vap}H_m$ 视作常数
   - 代入即得 $\frac{\mathrm{d}\ln p}{\mathrm{d}T} = \frac{\Delta_{vap}H_m}{RT^2}$，积分即得实验所用形式
   - **本实验的主要系统误差来源**——蒸气非理想性——正是由于近似②在乙醇分子间存在氢键时不够精确

3. **统计力学视角**
   - 蒸发焓本质上是克服液相中分子间作用力（氢键、范德华力）所需的能量
   - 平动配分函数 $q_t \propto V$（[[统计力学#平动配分函数]]），气相的 $V$ 远大于液相，平动熵剧增是蒸发过程的熵驱动来源
   - 标准摩尔吉布斯自由能函数 $\frac{G_{m,T}^\ominus - U_{0,m}}{T}$（[[统计力学#理想气体的标准摩尔吉布斯自由能函数]]）可通过配分函数计算，由此也可以得到蒸发过程的 $\Delta G$

4. **Maxwell 关系式**（[[热力学#Maxwell 关系式]]）
   - $(\partial S/\partial V)_T = (\partial p/\partial T)_V$ 等可以用于关联实验中不易直接测量的量（如 $\Delta_{vap}S_m$）与易测量（$p$、$T$）

# 实验四：平衡常数的测定

## 实验原理

氨基甲酸铵分解反应 $\mathrm{NH_2COONH_4(s)} \rightleftharpoons 2\mathrm{NH_3(g)} + \mathrm{CO_2(g)}$ 在密闭系统中达平衡。由计量关系 $p(\mathrm{NH_3}) = 2p(\mathrm{CO_2})$，系统总压 $p_{总} = \frac{3}{2}p(\mathrm{NH_3})$，标准平衡常数：

$$K^\ominus = \left(\frac{p(\mathrm{NH_3})}{p^\ominus}\right)^2 \cdot \frac{p(\mathrm{CO_2})}{p^\ominus} = \frac{4}{27}\left(\frac{p_{总}}{p^\ominus}\right)^3$$

利用 van't Hoff 方程 $\frac{\mathrm{d}\ln K^\ominus}{\mathrm{d}T} = \frac{\Delta_r H_m^\ominus}{RT^2}$，以 $\ln K^\ominus$ 对 $1/T$ 作图，由斜率和截距求得 $\Delta_r H_m^\ominus$ 和 $\Delta_r S_m^\ominus$。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| 标准平衡常数 $K^\ominus$ | [[热力学#化学势]] | ★★★ 核心 |
| $\Delta_r G_m^\ominus = -RT\ln K^\ominus$ | [[热力学#自发过程的判据]] | ★★★ 核心 |
| van't Hoff 方程 | [[热力学#温度对化学平衡的影响]] | ★★★ 核心 |
| Gibbs-Helmholtz 方程 | [[热力学#温度对化学平衡的影响]] | ★★★ 核心 |
| 标准摩尔吉布斯自由能函数 | [[统计力学#理想气体的标准摩尔吉布斯自由能函数]] | ★★ 微观计算 |
| 标准摩尔焓函数 | [[统计力学#理想气体的标准摩尔焓函数]] | ★★ 微观计算 |

### 详细解释

1. **化学平衡的热力学条件**（[[热力学#化学势]]）
   - 笔记明确指出："当封闭系统达到平衡：$\sum_B \mu_B\mathrm{d}n_B = 0$"
   - 对于本实验的多相反应：$\mu(\mathrm{NH_2COONH_4},s) = 2\mu(\mathrm{NH_3},g) + \mu(\mathrm{CO_2},g)$
   - 固相化学势近似为常数（$\mu_s \approx \mu_s^\ominus$），气相化学势为 $\mu_i = \mu_i^\ominus + RT\ln(p_i/p^\ominus)$
   - 代入平衡条件即得到 $K^\ominus$ 的表达式

2. **Gibbs-Helmholtz 方程与 van't Hoff 方程**（[[热力学#温度对化学平衡的影响]]）
   - 笔记从 $\left(\frac{\partial G}{\partial T}\right)_p = -S$ 出发，严格推导了 Gibbs-Helmholtz 方程：
     $$\left(\frac{\partial (G/T)}{\partial T}\right)_p = -\frac{H}{T^2}$$
   - 应用于化学反应（$\Delta_r G_m^\ominus = -RT\ln K^\ominus$），得到 van't Hoff 方程：
     $$\frac{\mathrm{d}\ln K^\ominus}{\mathrm{d}T} = \frac{\Delta_r H_m^\ominus}{RT^2}$$
   - **$\Delta_r H_m^\ominus$ 在温度范围不大时视为常数**，积分得 $\ln K^\ominus = -\frac{\Delta_r H_m^\ominus}{RT} + \frac{\Delta_r S_m^\ominus}{R}$，这正是实验数据处理所用的线性形式

3. **相律与本实验的自由度分析**
   - 笔记未直接讲相律，但可以从化学势部分推导
   - 本实验：$C = 3 - 1 = 2$（一个化学反应限制了组成），$P = 3$（固+两种气），$f = C - P + 2 = 1$——只有一个自由度，温度确定了，平衡压力就唯一确定

4. **统计力学计算 $K^\ominus$**（[[统计力学#理想气体的标准摩尔吉布斯自由能函数]]）
   - 笔记中明确指出："标准摩尔吉布斯自由能函数和标准摩尔焓函数是利用统计热力学计算理想气体化学反应平衡常数的基础数据"
   - 通过配分函数 $q^0 = q_t^0 q_r^0 q_v^0$ 计算 $\frac{G_{m,T}^\ominus - U_{0,m}}{T} = -R\ln\frac{q^0}{N}$
   - 这是实验热化学与统计力学的**核心连接点**——实验中测得的 $K^\ominus$、$\Delta_r H_m^\ominus$ 原则上都可以通过配分函数从光谱数据独立计算

# 实验五：反应焓的测定

## 实验原理

在绝热、恒压条件下，利用简单量热计测量化学反应（$\mathrm{ZnO(s)} + 2\mathrm{HCl(aq)} \to \mathrm{ZnCl_2(aq)} + \mathrm{H_2O(l)}$）的温度变化。根据热力学第一定律：

$$\Delta H = Q_p = 0 \quad (\text{绝热恒压})$$

用 KCl 溶解焓标定量热计热容 $K$ 后，由 $\Delta t$ 计算反应焓。实验还使用 Hess 定律（状态函数法）设计路径计算理论值。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| $\Delta H = Q_p$ | [[热力学#热力学第一定律]] | ★★★ 核心 |
| 焓的定义 $H = U + pV$ | [[热力学#热力学第一定律]] | ★★★ 核心 |
| Hess 定律（状态函数法） | [[热力学#自发过程的判据]] | ★★★ 核心 |
| 热容 $C_p(T)$ | [[热力学#热容]] | ★★ 基础 |
| 积分溶解焓与微分溶解焓 | [[热力学#化学势]] | ★★ 关联 |
| 溶解过程的熵驱动 | [[统计力学#熵与配分函数的关系]] | ★ 微观解释 |

### 详细解释

1. **热力学第一定律与焓**（[[热力学#热力学第一定律]]）
   - 笔记中核心公式：$\Delta U = Q + W$，恒压条件下 $Q_p = \Delta H$
   - 焓的定义：$H \equiv U + pV$，是处理恒压过程最便捷的状态函数
   - 本实验的绝热恒压条件：$Q_p = 0$，即系统总焓不变：$\Delta H_{总} = \Delta_r H + K\Delta t = 0$
   - 由此 $\Delta_r H = -K\Delta t$，量热计热容 $K$ 的标定利用了同一个原理

2. **Hess 定律——状态函数的路径无关性**
   - 笔记中强调热力学状态函数的自然变量和 Legendre 变换（[[热力学#构造辅助热力学函数]]），其推论就是：**状态函数的变化只取决于始末态，与路径无关**
   - Hess 定律正是这个推论在化学反应焓变中的具体体现
   - 本实验设计 $\mathrm{ZnO(s)} \to \mathrm{ZnCl_2(aq)}$ 的替代路径：$\mathrm{ZnO(s)} \to \mathrm{ZnCl_2(s)} \to \mathrm{ZnCl_2(aq)}$，利用了已知的生成焓和溶解焓数据
   - 赫尔姆霍兹自由能 $A$ 和吉布斯自由能 $G$ 作为 Legendre 变换构造出的新状态函数，同样具有路径无关性

3. **热容与温度的函数关系**（[[热力学#热容]]）
   - 笔记定义：$C_p(T) = \left(\frac{\partial H}{\partial T}\right)_p$，$\Delta H = \int C_p\mathrm{d}T$
   - 量热计热容 $K$ 本质上是整个量热系统的 $C_p$（包括保温瓶、溶液、搅拌器、测温探头等所有参与热交换的部分）
   - 标定 $K$ 时需要使用 KCl 溶解后的**实际温度**去查对应的积分溶解焓，因为 $C_p$ 本身是温度的函数

4. **统计力学中的能量均分**（[[统计力学#能量均分原理]]）
   - 系统热容 $C_V$ 可以通过能量均分原理和配分函数计算：$C_{V,t} = \frac{3}{2}R$（平动）、$C_{V,r} = R$（转动，双原子）
   - 这些微观贡献加和构成了量热实验中所有宏观热容的分子基础

# 实验六：二组分凝聚系统相图

## 实验原理

采用**热分析法**测绘 Sn-Pb 二组分凝聚系统的冷却曲线（步冷曲线）。熔融系统在冷却过程中发生相变时，因相变热（凝固潜热）的释放，冷却曲线上出现转折点或水平段。将不同组成样品的相变温度汇总，即可绘制温度-组成相图。低共熔组成（61.9% Sn）的冷却曲线与纯物质相似——仅有单一水平平台。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| 相平衡的化学势判据 | [[热力学#化学势]] | ★★★ 核心 |
| 凝聚系统相律 $f = C-P+1$ | [[热力学#热力学基本方程]] | ★★★ 核心 |
| 自由度的热力学含义 | [[热力学#自发过程的判据]] | ★★ 基础 |
| 相变热与熵变 | [[热力学#熵与克劳修斯不等式]] | ★★ 关联 |
| 固溶体形成的热力学 | [[热力学#热力学方程的应用]] | ★ 关联 |

### 详细解释

1. **相律**（$f = C - P + 1$）
   - 笔记中虽未直接写入"相律"这个术语，但其理论基础——化学势平衡条件 $\sum_B \mu_B\mathrm{d}n_B = 0$——已完整覆盖（[[热力学#化学势]]）
   - 对于凝聚系统（压力恒定），相律简化为 $f = C - P + 1$
   - 纯 Pb 凝固时（$C=1$, $P=2$）→ $f=0$ → 温度恒定 → 冷却曲线上的水平段
   - 30% Sn 初晶析出时（$C=2$, $P=2$）→ $f=1$ → 温度可变化但斜率改变 → 冷却曲线上的转折点
   - 低共熔转变时（$C=2$, $P=3$）→ $f=0$ → 温度恒定 → 冷却曲线上的水平段

2. **化学势与相平衡**（[[热力学#化学势]]）
   - 笔记判断依据：$\sum_B \mu_B\mathrm{d}n_B \leq 0$（$W' = 0$），平衡时取等
   - 低共熔点处：$\mu_{\mathrm{Sn}}(l) = \mu_{\mathrm{Sn}}(\alpha) = \mu_{\mathrm{Sn}}(\beta)$，$\mu_{\mathrm{Pb}}(l) = \mu_{\mathrm{Pb}}(\alpha) = \mu_{\mathrm{Pb}}(\beta)$
   - 三个相（$l, \alpha, \beta$）中每个组分的化学势相等，决定了低共熔温度的**唯一性**——无论初始总组成如何，低共熔温度相同——这是实验中不同组成样品平台温度一致的热力学根源

3. **相变热与熵变**（[[热力学#熵与克劳修斯不等式]]）
   - 凝固时：$\Delta S = \frac{Q_r}{T} = -\frac{\Delta_{fus}H}{T_f} < 0$（系统向环境放热，熵降低）
   - 但环境吸热 $\Delta S_{环} > 0$，且 $\Delta S_{总} \geq 0$（凝固是热力学允许的自发过程）
   - 冷却曲线上水平段的**长度**正比于相变焓 ÷ 散热速率——这与 $\Delta S = \int \delta Q_r/T$ 中 $Q_r$ 的量级直接相关

4. **冷却曲线斜率变化的物理含义**
   - 斜率变化 = 热容 $C_p$ 的有效值改变（[[热力学#热容]]）
   - 固态+液态共存时，表观热容 $C_p^{eff} = C_p + \frac{\mathrm{d}Q_{凝固}}{\mathrm{d}T}$，显著大于纯液态的 $C_p$
   - 因此冷却曲线在析晶开始后斜率绝对值减小（降温变慢）

# 实验七：二组分液相完全互溶系统的沸点-组成图

## 实验原理

在恒定压力下，测定乙醇-正丙醇系统气液平衡时的沸点及平衡两相的组成（通过折射率间接确定）。乙醇-正丙醇为紧邻同系物，蒸馏曲线属于第一类——沸点始终介于两纯组分沸点之间，无恒沸点。

## 知识点对照

| 实验涉及 | 对应笔记 | 关联程度 |
|----------|----------|----------|
| 气液平衡的化学势条件 | [[热力学#化学势]] | ★★★ 核心 |
| 相律 $f = C-P+2$ | [[热力学#热力学基本方程]] | ★★★ 核心 |
| 理想气体化学势 $\mu = \mu^\ominus + RT\ln(p/p^\ominus)$ | [[热力学#理想气体化学势]] | ★★ 关键公式 |
| Raoult 定律的热力学基础 | [[热力学#化学势]] | ★★ 关联 |
| 折射率与组成的关系 | — | ☆ 物理方法，笔记未涉及 |

### 详细解释

1. **气液平衡的热力学条件**（[[热力学#化学势]]）
   - 对于每一个组分 $i$：$\mu_i(l, T, p, x_i) = \mu_i(g, T, p, y_i)$
   - 笔记中理想气体化学势公式 $\mu^* = \mu^\ominus + RT\ln(p/p^\ominus)$（[[热力学#理想气体化学势]]），对气相适用
   - 液相：若近似为理想溶液，$\mu_i(l) = \mu_i^*(l) + RT\ln x_i$
   - 两相结合得 $p_i = x_i \cdot p_i^*$（Raoult 定律），这是解释蒸馏曲线形状的微观基础

2. **相律分析**（$f = C - P + 2$）
   - 二组分气液两相系统：$C = 2$, $P = 2$，一般 $f = 2$
   - 恒压条件下 $f = 1$——沸点与组成一一对应，T-x 图上的每一条线（液相线/气相线）都有确定的物理含义
   - 纯物质沸点：$C = 1$, $P = 2$，恒压下 $f = 0$——沸点固定值，与笔记中对纯物质状态变量自由度的讨论一致

3. **沸点介于两纯组分之间的热力学原因**
   - 乙醇-正丙醇作为紧邻同系物，分子间相互作用（氢键+色散力）接近
   - 混合 Gibbs 自由能 $\Delta_{mix}G = RT(x_A\ln x_A + x_B\ln x_B) < 0$（熵驱动混合）
   - $\Delta_{mix}H \approx 0$（理想溶液近似）→ 无恒沸点
   - 对比：若 $\Delta_{mix}H$ 显著不为零（如乙醇-水系统的强氢键），可能出现最高或最低恒沸点

4. **与实验一（凝固点降低）的共通性**
   - 实验一：液相化学势降低→凝固点降低；实验七：气相化学势等于液相化学势→沸点确定
   - 两者的核心物理都是**化学势相等决定相平衡**（[[热力学#化学势]]），区别仅在于所涉及的相不同（固-液 vs 气-液）
