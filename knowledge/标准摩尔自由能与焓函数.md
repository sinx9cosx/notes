标准摩尔吉布斯自由能函数和标准摩尔焓函数是利用统计热力学计算理想气体化学反应平衡常数的基础数据。

## 理想气体的标准摩尔吉布斯自由能函数

吉布斯函数为

$$G = -NkT\ln\frac{q}{N} - NkT + NkTV\left(\frac{\partial \ln q}{\partial V}\right)_T$$

由于 $\left(\partial \ln q/\partial V\right)_T = V^{-1}$，$p = p^\ominus = 10^5\ \mathrm{Pa}$ 时，理想气体的标准摩尔吉布斯函数：

$$G_{m,T}^\ominus = -RT\ln\frac{q}{N}$$

$$G_{m,T}^\ominus = -RT\ln\frac{q^0}{N} + U_{0,m}$$

$$\frac{G_{m,T}^\ominus - U_{0,m}}{T} = -R\ln\frac{q^0}{N}$$

$\left(G_{m,T}^\ominus - U_{0,m}\right)/T$ 称为**标准摩尔吉布斯自由能函数**，它可以通过光谱数据计算得到，是一种基础数据。由于 $0\ \mathrm{K}$ 时物质的热力学能与焓近似相等，故标准摩尔吉布斯自由能函数也可表示为

$$\frac{G_{m,T}^\ominus - H_{0,m}}{T} = -R\ln\frac{q^0}{N}$$

---

**例** 已知 $\mathrm{HI}$ 的 $\Theta_r = 9.125\ \mathrm{K}$，$\Theta_v = 3208\ \mathrm{K}$，试求 $500\ \mathrm{K}$ 时 $\mathrm{HI}$ 气体的标准摩尔吉布斯自由能函数。

**解：**

$$\frac{G_{m,T}^\ominus - U_{0,m}}{T} = -R\ln\frac{q^0}{N}$$

其中 $q^0 = q_t^0 q_r^0 q_v^0$，$T = 500\ \mathrm{K}$，$P = 10^5\ \mathrm{Pa}$，$n = 1\ \mathrm{mol}$，

$$M_{\mathrm{HI}} = 127.9 \times 10^{-3}\ \mathrm{kg/mol}$$

即

$$m = \frac{M}{L} = 2.124 \times 10^{-25}\ \mathrm{kg}$$

$\mathrm{HI}$ 为异核双原子分子，对称数 $\sigma = 1$

$$q_t^0 \approx q_t = \left(\frac{2\pi mkT}{h^2}\right)^{\frac{3}{2}}V = \left(\frac{2\pi mkT}{h^2}\right)^{\frac{3}{2}}\frac{nRT}{P} = 1.263 \times 10^{32}$$

$$q_r^0 = q_r = \frac{T}{\Theta_r \sigma} = \frac{500}{9.125} = 54.795$$

$$q_v^0 = \frac{1}{1-e^{-\Theta_v/T}} = \frac{1}{1-e^{-3208/500}} = 1.0016$$

$$q^0 = q_t^0 q_r^0 q_v^0 = 1.263 \times 10^{32} \times 54.795 \times 1.0016 = 6.93 \times 10^{33}$$

于是求得 $500\ \mathrm{K}$ 时 $\mathrm{HI}$ 气体的标准摩尔吉布斯自由能函数

$$\frac{G_{m,T}^\ominus - U_{0,m}}{T} = -R\ln\frac{q^0}{N}$$

$$= -8.314 \times \ln\frac{6.93 \times 10^{33}}{6.02 \times 10^{23}} = -192.6\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$$

## 理想气体的标准摩尔焓函数

$$H = NkT^2\left(\frac{\partial \ln q}{\partial T}\right)_V + NkTV\left(\frac{\partial \ln q}{\partial V}\right)_T$$

当 $p = p^\ominus = 10^5\ \mathrm{Pa}$ 时

$$H_m^\ominus = RT^2\left(\frac{\partial \ln q^0}{\partial T}\right)_V + RT + U_{0,m}$$

$$\frac{H_{m,T}^\ominus - U_{0,m}}{T} = RT\left(\frac{\partial \ln q^0}{\partial T}\right)_V + R$$

$\left(H_{m,T}^\ominus - U_{0,m}\right)/T$ 或 $\left(H_{m,T}^\ominus - H_{0,m}\right)/T$ 称作**标准摩尔焓函数**。

---

### 关联概念与对比辨析

| 对比项 | 标准摩尔吉布斯自由能函数 | 标准摩尔焓函数 |
| :--- | :--- | :--- |
| **定义式** | $\displaystyle\frac{G_{m,T}^\ominus - U_{0,m}}{T} = -R\ln\frac{q^0}{N}$ | $\displaystyle\frac{H_{m,T}^\ominus - U_{0,m}}{T} = RT\left(\frac{\partial \ln q^0}{\partial T}\right)_V + R$ |
| **主要用途** | 计算 $\Delta_r G_m^\ominus$，进而求 $K^\ominus$ | 计算 $\Delta_r H_m^\ominus$，进而求温度对平衡常数的影响 |
| **与配分函数关系** | 直接依赖于 $\ln q^0$ | 直接依赖于 $\displaystyle\left(\frac{\partial \ln q^0}{\partial T}\right)_V$ |
| **零点能处理** | 以 $U_{0,m}$（或 $H_{0,m}$）形式单独列出 | 以 $U_{0,m}$（或 $H_{0,m}$）形式单独列出 |

- **$q^0$ 的含义**：表示以分子基态能量为零点的相对配分函数（各运动形式配分函数的乘积），与绝对配分函数 $q$ 的关系为 $q = q^0 e^{-\varepsilon_0/kT}$。
- **对称数 $\sigma$**：转动配分函数中的 $\sigma$ 用于修正同核双原子分子（或多原子分子）因旋转 $180^\circ$ 产生的不可区分构型。异核分子（如 $\mathrm{HI}$）$\sigma=1$，同核分子（如 $\mathrm{H_2}$）$\sigma=2$。
