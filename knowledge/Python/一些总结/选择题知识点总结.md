## 一、for 循环与 range() — ⭐⭐⭐⭐⭐（最高频，约 20+ 题）

### 核心知识

```python
range(start, stop, step)
# start: 起始值（含），默认 0
# stop:  结束值（不含）
# step:  步长，默认 1
```

- `range(1,10)` → 1,2,3,4,5,6,7,8,9（**不含 10**）
- `range(1,10,2)` → 1,3,5,7,9
- `range(10)` → 0,1,2,...,9
- `range(8,2,-2)` → 8,6,4

### 易错点

| 题目 | 易错点 | 标记 |
|------|--------|------|
| 001 | `continue` 跳过奇数，print 在 continue 之后才执行 | !! |
| 012 | `sum=1` 初值不是 0！1+1+2+...+100 = 5051 | !! |
| 013/019 | `start=1, range(1, 25, 2)` → 1,3,5,...,23（共12个值） | - |
| 027 | `i/3 == 0` 永远不成立（只有 i=0 时成立，但 range(1,6)） | - |
| 036 | `for x in (1,10):` 是**元组**不是 range！只迭代 1 和 10 两个值 | !! |
| 063 | 循环内全是 continue，循环结束后 `i=9`（range(1,10)最后的值） | !! |
| 064 | 循环内修改 `i` 不影响迭代次数，`range(10)` 固定 10 次 | !! |
| 066 | `range(1,10,3)` → 1,4,7，只有 4 是偶数，Sum=4 | - |
| 075 | 嵌套循环：外层 3 次(range(8,2,-2)→8,6,4)，内层分别 8+6+4=18 次 | - |

### for-else 语法

```python
for i in range(N):
    if 条件:
        break      # break 后不执行 else
else:
    print("循环正常结束才执行")
```

| 题目 | 要点 | 标记 |
|------|------|------|
| 078 | 循环正常结束（无 break），else 执行，输出最后的 i=9 | !! |
| 080 | break 后 else **不执行**，所以有解时无输出 | !! |

## 二、break 与 continue — ⭐⭐⭐⭐⭐（约 12 题）

| 题目 | 知识点 | 标记 |
|------|--------|------|
| 001 | `continue` 跳过本次循环剩余代码，进入下一次迭代 | !! |
| 015 | `break` 直接终止整个循环（碰到 'r' 就停，输出 "mir"） | !! |
| 045 | **break 结束整个循环，continue 只结束本次循环** | [!warning] |
| 049 | break 只能在循环内使用 | - |
| 052 | continue 不结束循环，只是跳过本次剩余代码 | - |
| 063 | continue 跳过 print，最后只输出循环结束后的 i 值 | !! |
| 077 | `if i%2:` 条件为真时 continue（跳过奇数），只输出偶数 | - |
| 080 | break 触发后 for-else 的 else 不执行 | !! |

> **一句话总结**：`break` = 永久退出循环；`continue` = 跳过本次，继续下次。

### 引用赋值 vs 复制（高频易错！）

```python
a = [1, 2]
b = a          # b 和 a 指向同一个列表！
a.append(3)    # a 和 b 都变成 [1,2,3]
```

> 096 题：`b = a` 是引用赋值，不是复制！修改 a 会影响 b 喵！

### sort() vs sorted()（高频易错！）

| | `list.sort()` | `sorted(list)` |
|------|------|------|
| 返回值 | **None**（原地排序） | **新列表** |
| 原列表 | 被修改 | 不变 |

| 题目 | 要点 | 标记 |
|------|------|------|
| 088 | `sort(key=lambda x: x%2==0)` → 奇数(False)在前，偶数(True)在后 | ?? |
| 089 | `sorted()` 不改变原列表，lstA 保持不变 | ?? |
| 094 | `print(lstA.sort())` → 输出 **None**！sort() 返回 None | !! |

### key 参数与 lambda

```python
# x%2==0 → 奇数返回False(0)，偶数返回True(1)，所以奇数排前面
lst.sort(key=lambda x: x%2==0)

# sum(x) → 按元组元素和排序
lst.sort(key=lambda x: sum(x))
```

| 题目 | 排序逻辑 | 标记 |

| 091 | `sorted(dictScore.items(), key=lambda x: x[1][0]+x[1][1])` 按总分 | ?? |

## 五、运算符与表达式 — ⭐⭐⭐⭐（约 8 题）

### 算术运算符优先级

```python
# ** 优先级最高
5**2    → 25
3+5**2  → 3+25 → 28
x *= 3+5**2  → x *= 28
```

| 题目 | 运算 | 标记 |
|------|------|------|
| 006 | `x *= 3+5**2` → x=1*28=28 | - |
| 029 | `x%y` (取余), `x**y` (幂) → 1, 1000 | - |

### 逻辑运算符

```python
# and: 返回第一个假值或最后一个真值
# or:  返回第一个真值或最后一个假值
# 优先级: not > and > or
```

| 题目 | 表达式 | 结果 | 标记 |
|------|--------|------|------|
| 014 | `2!=5 or 0` | True（2!=5 为 True） | - |
| 022 | `gender=="男" and (mark<60 or mark>=90)` | 必须加括号！and 优先级高于 or | !! |
| 070 | `10%2 or 2+1` → `0 or 3` → 3 | - |
| 093 | `5 or 6` → 5（or 返回第一个真值，不转 bool） | !! |

### 浮点数精度（重要！）

```python
0.1 + 0.2 == 0.3   # False！（浮点数精度问题）
pow(3, 0.5) * pow(3, 0.5) == 3  # False！
```

| 题目 | 说明 | 标记 |

| 038 | `pow(3,0.5)*pow(3,0.5)==3` → False | !! |
| 044 | `0.1+0.2==0.3` → False | - |
