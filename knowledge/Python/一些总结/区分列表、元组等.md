## Python 数据类型创建方式速查表

| 类型              | 写法                      | 括号/符号是否必须     | 空值写法                   | 示例               |
| :-------------- | :---------------------- | :------------ | :--------------------- | :--------------- |
| **列表 (list)**   | `[1, 2, 3]`             | ✅ 必写方括号 `[ ]` | `[]` 或 `list()`        | `[1, "a", True]` |
| **元组 (tuple)**  | `1, 2, 3` 或 `(1, 2, 3)` | ❌ 逗号决定一切！括号可省 | `()` 或 `tuple()`       | `1,` 也是元组        |
| **字典 (dict)**   | `{"a":1, "b":2}`        | ✅ 必写花括号 `{ }` | `{}` 或 `dict()`        | `{"name":"猫"}`   |
| **集合 (set)**    | `{1, 2, 3}`             | ✅ 必写花括号 `{ }` | `set()` ← **不能用 `{}`** | `{1, "a"}`       |
| **字符串 (str)**   | `"hello"` 或 `'hello'`   | ✅ 必写引号        | `""` 或 `str()`         | `"喵"`            |
| **整数 (int)**    | `123`                   | ❌ 啥都不用        | `0`                    | `42`             |
| **浮点数 (float)** | `3.14`                  | ❌ 啥都不用        | `0.0`                  | `-2.5`           |
| **布尔 (bool)**   | `True` / `False`        | ❌ 啥都不用        | —                      | `True`           |

## 易混淆速查

| 写法 | 实际是什么 | 原因 |
|:---|:---|:---|
| `{}` | **空字典** dict | Python 优先把它当字典 |
| `set()` | 空集合 set | 空集合唯一写法 |
| `(1)` | **整数 1** | 括号被当成数学括号！ |
| `(1,)` | 单元素元组 `(1,)` | 逗号在才算元组 |
| `1, 2, 3` | 元组 `(1, 2, 3)` | 逗号就是元组，不需要括号 |
| `[1, 2, 3]` | 列表 `[1, 2, 3]` | 方括号 = 列表 |
| `{1, 2, 3}` | 集合 `{1, 2, 3}` | 花括号没冒号 = 集合 |
| `{"a":1}` | 字典 `{"a":1}` | 花括号有冒号 = 字典 |

## 三大序列对比

|          | 列表 `list`           | 元组 `tuple`            | 字符串 `str`          |     |     |     |
| :------- | :------------------ | :-------------------- | :----------------- | --- | --- | --- |
| **符号**   | `[ ]`               | `,`（`( )`可选）          | `" "` 或 `' '`      |     |     |     |
| **元素可改** | ✅ 可以                | ❌ 不能                  | ❌ 不能               |     |     |     |
| **拼接**   | `[1]+[2]` → `[1,2]` | `(1,)+(2,)` → `(1,2)` | `"a"+"b"` → `"ab"` |     |     |     |
| **重复**   | `[1]*3` → `[1,1,1]` | `(1,)*3` → `(1,1,1)`  | `"a"*3` → `"aaa"`  |     |     |     |
| **可哈希**  | ❌                   | ✅                     | ✅                  |     |     |     |

## 终极判断口诀

```
方括号 → 列表 [ ]
逗号在 → 元组 ( ) 可有可无
花括号看冒号：
  有冒号 → 字典 {键:值}
  没冒号 → 集合 {值}
空花括号 {} → 字典！
空集合必须写 set()
```
