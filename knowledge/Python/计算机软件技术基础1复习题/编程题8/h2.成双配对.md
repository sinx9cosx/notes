## 题目名称：成双配对

## 题目描述

编写函数 `isMatch()`，使用栈，检查输入的字符串中，括号和引号是否完美匹配。

```
括号包括：(小括号) [中括号] {大括号} <尖括号> 四种情况
引号包括： '单引号' "双引号" `反引号` 三种情况
```

​	括号及引号可以嵌套，如`[a(b'c')d]`，但不能交叉，如`{x<y}z>`。

​	例如：以下字符串是完美匹配的

```
{abc[def(gh"1[2h]'9<he`l{@#$}l`o>9'3").],}
```

​	但是，以下字符串就是不匹配的

```
(a[b)]
"a'b"c'd
((a)))
"<a"(b)>
```

函数头

​	`def isMatch(expression):`

## 输入格式

函数的形参：

​	一个字符串表达式 expression

## 输出格式

函数的返回值：

​	如果表达式当中的括号和引号完美匹配，返回 True，若不匹配，返回False。

## 输入输出样例 #1

### 输入 #1

```
{abc[def(gh"1[2h]'9<he\`l{@#$}l\`o>9'3").],}
```

### 输出 #1

```
True
```

## 输入输出样例 #2

### 输入 #2

```
"<a"(b)>
```

### 输出 #2

```
False
```

class Stack:

    def __init__(self):

        self.items = []

    def isEmpty(self):

        return self.items == []

    def push(self, item):

        self.items.append(item)

    def pop(self):

        return self.items.pop()

    def peek(self):

        return self.items[-1]

    def size(self):

        return len(self.items)

  

def isMatch(expression): # DO NOT modify this line

    opens = "([{<"

    closers = ")]}>"

    quotes = "\"'`"

    s = Stack()

    balanced = True

    index = 0

    while index < len(expression) and balanced:

        symbol = expression[index]

        if symbol in opens:

            s.push(symbol)

        elif symbol in closers:

            if s.isEmpty():

                balanced = False

            else:

                top = s.pop()

                if top not in opens or opens.index(top) != closers.index(symbol):

                    balanced = False

        elif symbol in quotes:

            if s.isEmpty():

                s.push(symbol)

            else:

                top = s.peek()

                if top == symbol:

                    s.pop()

                else:

                    s.push(symbol)

        index = index + 1

    if balanced and s.isEmpty():

        return True

    else:

        return False
