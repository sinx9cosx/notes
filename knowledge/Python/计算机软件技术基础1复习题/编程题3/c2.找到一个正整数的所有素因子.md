# 题目名称：找到一个正整数的所有素因子

## 题目描述

显示一个大于 1 的整数的所有素因子。素因子即该因子必须是素数。若此数为素数，则仅显示此数本身即可。

## 输入格式

一个大于1的整数。

## 输出格式

升序显示该整数的所有素因子，即较小素因子的应该先输出，一个素因子一行。

## 输入输出样例

### 输入 #1
``` 
120
```

### 输出 #1
```
2
2
2
3
5
```

## 代码

``` python
n = int(input())

m = 2

while n>1:

    if n%m == 0:

        print(m)

        n //= m

    else:

        m += 1
```
