# 题目名称：找出任意一天是一年中的第几天

## 题目描述

找出任意一天是一年中的第几天。注意闰年的判断。世纪年（年份最后两位是00的）需要除得尽400才是闰年，非世纪年需要除得尽4才是闰年。

注意：1月1日为第1天。

## 输入格式

输入一个日期的年、月、日，一行数字一个。

## 输出格式

这一天是当年中的第几天。

## 输入输出样例

### 输入 #1
```
2022
3
31
```

### 输出 #1
```
90
```

### 输入 #2

```
2000
8
31
```

### 输出 #2

```
244
```

## 代码

``` python
year = int(input())

month = int(input())

day = int(input())

  

days = day

for i in range(1,month):

    if i in (1,3,5,7,8,10,12):

        days += 31

    elif i in (4,6,9,11):

        days += 30

    elif i == 2:

        if year%400==0 or year%100!=0 and year%4==0:

            days += 29

        else:

            days += 28

  

print(days)
```
