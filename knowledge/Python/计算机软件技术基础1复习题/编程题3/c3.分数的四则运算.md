# 题目名称：分数的四则运算

## 题目描述

计算二个分数的四则运算结果。

（1）输出结果应该是约分过的最简分数，如10/12应该输出为5/6。

提示：正分数约分为最简分数时，分子分母同时除以它们的最大公约数即可。

（2）如果输出结果的分数为负值，则负号标在分子上，如-3/5，输出-3和5。

（3）如果要输出结果为0时，分母输出1。

（4）如果要结果是个整数时，分母输出1。

（5）输入的分数也遵守上述之规则。

## 输入格式

共输入5个数字，分别是：第1个分数（分别输入分子和分母），运算符（1代表加法，2代表减法，3代表乘法，4代表除法），第2个分数（分别输入分子和分母），每个数字一行。

## 输出格式

计算两个分数的四则运算结果，以分数形式输出，分别输出分子分母，一个一行。

## 输入输出样例

### 输入 #1
```
2
3
2
1
4
```

### 输出 #1
```
5
12
```

### 说明 #1

本例含义为 $\frac {2} {3} - \frac {1} {4}$，结果输出 $5 \over 12$ 。

## 代码

``` python
x1 = int(input())

y1 = int(input())

op = int(input())

x2 = int(input())

y2 = int(input())

  

if op == 1:

    x3 = x1*y2+x2*y1

    y3 = y1*y2

elif op == 2:

    x3 = x1*y2-x2*y1

    y3 = y1*y2

elif op == 3:

    x3 = x1*x2

    y3 = y1*y2

elif op == 4:

    x3 = x1*y2

    y3 = y1*x2

  

if x3 == 0:

    y3 = 1

    sign = 1

elif x3*y3 < 0:

    sign = -1

else:

    sign = 1

  

gcd = 1

x3,y3 = abs(x3),abs(y3)

for i in range(min(x3,y3),0,-1):

    if x3%i==0 and y3%i==0:

        gcd = i

        break

x3,y3 = x3//gcd,y3//gcd

x3 *= sign

  

print(x3)

print(y3)
```
