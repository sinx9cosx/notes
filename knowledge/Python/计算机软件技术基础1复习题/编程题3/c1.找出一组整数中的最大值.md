# 题目名称：找出一组整数中的最大值

## 题目描述

读取若干个（至少1个）整数（正负都有，但不包含0），找出它们中的最大值，并计算它的出现次数。

## 输入格式

依次输入若干整数，一个一行，以输入数字0结束（0仅表示结束，不作为要处理的数字）。

## 输出格式

输入的数字中的最大值，然后是该最大值出现的次数，一个一行。

## 输入输出样例

### 输入 #1
```
3
4
-2
5
2
5
0
```

### 输出 #1
```
5
2
```

## 代码

``` python
n = int(input())

max = n

count = 1

while True:

    n = int(input())

    if n == 0:

        break

    if n>max:

        max = n

        count = 1

    elif n==max:

        count += 1

print(max)

print(count)
```
