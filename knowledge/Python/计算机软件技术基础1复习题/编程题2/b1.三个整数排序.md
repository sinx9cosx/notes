# 题目名称：三个整数排序

## 题目描述

用户输入三个整数，然后按其值从小到大（升序）显示它们。

## 输入格式

三个整数，一行一个

## 输出格式

以升序显示三个整数，一行一个

## 输入输出样例

### 输入 #1
```
99
-8
0
```

### 输出 #1
```
-8
0
99
```

## 代码

``` python
# 输入三个整数

number1 = int(input())

number2 = int(input())

number3 = int(input())

  

# 对 number1,number2,number3 按升序排列

  

if number1 > number2:

    number1,number2 = number2,number1

  

if number2 > number3:

    number2,number3 = number3,number2

if number1 > number2:

    number1,number2 = number2,number1

  

# 此时 number1,number2,number3 已经按升序排好

print(number1)

print(number2)

print(number3)
```
