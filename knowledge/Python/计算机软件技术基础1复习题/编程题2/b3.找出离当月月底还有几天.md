# 题目名称：找出离当月月底还有几天

## 题目描述

输入某日的日期，计算此日距当月月底还有几天

## 输入格式

输入三个整数，分别为年、月、日，一行一个。年份输入的范围是1793～9999年。输入的日期为合法的日期。

## 输出格式

这一天距离当月月底还有多少天，计算时不含输入的这一天。

## 输入输出样例

### 输入 #1
```
2023
2
26
```

### 输出 #1
```
2
```

### 输入 #2

```
2022
3
3
```

### 输出 #2

```
28
```

## 代码

``` python
# 输入年、月、日

year = eval(input())

month = eval(input())

day = eval(input())

  

if month == 2:

    if year % 400 == 0 or year % 100 !=0 and year % 4 == 0:

        days = 29  # 闰年，2月为29天

    else:

        days = 28  # 平年，2月为28天

  

elif month in (1,3,5,7,8,10,12):

    days = 31

  

elif month == 4 or month == 6 or month == 9 or month == 11:

    days = 30

  

days_left = days - day

  

# days_left=离月底还有几天

print(days_left)
```
