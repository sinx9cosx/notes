# 逐项详解

## 1. 振动 —— 最明确的「无简并」

笔记第526行直接写了：

> $\varepsilon_{v,i} = (i+\frac{1}{2})h\nu$  **(非简并)**

一维谐振子的每个能级对应唯一一个波函数（唯一的 Hermite 多项式），$g_v \equiv 1$。这是笔记里最干净的无简并案例喵。

## 2. 转动 —— 最典型的「有简并」

第340-343行：

$$\varepsilon_r = J(J+1)\frac{h^2}{8\pi^2I}, \qquad g_r = 2J+1$$

原因是：对于同一个 $J$，磁量子数 $m_J = -J, -J+1, \dots, J-1, J$ 共 $2J+1$ 个不同的取向，它们在不加外场时能量完全相同。配分函数里那个 $(2J+1)$ 因子就是简并度喵。

## 3. 电子运动 —— 有简并（自旋多重度）

第561-584行：

$$q_e^0 = g_{e,0}, \qquad g_{e,0} = 2S+1$$

- 普通分子（电子全部配对，$S=0$）：$g_{e,0} = 1$（恰好"看起来"无简并）
- $\ce{O2}$（三重态，$S=1$）：$g_{e,0} = 3$
- $\ce{NO}$（$S=\frac{1}{2}$）：$g_{e,0} = 2$

电子运动的简并**原则上存在**，只不过大多数分子恰好 $g_{e,0}=1$ 喵。

## 4. 核运动 —— 有简并

第589行：$q_n^0 = g_{n,0}$，核自旋带来的简并度。类似电子，原则上存在，但通常作为常数处理，不影响热力学量的计算喵。

## 5. 平动 —— 微妙的情况

平动**原则上是有简并的**。比如在正方体盒子（$a=b=c$）中：

$$(n_x,n_y,n_z) = (1,1,2),\ (1,2,1),\ (2,1,1)$$

三组不同的量子数给出同一个能量：$\dfrac{h^2}{8ma^2}(1+1+4) = \dfrac{6h^2}{8ma^2}$。

但在实际计算中，笔记用积分近似（第413行）把加和变成了连续积分，这个过程中**所有量子态自动被计数**，就不需要单独写一个 $g_t$ 因子了喵。

# 回到 $\omega$ 公式，做一个完整对照表

把"可区分/不可区分"和"有简并/无简并"交叉，得到四种情况：

|              | 无简并 ($g_i=1$)                     | 有简并 ($g_i \ge 1$)                                         |
| ------------ | --------------------------------- | --------------------------------------------------------- |
| **可区分**（定域）  | $\omega = \dfrac{N!}{\prod n_i!}$ | $\omega = N!\displaystyle\prod_i \dfrac{g_i^{n_i}}{n_i!}$ |
| **不可区分**（离域） | $\omega = 1$                      | $\omega' = \displaystyle\prod_i \dfrac{g_i^{n_i}}{n_i!}$  |

## 一句话总结

> 笔记里**振动是无简并的**，**转动、电子、核运动是有简并的**，**平动原则上也有但用积分消解了**。对应的 $\omega$ 公式则取决于你同时选"可区分/不可区分"和"有简并/无简并"这两个维度——上面的 2×2 表就是完整答案喵。
