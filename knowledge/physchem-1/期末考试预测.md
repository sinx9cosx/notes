# 教师出题风格分析

从作业题和讨论题来看，老师有以下几个鲜明的命题偏好：

1. **概念辨析**：喜欢设"陷阱"对比——比如"熵是状态函数，为什么 $\Delta S_{\mathrm{univ}}$ 却与过程有关？"（表面矛盾→深层统一），又比如讨论题"概率是无知的度量"要求同时结合量子力学和统计力学两个学科论证。
2. **条件敏感性**：很看重公式/判据的适用条件——什么时候可逆？什么时候需要孤立系统？什么时候需要恒温恒压？
3. **跨学科打通**：热力学与统计力学的互译（熵的两种计算方式、最可几分布与自发不可逆）、量子力学与统计力学的衔接（配分函数的能级来源）、对易关系与共同本征态。
4. **推导与证明**：作业大量出现公式推导（玻尔兹曼分布、麦克斯韦关系式、热力学基本方程的衍生公式）。
5. **图像/定性判断**：如 S-U 图上判断温度正负区间、判断能量流动方向。

## 一、量子力学基本概念

### 1. 波函数的良好定义条件
**预测题型**：多选题 / 填空

- E. 实数

> 答案：A, B, C（见笔记量子力学基本假设 ^58d8eb）

### 2. 厄米算符的性质
**预测题型**：单选 / 判断

- 厄米算符的本征值一定是____（实数/复数）？
- 不同本征值对应的本征函数相互____（正交/平行/无关）？

> 答案：实数；正交

### 3. 对易算符与共同本征态
**预测题型**：单选 / 填空

若 $[\hat{A}, \hat{B}] = 0$，则：
- A. $\hat{A}$ 和 $\hat{B}$ 有相同的本征值
- B. $\hat{A}$ 和 $\hat{B}$ 有共同的本征函数完备集
- C. $\hat{A}$ 的本征态一定是 $\hat{B}$ 的本征态（无简并时成立，有简并时需重组）
- D. 以上都不对

> 答案：B（最关键结论），C 在有简并时不一定成立，需注意笔记 ^cce281 的讨论。

**概念辨析**：环上粒子的 $e^{im\phi}$ 同时是 $\hat{T}$ 和 $\hat{J}$ 的本征态（二者对易）。但它们的线性组合 $\cos m\phi$ 仍是 $\hat{T}$ 的本征态，却不再是 $\hat{J}$ 的本征态——这是"对易算符在简并子空间里，共同本征态可以重组掉"的经典例子。老师极可能出判断题或选择题。

### 4. 势函数对称性与波函数奇偶性
**预测题型**：填空 / 判断

若 $V(x) = V(-x)$，则能量本征态 $\psi(x)$ 可以取为____或____。

> 答案：奇函数；偶函数（关键是构造宇称算符 $\hat{p}$，证明 $[\hat{H}, \hat{p}] = 0$）

### 5. 一维无限深势阱基本结论
**预测题型**：单选 / 填空

- 一维无限深势阱 $(0, a)$ 中，$\langle x \rangle =$ ____，$\langle p \rangle =$ ____。

- 势阱本征态 $\psi_n = \sqrt{2/a}\sin(n\pi x/a)$ 是否是动量算符的本征态？____

### 6. 二维势阱的简并
**预测题型**：单选 / 判断

### 29. 玻尔兹曼分布与 $C_V$ 的关系
**预测题型**：单选（作业原题变体）

某一分子体系测量恒容热容 $C_V = 2R$，由此可推断其配分函数的基本数学形式为：

### 48. Maxwell 关系式
**预测题型**：填空 / 单选（给出一个让选另一个）

四个 Maxwell 关系：
- $\left(\frac{\partial T}{\partial V}\right)_S = -\left(\frac{\partial p}{\partial S}\right)_V$
- $\left(\frac{\partial T}{\partial p}\right)_S = \left(\frac{\partial V}{\partial S}\right)_p$
- $\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial p}{\partial T}\right)_V$
- $\left(\frac{\partial S}{\partial p}\right)_T = -\left(\frac{\partial V}{\partial T}\right)_p$

**速记法**：共轭变量 $(S,T)$ 和 $(V,p)$，斜对角线的分子分母是一对共轭变量。

# 大题预测（75分：计算 + 公式推导）

## 题型一：一维/二维势阱求解与期望值计算（15-20分）

**可能考题**：

1. **标准求解**：给出一维无限深势阱 $(0, a)$ 或 $(-a, a)$，求解薛定谔方程，得到本征态和本征值，计算归一化系数。
   - 与作业"一维无限深势阱位于 (-a,a)"完全一致。
   
2. **期望值计算**：计算 $\langle x \rangle, \langle p \rangle, \langle E \rangle$。如果是波函数叠加态 $\Psi = A(\psi_1 + \psi_2)$，计算 $\langle x \rangle$（作业原题）。

3. **二维势阱简并分析**：给出正方形势阱，求前三个能级的能量和简并度。
[[二维正方形势阱简并分析]]
4. **奇偶性证明**：证明若 $V(x) = V(-x)$，则能量本征态可以取为奇函数或偶函数（作业原题）。

5. **复共轭解论证**：证明若 $\psi(x)$ 是 SE 的解，则 $\psi^*(x)$ 也是解，并讨论成立条件（实势能 + 不含时）（作业原题）。

---

## 题型二：环上粒子/刚性转子/谐振子（10-15分）

1. **环上粒子**：求解薛定谔方程，得到波函数 $\psi = \frac{1}{\sqrt{2\pi}}e^{im\phi}$ 和能量 $E = \frac{\hbar^2 m^2}{2I}$，讨论简并性质（$m$ 取 $\pm$ 能量相同）。

2. **刚性转子**：推导能级公式 $E = l(l+1)\frac{\hbar^2}{2I}$，计算转动特征温度和转动配分函数（作业类似 $N_2$ 例题）。

3. **谐振子隧穿概率**：计算 $v=0$ 时的隧穿概率，或讨论隧穿概率随 $v$ 增大的变化趋势。

---

## 题型三：玻尔兹曼分布的推导（10-15分）

**必考概率极高**——这是连接统计力学与热力学的核心。

1. **最大值法推导**：在约束条件 $\sum n_i = N$ 和 $\sum n_i\varepsilon_i = U$ 下，用拉格朗日乘数法推导玻尔兹曼分布（作业原题）。

2. **推导 $\beta$ 与温度的关系**：从 $S = k\ln\omega$ 和 $\frac{\partial S}{\partial U} = \frac{1}{T}$ 推出 $\beta = -1/(kT)$。

---

## 题型四：配分函数与热力学函数的关系（15-20分）

**可能的出题形式**：

1. **配分函数计算**：给定分子的质量、转动惯量、振动频率等参数，计算 $q_t, q_r, q_v$ 及总配分函数（类似 $N_2$ 例题或 HI 的吉布斯自由能函数例题）。

2. **热力学函数推导**：
   - 从 $q$ 推导 $A$（离域子系统）：$A = -NkT\ln\frac{q}{N} - NkT$
   - 从 $A$ 推导 $p$：$p = NkT\left(\frac{\partial \ln q}{\partial V}\right)_T$ → 理想气体状态方程
   - 从 $q$ 推导 $U$：$U = NkT^2\left(\frac{\partial \ln q^0}{\partial T}\right)_V$

3. **$C_V$ 的理论计算**：
   - 推导 $C_{V,t} = \frac{3}{2}R$（平动贡献）
   - 推导 $C_{V,r} = R$（转动贡献，线型分子）
   - 推导 $C_{V,v} = R\left(\frac{\Theta_v}{T}\right)^2 \frac{e^{\Theta_v/T}}{(e^{\Theta_v/T}-1)^2}$（振动贡献）
   - 综合判断不同温度下单原子/双原子气体的 $C_{V,m}$ 取值

4. **标准摩尔吉布斯自由能函数**：类似 HI 例题的计算——给定光谱数据，计算 $\frac{G^\ominus - U_0}{T}$。

## 题型五：二能级系统的熵与温度（10-15分）

**作业原题直接改编可能性极大**。

4. 证明存在负温度（当 $n > N/2$ 时，$T < 0$）
5. 在 S-U 图上标出 $T = +0, +\infty, -\infty, -0$ 的位置

## 题型六：热力学基本方程与 Maxwell 关系的应用（10-15分）

**必考**——这是老师最爱的推导题型。

1. **证明类**：
   - 证明 $\left(\frac{\partial U}{\partial T}\right)_p = C_p - p\left(\frac{\partial V}{\partial T}\right)_p$（作业原题）
   - 证明理想气体内能只取决于温度：$\left(\frac{\partial U}{\partial V}\right)_T = 0$ 和 $\left(\frac{\partial U}{\partial p}\right)_T = 0$
   - 证明 $\left(\frac{\partial C_{p,m}}{\partial p}\right)_T = -T\left(\frac{\partial^2 V_m}{\partial T^2}\right)_p$（笔记中有）
   - 证明 $C_p - C_V = \left[p + \left(\frac{\partial U}{\partial V}\right)_T\right]\left(\frac{\partial V}{\partial T}\right)_p$

2. **推导绝热过程方程**：
   - 从 $\delta Q = 0$ 和 $dU = -pdV$ 出发，结合 $U = C_V T$ 和 $pV = nRT$，推导 $TV^{\gamma-1} =$ 常数
   - 解释压缩升温的物理原因（作业原题）

## 题型十：跨学科综合题（10-15分）

老师极可能出一道连接两个学科的题：

2. **熵的两种计算方式统一**：
