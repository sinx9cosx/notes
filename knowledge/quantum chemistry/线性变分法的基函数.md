# 基函数$\phi_{i}$的选择要求

| 硬性要求                       | 软性要求                             |
| -------------------------- | -------------------------------- |
| 满足边界条件                     | 完备性（当$n \to \infty$，线性组合能趋近任意函数） |
| 平方可积                       | 物理直觉（基函数形态越趋近真实波函数收敛越快）          |
| 线性无关（否则久期行列式奇异）            | 可计算性（涉及基函数的积分最好有解析公式）            |
| well-behaved（单值、连续、一阶导数连续） |                                  |

# 基函数的选择思路

## 原子轨道的线性组合LCAO

分子的电子结构可以用组成原子的原子轨道来近似，因此最自然的选择是类氢原子波函数的形式：
$$
\phi_{i} \sim r^{n-1}e^{-\zeta r}Y_{l,m}(\theta,\phi)
$$
这是Slater型轨道（STO）。
缺陷：多中心双电子积分没有解析公式，计算量太大。

## 用高斯函数替代

为了解决STO的计算困难，用高斯型轨道：
$$
\phi_{i} \sim x^ay^bz^ce^{-\alpha r^2}
$$
高斯函数的性质：两个不同中心的高斯函数相乘，等于另一个中心的高斯函数（高斯乘积定理）。这让多中心积分全部有解析解。
缺陷：
- 高斯函数在$r\to 0$处太平滑
- 在$r\to \infty$处衰减太快
所以需要多个高斯函数线性组合去逼近一个Slater函数。

# Gaussian的基组

Gaussian里的基组就是不同的基函数选择方案，基组的区别就是用什么样的高斯函数几何来做线性展开。

## 最小基组

每个占据的原子轨道只用一个收缩函数，如STO-3G：用3个原始高斯函数的固定线性组合来逼近1个Slater轨道。

```
STO-3G 中碳原子的 s 轨道:
φ_1s = 0.1543 g(α=71.62) + 0.5353 g(α=13.04) + 0.4446 g(α=3.531)
       ↑ 这三个系数是固定的，不算变分参数
```

## 分裂价层基组

化学成键主要涉及价层电子，所以价层轨道用更多基函数描述。这样夹层电子就有更大的变分灵活性。

```
6-31G:
  内层: 1 个收缩函数（6 个 primitive GTO）
  价层: 2 个收缩函数——一个"紧缩"的（3 个 primitive）
                          一个"弥散"的（1 个 primitive）
```

## 极化基组

加上角动量更高的函数来让电子云在成键时可以变形

```
6-31G(d) = 6-31G*:  给重原子加 d 函数
6-31G(d,p) = 6-31G**: 给氢也加 p 函数
```

## 弥散基组

加上指数很小的弥散函数，用来描述阴离子、激发态、弱相互作用中电子云比较蓬松的情况。

```
6-31+G:  给重原子加弥散 sp 函数
6-31++G: 给重原子和氢都加弥散函数
```
