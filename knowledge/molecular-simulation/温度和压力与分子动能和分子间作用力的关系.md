在经典统计力学和分子动力学中，温度主要由分子动能决定，而压力同时由分子动能和分子间作用力决定。核心关系是能量均分定理和维里定理。

# 温度与分子动能的关系

### 瞬时温度

对 \(N\) 个粒子组成的体系，若自由度为 \(N_{\rm df}\)，瞬时温度可写为：

\[
T=\frac{2K}{N_{\rm df}k_B}
\]

其中 \(K\) 为总动能：

\[
K=\sum_i \frac12 m_i v_i^2
\]

所以：

\[
T=\frac{1}{N_{\rm df}k_B}\sum_i m_i v_i^2
\]

若为 \(N\) 个单原子分子，且无约束，则 \(N_{\rm df}=3N\)，于是：

\[
T=\frac{1}{3Nk_B}\sum_{i=1}^N m_i v_i^2
\]

### 平衡态平均关系

平衡态下，能量均分给出：

\[
\langle K\rangle=\frac{N_{\rm df}}{2}k_B T
\]

单原子分子：

\[
\langle K\rangle=\frac32 N k_B T
\]

因此：

\[
\boxed{\text{温度只由分子动能决定，不显含分子间作用力}}
\]

但分子间势能会通过能量守恒影响动能。例如孤立体系中，总能量：

\[
E=K+U_{\rm int}
\]

若分子间势能 \(U_{\rm int}\) 改变，动能 \(K\) 会随之改变，从而影响瞬时温度。


#  压力与分子动能、分子间作用力的关系

压力由维里定理给出。对体积 \(V\) 中的 \(N\) 个粒子：

\[
P=\frac{1}{3V}
\left[
\sum_i m_i v_i^2+\sum_i \mathbf r_i\cdot \mathbf F_i
\right]
\]

其中：

- \(\sum_i m_i v_i^2=2K\)，是动能贡献；
- \(\sum_i \mathbf r_i\cdot \mathbf F_i\) 是维里项，来自分子间作用力；
- \(\mathbf F_i\) 是作用在粒子 \(i\) 上的总力。

因此：

\[
P=\frac{2K}{3V}+\frac{W}{3V}
\]

其中维里：

\[
W=\sum_i \mathbf r_i\cdot \mathbf F_i
\]

若只考虑成对中心势 \(U(r_{ij})\)，则：

\[
W=\sum_{i<j}\mathbf r_{ij}\cdot \mathbf F_{ij}
\]

而中心势满足：

\[
\mathbf F_{ij}
=
-\frac{dU(r_{ij})}{dr_{ij}}
\frac{\mathbf r_{ij}}{r_{ij}}
\]

所以：

\[
\mathbf r_{ij}\cdot \mathbf F_{ij}
=
-r_{ij}\frac{dU(r_{ij})}{dr_{ij}}
\]

代入压力表达式：

\[
\boxed{
P=
\frac{Nk_B T}{V}
-
\frac{1}{3V}
\left\langle
\sum_{i<j}
r_{ij}\frac{dU(r_{ij})}{dr_{ij}}
\right\rangle
}
\]

也可以写成：

\[
\boxed{
P=
\frac{Nk_B T}{V}
+
\frac{1}{3V}
\left\langle
\sum_{i<j}
\mathbf r_{ij}\cdot \mathbf F_{ij}
\right\rangle
}
\]

其中第一项：

\[
\frac{Nk_B T}{V}
\]

是理想气体动能贡献；第二项是分子间作用力贡献。

---

## 3. 各项的物理意义

- 动能项 \(Nk_B T/V\)：总是正贡献，使压力增大。
- 分子间排斥力：\(\mathbf r_{ij}\cdot \mathbf F_{ij}>0\)，维里项为正，使压力增大。
- 分子间吸引力：\(\mathbf r_{ij}\cdot \mathbf F_{ij}<0\)，维里项为负，使压力降低。
- 若分子间作用力可忽略，则回到理想气体状态方程：

\[
PV=Nk_B T
\]

---

## 4. 以 Lennard-Jones 势为例

Lennard-Jones 势：

\[
U(r)=4\varepsilon
\left[
\left(\frac{\sigma}{r}\right)^{12}
-
\left(\frac{\sigma}{r}\right)^6
\right]
\]

其维里项为：

\[
-r\frac{dU}{dr}
=
24\varepsilon
\left[
2\left(\frac{\sigma}{r}\right)^{12}
-
\left(\frac{\sigma}{r}\right)^6
\right]
\]

因此压力：

\[
P=
\frac{Nk_B T}{V}
+
\frac{1}{3V}
\left\langle
\sum_{i<j}
24\varepsilon
\left[
2\left(\frac{\sigma}{r_{ij}}\right)^{12}
-
\left(\frac{\sigma}{r_{ij}}\right)^6
\right]
\right\rangle
\]

其中：

- \(r^{-12}\) 排斥项使压力增大；
- \(r^{-6}\) 吸引项使压力减小。

---

## 5. 压力张量形式

更严格地，压力是一个张量：

\[
P_{\alpha\beta}
=
\frac{1}{V}
\left[
\sum_i m_i v_{i\alpha}v_{i\beta}
+
\sum_i r_{i\alpha}F_{i\beta}
\right]
\]

标量压力为：

\[
P=\frac13 \operatorname{Tr}(\mathbf P)
=
\frac{1}{3V}
\left[
\sum_i m_i v_i^2
+
\sum_i \mathbf r_i\cdot \mathbf F_i
\right]
\]

---

## 6. 与状态方程和维里展开的联系

实际气体状态方程可写为：

\[
\frac{P}{\rho k_B T}
=
1+B_2(T)\rho+B_3(T)\rho^2+\cdots
\]

其中第二维里系数：

\[
B_2(T)
=
-\frac12
\int
\left[
e^{-U(r)/k_B T}-1
\right]
d^3r
\]

这说明：

- 温度 \(T\) 通过 Boltzmann 因子 \(e^{-U/k_B T}\) 影响分子间作用力的统计分布；
- 分子间势 \(U(r)\) 通过维里系数影响压力。


# 总结

\[
\boxed{
T=\frac{2K}{N_{\rm df}k_B}
}
\]

即温度由分子动能决定。

\[
\boxed{
P=
\frac{Nk_B T}{V}
-
\frac{1}{3V}
\left\langle
\sum_{i<j}
r_{ij}\frac{dU(r_{ij})}{dr_{ij}}
\right\rangle
}
\]

即压力等于理想气体动能项加上分子间作用力的维里修正项。
