## 答题技巧

### 结构

1. `观点` I think ...
2. `理由1` first, ...
3. `例子1` for example...
4. `理由2` second, ...
5. `例子2` for instance, ...
6. `总结` so overall, ... （补时间）

## 表达

填充词：

Actually, ...
Well, ...
Let me think ...
To be honest, ...
Anyway ...
Like ...
So ...
I guess ...

表达观点：

I prefer ...
I would rather ...
Personally, I think ...

理由：

The main reason is that ...
Another reason is that ...

解释：

This means that ...
As a result, ...
For example, ...

收尾：

That's why I prefer ...
In conclusion, ...
