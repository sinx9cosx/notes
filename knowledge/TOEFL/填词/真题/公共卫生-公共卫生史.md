# 错题

## li_ -> like

类型：B 词义知道，但语境没想到
原因：句中是 "have grown from basic efforts ___ improving sanitation"，from ... to ... 结构里这一空引出"改善卫生"之类的例子，需要介词 like；我补成 fe，读成 life，efforts life improving 不成搭配。
处理：记 like 作介词表举例：efforts like improving sanitation（像改善卫生这样的努力）；对比 such as 后同样接名词或动名词。life n. 生命，生活（复数 lives），与 like 只差一个字母，靠词性和搭配判断。

## incl_ -> include

类型：B 词义知道，但语境没想到
原因：句中是 "have grown from basic efforts like improving sanitation to ___ many strategies"，to 后面需要一个动词原形，语义是"发展到包含"；我补成 ine，读成 incline，incline 意为"倾向，倾斜"，表示"倾向于"时要用 be inclined to do，此处不成立。
处理：记 include v. 包括，包含（后接名词或动名词，不接 to do）；同族 including prep. 包括、inclusive adj. 包含在内的；搭配 grow from A to include B。

## sanit_ -> sanitation

类型：D 不认识单词
原因：空格在 "improving ___" 中，improving 后面需要名词作宾语；`sanit` 已给出，我没有作答。答案 sanitation 是 sanitary 的名词形式。
处理：记词根 sanit- 表"健康"：sanitation n. 卫生设施，环境卫生、sanitary adj. 卫生的、sanitize v. 给……消毒；搭配 improve sanitation 改善卫生条件。

## strat_ -> strategies

类型：D 不认识单词
原因：空格在 "many ___ that deal with social factors" 中，many 后面需要复数名词，后面 that 从句修饰它；`strat` 已给出，我没有作答。
处理：记 strategy n. 策略，战略 → 复数 strategies（辅音字母 + y → ies）；搭配 strategies that deal with ...、strategies for doing sth；同族 strategic adj. 战略的、strategically adv. 战略性地。
