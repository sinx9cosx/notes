# 填词技巧与规律

## 总原则：四步顺序

1. **看位置定词性**：空的前后词已经限定了词性，词性错了意思再对也是零分。
2. **看搭配定词义**：`形容词 + 名词` 的固定搭配往往直接给出答案。
3. **看词形定拼写**：单复数、时态、派生后缀由句子骨架决定。
4. **最后才想「我认识哪个词」**：这一步放最后，是为了不让最熟的词抢答。

## 先定词性，再看意思

- 冠词 / 形容词后 → 名词：`technolog|ing → technological`，`technological practices`，`practices` 是名词，前面只能放形容词；而且它在 `daily lives, trade networks, and technological practices` 这个并列里，和 `networks` 同位置，词性必须一致。
- `to` 后 → 动词原形：`incl|ine → include`，`to include many strategies`，`to` 后不可能是 `incline` 这种多出来的词义。
- 句首大写处 → 主语（主格代词或名词）：`I|n → It`，后面是 `encompasses`，第三人称单数谓语，主语只能是 `It`。
- 修饰动词 → 副词：`of|fer → often`，`rapid fluctuations often signal approaching storms`，`signal` 是谓语，前面要副词 `often`，不是动词 `offer`。
- 修饰名词 → 形容词：`soc|ial → social`，`such complex social structures`，`structures` 前必须是形容词。
- 顺序不能反：先锁定词性，再去想意思；反过来就会先想到 `offer` 再硬塞进 `signal` 前面。

## 长派生词

- `systematically` = systematic + ally
- `sanitation` = sanit(ize) + ation
- `strategies` = strategy → strategies
- `precipitation` = precip(itate) + ation
- `variations` = vary → variation → variations
- `meteorologists` = meteor + olog(y) + ist + s
- `approaching` = approach + ing
- `layers` = lay → layer → layers（`the outer layers of Earth`）
- `areas` = area → areas（`encompasses areas such as ...`）
- `forecasts` = fore + cast + s
- `geological` = geology → geological
- `technological` = technology → technological
- `artifacts` = artif(act) + s。

拼写：

- `-ally` 类：`systematically`，形容词以 `-ic` 结尾时副词加 `-ally`，不是直接加 `-ly`。
- `-ation` 类：`precipitation`、`sanitation`、`variations`
- `-ologists` 类：`meteorologists`，`-ist + s` 两层后缀
- `-ies` 类：`strategies` ，`colonies`、`audiences` 同理。
- `-ences` 类：`audiences`
- `infra-` 前缀：`infrastructure` 是 `infra + structure`
- `-ical` 类：`geological` = geology → geological，`y` 去掉再加 `ical`


## 先扫语法骨架再逐空填

- 主谓宾先找主干：`Historians debate whether ...`，句首空直接由主语位置定案，`Hist|orists → Historians`。
- 并列结构给词性：`A, B, and C` 里每一项词性一致，`built by colonies of tiny organisms called coral polyps` 里 `by` 后统一是名词。
- `such as` 后是列举：`encompasses areas such as natural hazard assessment, resource management, and land-use planning`，`ar → areas` 由 `encompasses ... such as` 锁定「领域」，`sanit → sanitation` 也是同一类列举位置。
- 标点定范围：逗号 / 分号会把句子切成小段，每个小段内部的词性可以提前标出来，`such complex social structures can lead to increased group stability` 里的 `social` 就是形容词位置。
