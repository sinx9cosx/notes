# 填词技巧与规律

## 总原则：四步顺序

1. **看位置定词性**：空的前后词已经限定了词性，词性错了意思再对也是零分。
2. **看搭配定词义**：`形容词 + 名词` 的固定搭配往往直接给出答案。
3. **看词形定拼写**：单复数、时态、派生后缀由句子骨架决定。
4. **最后才想「我认识哪个词」**：这一步放最后，是为了不让最熟的词抢答。

## 先定词性，再看意思

- 冠词 / 形容词后 → 名词：`technolog|ing → technological`，`technological practices`，`practices` 是名词，前面只能放形容词；而且它在 `daily lives, trade networks, and technological practices` 这个并列里，和 `networks` 同位置，词性必须一致。
- `to` 后 → 动词原形：`incl|ine → include`，`to include many strategies`，`to` 后不可能是 `incline` 这种多出来的词义。
- 句首大写处 → 主语（主格代词或名词）：`I|n → It`，后面是 `encompasses`，第三人称单数谓语，主语只能是 `It`。
- 修饰动词 → 副词：`of|fer → often`，`rapid fluctuations often signal approaching storms`，`signal` 是谓语，前面要副词 `often`，不是动词 `offer`。
- 修饰名词 → 形容词：`soc|ial → social`，`such complex social structures`，`structures` 前必须是形容词。
- 顺序不能反：先锁定词性，再去想意思；反过来就会先想到 `offer` 再硬塞进 `signal` 前面。

## 长派生词

- `systematically` = systematic + ally
- `sanitation` = sanit(ize) + ation
- `strategies` = strategy → strategies
- `precipitation` = precip(itate) + ation
- `variations` = vary → variation → variations
- `meteorologists` = meteor + olog(y) + ist + s
- `approaching` = approach + ing
- `layers` = lay → layer → layers（`the outer layers of Earth`）
- `areas` = area → areas（`encompasses areas such as ...`）
- `forecasts` = fore + cast + s
- `geological` = geology → geological
- `technological` = technology → technological
- `artifacts` = artif(act) + s。

拼写风险点（这些长词最容易丢分的地方）：

- `-ally` 类：`systematically`，形容词以 `-ic` 结尾时副词加 `-ally`，不是直接加 `-ly`。
- `-ation` 类：`precipitation`、`sanitation`、`variations`
- `-ologists` 类：`meteorologists`，`-ist + s` 两层后缀，中间是 `o` 不是 `e`。
- `-ies` 类：`strategies` 不是 `-ys / -es` 乱加，`y` 结尾要先还原再加 `es`；`colonies`、`audiences` 同理。
- `-ences` 类：`audiences`，别写成 `audiances`。
- `infra-` 前缀：`infrastructure` 是 `infra + structure`，`structure` 里的 `t` 不能漏。
- `-ical` 类：`geological` = geology → geological，`y` 去掉再加 `ical`，中间字母不能漏。
- 单字母空（`I`、`m`；如 `I|n → It`、`m|ethods → meaning`）：候选词最多，先定词性和句子成分，再核对拼写；这一类的错都不是拼写错，是词性判断错。

## 长前缀：不是送分，是拼写题

- 前缀 ≥5 个字母的失误有 10 条，其中 7 条是空着没答的：`systema → systematically`、`sanit → sanitation`、`strat → strategies`、`precip → precipitation`、`varia → variations`、`meteor → meteorologists`、`appro → approaching`；另外 3 条是错答：`artif → artifacts`、`technolog → technological`、`infra → infrastructure`。
- 前缀给得多 ＝ 词形和拼写方向已经确定，不用再猜词；但「前缀长」同时意味着要写的字母更多，写不出来照样 0 分——所以这类空要专门练拼写（`-ally`、`-ation`、`-ologists`、`-ical`、`infra-`）。
- 结论：错答的 14 条里，11 条的前缀 ≤4 个字母；时间应该从「拼写题」里省出来，投到「短前缀 + 词性判断」上。

## 先扫语法骨架再逐空填

- 主谓宾先找主干：`Historians debate whether ...`，句首空直接由主语位置定案，`Hist|orists → Historians`。
- 并列结构给词性：`A, B, and C` 里每一项词性一致，`built by colonies of tiny organisms called coral polyps` 里 `by` 后统一是名词。
- `such as` 后是列举：`encompasses areas such as natural hazard assessment, resource management, and land-use planning`，`ar → areas` 由 `encompasses ... such as` 锁定「领域」，`sanit → sanitation` 也是同一类列举位置。
- 标点定范围：逗号 / 分号会把句子切成小段，每个小段内部的词性可以提前标出来，`such complex social structures can lead to increased group stability` 里的 `social` 就是形容词位置。
- 一段话里骨架只有一套，先扫一遍骨架，能把 3-5 个空的词性同时定下来，比一个空一个空硬猜快得多。

## 错因分类对照

- **A 主动回忆失败（1 条）**：`la → layers`，`the outer layers of Earth`；词很常见，但看到 `la` 时没回想起来。做法：常见词也要顺着搭配（`outer ... of Earth`）往回想，不要因为前缀短就直接跳过。
- **B 词义知道，但语境没想到（11 条）**：`artif → artifacts`、`m → meaning`、`infra → infrastructure`、`Hist → Historians`、`soc → social`、`li → like`、`incl → include`、`of → often`、`colo → colonies`、`audi → audiences`、`pre → pressing`；词都认识，但没先把语法位置锁死就抢答。做法：先按位置定词性，再用整句意思筛候选。
- **C 没想到这个方向（3 条）**：`technolog → technological`、`curr → currents`、`I → It`；不是词汇问题，是解题思路问题——没想到这里要的是形容词、复数名词、主格代词。做法：按四步顺序走，先定词性，再定词义。
- **D 不认识单词（10 条）**：`sanit → sanitation`、`strat → strategies`、`precip → precipitation`、`varia → variations`、`meteor → meteorologists`、`fore → forecasts`、`appro → approaching`、`geol → geological`、`ar → areas`、`systema → systematically`；这 10 条全是空着没答的，靠构词法（词根 + 词缀）和拼写专项练习解决。

| 前缀长度 | 条数 | 例子 |

| 1-2 个字母 | 6 | `I`、`m`、`li`、`of`、`la`、`ar` |

- 合计：前缀 ≤4 个字母的 15 条，占 60%；前缀只有 1-2 个字母的 6 条，占 24%；前缀 ≥5 个字母的 10 条，占 40%。
- 错答 14 条里，前缀 ≤4 个字母的有 11 条（占 79%）：`colo`、`I`、`m`、`li`、`incl`、`soc`、`audi`、`pre`、`Hist`、`of`、`curr`。
- 未作答 11 条里，前缀 ≥5 个字母的有 7 条：`systema`、`sanit`、`strat`、`precip`、`varia`、`meteor`、`appro`；其余 4 条（`la`、`ar`、`fore`、`geol`）是 2-4 个字母。
- 行动项：短前缀是错答主因，主要时间投在「短前缀 → 先判词性 → 再看搭配 → 最后写词」这个流程上；长前缀的失误主要卡在拼写和词形（`-ally`、`-ation`、`-ologists`），单独做拼写专项。
