# 万能接口句

"Technology itself is not the problem — the user is."

适用题目：relying on technology / independent thinking / critical thinking / AI and students / how to use technology wisely

# 卡片对应的完整示范回答

Some people say relying on technology makes our thinking lazy, but I think it depends on how you use it. For example, when I search for information with AI, I always double-check the facts using different sources. That forces me to compare and judge instead of just accepting answers. Used this way, AI actually trains my brain instead of weakening it. So technology itself is not the problem — the user is.
