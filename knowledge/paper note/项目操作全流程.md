> **项目**：用 Gaussian 16 研究苯（Benzene）和萘（Naphthalene）的 S₀ → S₁ 激发和 S₁ → S₀ 发射
> **方法**：B3LYP/6-31G(d)
> **软件**：Gaussian 16 Rev A.03（2016-12-17，早期版本，**不支持 `FCHT` 关键字**）
> **本文档**：记录从输入文件编写、计算执行、故障排除到光谱数据后处理与 Origin 画图的完整操作流程，面向计算化学研究生初学者

# 第一部分：Gaussian 计算文件

## 1.1 项目概述

### 研究目标

用 TD-DFT（Time-Dependent Density Functional Theory，含时密度泛函理论）计算苯和萘以下性质：

- **S₀ → S₁ 垂直激发能**（Vertical Excitation Energy）：基态平衡几何下，吸收一个光子跃迁到第一激发态所需的能量
- **S₁ 几何优化**（Adiabatic Excitation）：让激发态也做几何松弛，找到 S₁ 势能面上的极小点
- **S₁ → S₀ 发射能**（Emission Energy）：激发态平衡几何下，回到基态并释放光子
- **Franck-Condon（FC）光谱**：结合振动波函数重叠积分，计算吸收和发射光谱的谱形（振动伴线位置和相对强度）

### 计算级别

- **泛函**（Functional）：B3LYP — 这是最常用的杂化泛函，包含 Becke 的三参数交换泛函 + Lee-Yang-Parr 相关泛函，对有机分子的激发态计算精度可接受
- **基组**（Basis Set）：6-31G(d) — 中等大小的 Pople 基组，对重原子（C）添加 d 极化函数以描述电子密度的各向异性变形，对氢不加极化函数；是激发态计算中计算量与精度之间常见的折中选择
- **软件版本**：Gaussian 16 Revision A.03（2016 年 12 月发布）。注意这是 **G16 的早期版本**，某些高级关键字（如 `FCHT`、`ReadFCHT`）尚未实现。后续故障排除部分会详细讨论这个限制带来的影响

## 1.2 基态几何优化

### 输入文件逐行解析

以 `ben opt.gjf`（苯的基态优化）为例：

```
%mem=1200MB
%chk=F:\gaussian\practice benzene\ben opt.chk
%nprocshared=4
# opt freq b3lyp/6-31g(d) geom=connectivity

Title Card Required

0 1
 C                  0.89234723   -1.74431543    0.00125800
 C                  2.28750723   -1.74431543    0.00125800
 ...（共12个原子）
```

逐段解释：

#### Link 0 命令（以 `%` 开头）

| 命令 | 值 | 含义 |
|------|-----|------|
| `%mem=1200MB` | 1200 MB | 分配给当前计算的**最大内存**。Gaussian 在运行时动态使用内存，此值只是上限。TD-DFT 计算通常比纯 DFT 更耗内存，1200 MB 对 6-31G(d) 基组下的苯（~200 个基函数）绰绰有余 |
| `%chk=...` | 检查点文件路径 | **Checkpoint file** 的存储路径。`.chk` 文件是二进制文件，保存了分子轨道系数、密度矩阵、波函数等信息，后续程序（如频率计算、FC 计算）可以用 `geom=check guess=read` 从 chk 读取并继续计算。**路径必须用绝对路径**（原因见 1.7 节故障排除 5） |
| `%nprocshared=4` | 4 | 使用 4 个**共享内存 CPU 核心**并行计算。注意在 Windows 下，Gaussian 使用共享内存并行而非 MPI（分布式）并行。核心数不宜超过物理核心数，且与 `%mem` 配合——如果核数多但内存不够大，反而可能因内存争用而降速 |

#### Route 行（`#` 开头）

```
# opt freq b3lyp/6-31g(d) geom=connectivity
```

这是 Gaussian 计算的核心设定行，以 `#` 开头（`#p` 表示打印更多输出细节）。各关键字含义：

| 关键字 | 含义 | 为什么需要 |
|--------|------|-----------|
| `opt` | 几何优化 (Geometry Optimization) | 找到势能面上的**驻点**（Stationary Point，即能量对核坐标的一阶导数为零的点）。对基态，默认找极小点（能量最低） |
| `freq` | 频率计算 (Frequency Calculation) | 在优化收敛的几何下计算力常数矩阵（Hessian）的本征值和本征矢。两个作用：(1) **验证驻点性质**——如果全部频率为正（实数），说明是真正的极小点；如果有虚频（imaginary frequency），说明是鞍点；(2) **输出热化学量**——零点能、焓、自由能等热力学校正 |
| `b3lyp/6-31g(d)` | 泛函/基组 | 见 1.1 节说明 |
| `geom=connectivity` | 以原子连接关系指定分子拓扑 | Gaussian 标准输入包含三个部分：原子坐标段、连接关系段（可选）、修饰段（可选）。`geom=connectivity` 告诉 Gaussian 在坐标段后面读取连接关系（哪个原子和哪个原子成键、键级是多少）。这主要用于**内坐标定义**——Gaussian 内部会把 Cartesian 坐标转为冗余内坐标（键长、键角、二面角），优化效率更高。如果不加此关键字，Gaussian 会基于原子间距离自动判断成键（对于苯这种平面分子可能出错） |

#### 分子说明段

```
Title Card Required     ← 标题行（可以写任意说明文字）

0 1                     ← 电荷 (0 = 中性) 和自旋多重度 (1 = 单重态)
 C  ...  x y z          ← 原子坐标（Cartesian，单位 A）
 ...
```

- **电荷** = 0：中性分子
- **自旋多重度** (Spin Multiplicity) = 1：单重态（所有电子配对），用公式 `2S+1` 计算，S = 总自旋量子数。对闭壳层分子 S=0，所以多重度 = 1
- 坐标单位为 A（Angstrom，10^-10 m）

#### 连接关系段（`geom=connectivity` 要求）

```
 1 2 1.5 6 1.5 7 1.0
 2 3 1.5 8 1.0
 ...
 7
 8
 ...
```

格式：`原子编号 相邻原子1 键级1 相邻原子2 键级2 ...`

- `1.5` 表示芳香键（苯环上的 C-C），`1.0` 表示单键（C-H）
- 每个原子的连接定义一行；末行只有原子编号（如 `7`）表示该原子（H）之后没有更多连接

### 如何判断优化收敛

在输出文件中搜索以下标志：

```
-- Stationary point found.
```

如果看到这一行，说明优化已经收敛到驻点。完整的一套收敛判断：

| 收敛判据 | 含义 | 典型阈值 |
|---------|------|---------|
| Maximum Force | 最大力（能量对坐标的梯度） | < 0.000450 Hartree/Bohr |
| RMS Force | 力的均方根 | < 0.000300 |
| Maximum Displacement | 最大位移 | < 0.001800 Bohr |
| RMS Displacement | 位移的均方根 | < 0.001200 |

四个项目全部显示 `YES` → 优化收敛。

### 频率验证

在输出文件中找到：

```
Frequencies --   xxx.xxxx   xxx.xxxx   ...
```

**关键判断**：所有频率值必须为**正数**（单位 cm⁻¹）。如果有**虚频**（输出显示为负数，如 `-45.23`），说明此几何是鞍点而非极小点——意味着该坐标方向上能量还在下降，需要沿此方向位移后重新优化。

> **注意**：优化后的频率通常还会包含分子整体的**平动和转动模式**（6 个，对非线性分子），它们频率应当接近 0（通常 < 10 cm⁻¹）。如果出现了较大的平动/转动"虚频"（如 -10 左右），一般不影响判断（是数值噪音），但真正虚频的绝对值通常远大于 10 cm⁻¹。

## 1.3 激发态 S₁ 几何优化

### 输入文件

以 `exc ben opt.gjf`（苯 S₁ 激发态优化）为例：

```
%chk=F:\gaussian\practice benzene\exc ben opt.chk
# opt freq td=(nstates=10,root=1) b3lyp/6-31g(d) geom=connectivity

Title Card Required

0 1
 C                 -1.33923646   -0.39585301    0.00000469
 ...（S₁ 优化后的坐标）
```

与基态优化的区别仅在于 Route 行增加了 TD-DFT 关键字 `td=(nstates=10,root=1)`：

| 关键字 | 含义 |
|--------|------|
| `td` | 启用 **TD-DFT**（Time-Dependent DFT）计算。告诉 Gaussian："这不是基态 DFT，而是求解含时 Kohn-Sham 方程来计算电子激发" |
| `nstates=10` | 求解 **10 个最低的激发态**。数值越大越能完整覆盖感兴趣的能区，但也更耗时。对苯和萘，我们只需要 S₁（root=1），但多求几个态是好的——有时 S₁ 和 S₂ 可能发生态交换（State Swapping），追踪 10 个态能帮助发现 |
| `root=1` | **跟踪第 1 个激发态**（即 S₁）。在几何优化过程中，每步的结构在变，势能面变化可能导致 S₁ 和 S₂ 的能量顺序交换——如果没有 `root=`，Gaussian 会默认优化 S₁ 的几何，但当 S₁/S₂ 交叉时会"跟丢"。指定 `root=1` 后，Gaussian 通过波函数重叠（State Tracking Algorithm）确保**始终跟踪同一电子态**，即使它不再是最低的激发态 |

### 为什么激发态优化必须从基态优化后的几何出发？

回答分两层：

1. **逻辑上**：激发态优化需要一个初始猜测几何。基态优化给出的平衡几何是自然选择——分子在室温下确实待在基态极小点，吸收光子后才"跳跃"到 S₁ 势能面上

2. **技术上**：激发态 TD-DFT 计算需要基态 SCF（Self-Consistent Field）波函数作为参考态。基态 SCF 必须收敛——从基态优化后的几何开始，SCF 更容易收敛。随便给一个未优化的畸形几何可能让 SCF 收敛失败

3. **物理上**：如果从激发态未优化的几何开始，得到的只是那个几何下的垂直激发能，不是真正的绝热激发能（Adiabatic Excitation Energy）。绝热激发能 = S₁ 极小点能量 − S₀ 极小点能量，这两个极小点都必须是通过优化找到的

### 输出中如何区分各步数据

激发态 `opt freq td=(nstates=10,root=1)` 的输出包含多步，**必须注意区分**：

| 步数 | 分子几何 | 物理含义 |
|------|---------|---------|
| **Step 1**（第一次 TD-DFT） | 基态优化后的几何 | **垂直吸收能**（Vertical Absorption）：分子保持在基态几何，电子"瞬间"跃迁。这是吸收光谱的 0-0 参考位置 |
| **中间各步** | 向 S₁ 极小点移动 | 几何在松弛，体系沿 S₁ 势能面下降 |
| **最后一步**（`Stationary point found` 之后） | S₁ 极小点几何 | **绝热激发能**（Adiabatic Excitation）：S₁ 平衡几何下的激发能。这是发射谱的 0-0 参考位置 |

**重要**：提取结果时，必须取 **`Stationary point found` 之后的最后一步数据**，不能取第一步的数据。

> 例如，对于苯：第一步 TD-DFT（基态几何）给出的激发能可能略大于最后一步的值，因为基态几何下 S₁ 势能还没找到极小点。

## 1.4 S₁ → S₀ 发射能量计算

### 输入文件

以 `ben s1-s0.gjf` 为例：

```
%chk=F:\gaussian\practice benzene\s1 ben opt.chk
# td=(nstates=10,root=1) b3lyp/6-31g(d)

S1 emission from optimized geometry

0 1
 C    -1.369009   -0.404694   -0.000013
 C    -0.334017   -1.387938    0.000008
 ...（S₁ 优化收敛后的坐标）
```

注意三个关键点：

1. **Route 行中 `td=(nstates=10,root=1)` 不带 `opt`**——这不是优化，而是在**指定的几何坐标下做单点 TD-DFT 计算**。因为分子已经处于 S₁ 极小点，无需再优化

2. **不带 `geom=connectivity`**——坐标段后没有连接关系，直接空行结束。因为不是优化计算，Gaussian 无需内坐标转换，直接用给定的 Cartesian 坐标做 SCF + TD-DFT

3. **坐标必须是 S₁ 优化收敛后的几何**——见下面

### 为什么必须用 S₁ 优化收敛后的坐标？

想象势能面的示意图：

```
   能量
    ↑
    |     S₁  ─────●──── (S1极小点)
    |           ／      ＼
    |         ／          ＼
    |    S₀  ●────────────●
    |  (基态极小点)    (S₀几何下的基态)
    └─────────────────────────→ 核坐标
```

- 如果用了基态几何算 `td=(nstates=10,root=1)`，得到的是**垂直吸收能**——分子在基态极小点吸收光子
- 如果用 S₁ 极小点几何算，得到的是**垂直发射能**——分子在 S₁ 极小点发射光子回到 S₀ 势能面
- 两者能量不同！发射能 ≤ 吸收能（因为 S₁ 松弛后能量降低了）

### 如何通过 SCF 能量甄别几何是否正确

Gaussian TD-DFT 输出中，第一行 SCF 能量（基态 DFT 能量）可以帮你快速判断是否用了正确的几何：

| 几何 | 苯 SCF 能量（Hartree） |
|------|----------------------|
| 基态极小点 | -232.248650991 |
| S₁ 极小点 | -232.243642 |

**验证方法**：打开发射计算输出文件，找到第一个 SCF Done 行，看 SCF 能量。如果它是 `-232.248...`，说明几何退回到了基态极小点；如果它是 `-232.243...`，说明用的是 S₁ 极小点几何。

> **注意：SCF 能量 vs TD 总能量** —— SCF Done 行给出的是基态 DFT 单点能（即使计算了 TD-DFT），而 TD-DFT 输出中的 "Total Energy" 是 **SCF 能量 + 激发能**。对苯 S₁ 极小点：SCF = -232.243642，激发能 = 5.2715 eV = 0.193729 Hartree，TD 总能量 = -232.243642 + 0.193729 = -232.049913 ≈ -232.049919。两者相差约 0.19 Hartree，切勿混淆。
>
> 原理：在 S₁ 几何下，基态 SCF 能量必然**高于**基态极小点的能量（因为基态势能面上，偏离极小点 → 能量升高），所以 S₁ 几何下的 SCF 能量 > 基态 SCF 能量。（注意：Hartree 单位下负值更小 = 能量更低，所以 -232.243642 > -232.248650991。）

萘的对应值：基态极小点 SCF = -385.892706628，S₁ 极小点 SCF = -385.882453279。（对应 TD 总能量 = -385.739037941。）

## 1.5 独立频率计算（freq=savenm）

### 为什么需要？

FC 光谱计算需要两个关键输入：

1. **初始电子态和末态的简正模式**（Normal Mode）——即每个振动模式对应的原子位移矢量
2. **跃迁偶极矩**（Transition Dipole Moment）

Gaussian 的 `freq=savenm` 关键字会将频率计算结果以扩展格式输出（包括简正模坐标和约化质量），这些信息被 FC 模块（或外部程序 ezFCF）用来：

- 把 Cartesian 位移投影到简正模坐标上
- 计算 Huang-Rhys 因子（衡量每个振动模式在电子跃迁时几何位移的大小）
- 计算多维 Franck-Condon 积分

### S₀ vs S₁ 频率计算的区别

| 文件 | 任务 | 关键字 | 特点 |
|------|------|--------|------|
| `ben s1 freq.gjf` | S₁ 频率 | `freq=savenm td=(nstates=10,root=1)` | 频率计算在 **S₁ 势能面**上进行。输入几何是 S₁ 极小点 → 全部频率为正，无需分步 |
| `ben s0 freq.gjf` | S₀ 频率 | `--Link1--` 两步法 | 频率计算必须在 **S₀ 势能面**上进行（见下面的虚频问题） |

### `--Link1--` 两步法的原理

**问题背景**：对于 S₀ 频率计算，乍看使用 `freq=savenm td=(nstates=10,root=1)` 是合理的——因为我们需要 TD-DFT 计算来确定跃迁偶极矩。但这会引发一个严重问题。

#### 错误 2：`freq=savenm td=` 导致虚频

**现象**：S₀ 频率计算出现 **2 个虚频**

**原因分析**：

- `td=(nstates=10,root=1)` 告诉 Gaussian "对这个态（S₁）做频率计算"
- 频率计算的本质是：在当前几何下，沿各简正模方向计算能量的二阶导数
- 频率计算在哪个势能面上做，由 `td=` 的状态决定——`td=(nstates=10,root=1)` 意味着在 **S₁ 势能面**上算频率
- 但输入坐标是 S₀ 极小点，S₀ 极小点不是 S₁ 极小点 → 在 S₁ 势能面上，这个几何是"山坡上"的位置 → 某些方向的曲率为负 → 产生虚频

**解决方案**：用 `--Link1--` 把 TD-DFT（算跃迁偶极矩）和频率计算（算正常模）分成两个独立的 Gaussian job：

```
--Link1--
```

每一段是一个完整的 Gaussian 子计算（有自己的 Route 行和分子说明段），它们**顺序执行**，但 SCF 和波函数独立。

以 `ben s0 freq.gjf` 为例：

```
%mem=1200MB
%chk=F:\gaussian\practice benzene\ben s0 freq.chk
%nprocshared=4
# td=(nstates=10,root=1) b3lyp/6-31g(d)

benzene S0 TD-DFT - step 1

0 1
 C  -1.339236  -0.395853   0.000005
 ...（S₀ 几何坐标）

--Link1--
%mem=1200MB
%chk=F:\gaussian\practice benzene\ben s0 freq.chk
%nprocshared=4
# freq=savenm geom=check guess=read b3lyp/6-31g(d)

benzene S0 freq - step 2

0 1

（坐标由 geom=check 从 chk 读取，无需手写）
```

两步的作用：

| Step | 关键字 | 作用 | 写入 chk 的数据 |
|------|--------|------|----------------|
| 1 | `td=(nstates=10,root=1)` | 在基态几何做 TD-DFT 单点计算 | SCF 波函数 + **跃迁偶极矩** + 激发能 |
| 2 | `freq=savenm geom=check guess=read` | 从 chk 读取基态几何和 SCF 波函数，在 **S₀ 势能面**上做频率计算 | 简正模信息 + SCF 波函数 |

**关键**：Step 2 的 `freq=savenm` **不带 `td=`**！这意味着频率计算在 S₀ 势能面上进行，输入几何就是 S₀ 极小点 → 全部频率为正 → 虚频问题解决。

`geom=check` 让 Gaussian 从 `.chk` 文件中读取分子几何（Step 1 存储的），`guess=read` 让 SCF 从 chk 读取初始猜测波函数（加速收敛）。

> **注意**：Step 2 的 SCF 会**覆盖** chk 中的波函数。这产生了后续发射 FC 计算的致命问题（见 1.6 和 1.7 第 9 条故障）。

## 1.6 FC 光谱计算（Gaussian 内置）

### FC 原理简介

**Franck-Condon 原理**（弗兰克-康登原理）：

- 电子跃迁发生在 ~10⁻¹⁵ 秒的时间尺度上，而核运动发生在 ~10⁻¹³ 秒的尺度上
- **电子跃迁时，核坐标来不及改变**——这就是"垂直"跃迁的含义
- 光谱强度 **∝** 初始态和末态振动波函数的**重叠积分的平方**（FC 因子）

物理图像：

```
        初态势能面          末态势能面
         /    \              /    \
        /      \            /      \
    v"=0   v"=1  ...    v'=0   v'=1  ...

    |⟨ψ_v''|ψ_v'⟩|²  =  FC 因子
```

如果一个振动模式在电子跃迁前后**几何位移很大**（即两个势能面的极小点沿该模式方向偏移很多），那么该模式的 FC 序列（v"=0→v'=0, 1, 2, ...）就会包含多条显著的伴线。

#### Condon 近似 vs Herzberg-Teller

- **Condon 近似**（FC 框架）：假设跃迁偶极矩 μ 不随核坐标变化，即 μ = 常数。那么谱强度 ∝ FC 因子 |⟨ψ_v''|ψ_v'⟩|²
- **Herzberg-Teller (HT) 修正**：考虑 μ 随核坐标的一阶导数 ∂μ/∂Q。这允许**弱的**电子态"借用"近邻**强的**电子态的强度。对电偶极禁阻跃迁（如苯的 S₁ → S₀，f=0），FC 贡献为零，**全部强度来自 HT 贡献**

### `freq=(FC,ReadFC)` 工作原理

Gaussian 内置的 FC 光谱计算使用 `--Link1--` 两步法：

**Step 1**：在当前几何下做频率计算（初始态频率），结果存入 `.chk` 文件

- 吸收谱：S₀ 几何下 `freq`
- 发射谱：S₁ 几何下 `freq td=`

**Step 2**：`freq=(FC,ReadFC) geom=check guess=read`，Gaussian 会：
1. 从当前 chk（Step 1 存的那个）读取**初始态**的简正模信息
2. 从文件名指定的 chk 读取**末态**的简正模和跃迁偶极矩
3. 做 Duschinsky 旋转（将初始态和末态简正模互相投影）
4. 计算 FC 因子（多维递归算法）
5. 输出 stick spectrum：每行 = 相对能量 (cm⁻¹) + 强度

**末态 chk 的指定方式**：Step 2 坐标段后空一行，写末态 chk 的**绝对路径**：

```
0 1

F:\gaussian\naphthalene\nai s1 freq.chk
```

> **为什么必须用绝对路径？**见 1.7 节故障排除第 5 条。

### 四组 FC 计算对照表

| 文件 | 光谱 | Step 1 | Step 2 读的 chk | 可用？ |
|------|------|--------|-----------------|:-----:|
| `ben absorption.gjf` | 苯吸收 | S₀ 几何 `freq` | `ben s1 freq.chk` | ✅ |
| `ben emission.gjf` | 苯发射 | S₁ 几何 `freq td=` | `ben s0 freq.chk` | ❌ |
| `naph absorption.gjf` | 萘吸收 | S₀ 几何 `freq` | `nai s1 freq.chk` | ✅ |
| `naph emission.gjf` | 萘发射 | S₁ 几何 `freq td=` | `nai s0 freq.chk` | ❌ |

> **为什么只有吸收谱可用？**见 1.7 节故障排除第 9 条（最关键发现）。

## 1.7 故障排除记录

以下记录了本项目遇到的 10 个典型错误和解决方案。每个条目以「现象 → 原因分析 → 解决方案 → 为什么这样修改」格式呈现。

---

### 错误 1：`freq=(FCHT,readFCHT,absorption)` → 语法错误

**现象**：Gaussian 报语法错误，不识别这些关键字。

**原因分析**：`FCHT`（Franck-Condon + Herzberg-Teller）和 `absorption` 是 G16 **后期版本**才加入的关键字（约 Rev C.01 开始）。本项目用的 G16 Rev A.03（2016 年早期版本）中这些关键字尚未实现。类似地，`ReadFCHT`、`emission` 也不可用。

**解决方案**：改用 `freq=(FC,ReadFC)` 组合（FC 模式会在 G16 早期版本中存在），并通过 `--Link1--` 两步法拆分计算步骤。发射谱则完全放弃 G16 内置方案，改用 ezFCF。

**为什么这样修改**：
- `FC`（Franck-Condon）计算在 G16 的早期版本中已可用
- `ReadFC` 让 Step 2 从外部 chk 读取末态数据
- 至于 HT 修正和发射谱，ezFCF 是更好的替代方案

---

### 错误 2：`freq=(ReadFCHT)` → 语法错误

**现象**：与错误 1 相同。

**原因分析**：同上，早期版本不支持。

**解决方案**：同错误 1。

---

### 错误 3：`freq=(FC,absorption) td=...` → Error 2070

**现象**：Gaussian 报 Error 2070（内部逻辑错误）。

**原因分析**：`absorption` 关键字是后期版本才有的功能。G16A03 中尝试在一条命令中同时做频率 + FC + 指定光谱类型会导致内部路由错误。

**解决方案**：去掉 `absorption`、`emission` 等高级关键字，只用基础的 `freq=(FC,ReadFC)`。

---

### 错误 4：`freq=(FC,ReadFC)` 单步 → FileIO 错误

**现象**：Gaussian 报文件 I/O 错误，找不到 chk。

**原因分析**：`freq=(FC,ReadFC)` 设计为两步工作流。如果只用一条命令（不拆分 `--Link1--`），Gaussian 在同一 job 中既要计算频率、又要读取末态 chk、又要做 FC 积分——这些操作的中间文件读写时序冲突，导致 FileIO 错误。

**解决方案**：用 `--Link1--` 拆分两步（Step 1 = 频率计算，Step 2 = FC 读取 + 积分计算）。

---

### 错误 5：相对路径 → FileIO

**现象**：即使正确拆分了两步，仍然报 FileIO 错误（找不到末态 chk）。

**原因分析**：Gaussian 运行时在**临时 scratch 目录**（通常是 `/tmp/` 或 `%TEMP%` 下的一个子目录，以 `Gau-` 开头）中执行。它把你写的输入文件复制到 scratch 目录中运行，再把输出复制回来。因此，相对路径 `ben s1 freq.chk` 会被在 scratch 目录中查找——而它当然不在那里。

**解决方案**：chk 路径必须用**绝对路径**。例如：
```
F:\gaussian\practice benzene\ben s1 freq.chk
```

---

### 错误 6：`total intensity is null`（第 1 次）

**现象**：`ben emission.gjf` 的 Step 2 报错 `total intensity is null`。

**原因分析**：ReadFC 从 `ben s0 freq.chk` 中读取末态数据，但当时的 `ben s0 freq.gjf` 只是纯基态频率计算（`freq=savenm` 不带 `td=`），因此 chk 文件中**没有跃迁偶极矩**。FC 模块找不到跃迁偶极矩 → 总强度 = 0 → 报错。

**解决方案**：`ben s0 freq.gjf` 改为 `--Link1--` 两步法：
- Step 1：`td=(nstates=10,root=1)`，在 S₀ 几何下做 TD-DFT，把跃迁偶极矩写入 chk
- Step 2：`freq=savenm geom=check guess=read`，做纯 S₀ 频率计算

这样 chk 中有跃迁偶极矩了。

---

### 错误 7：S₀ freq 出现 2 个虚频（错误 2 的详细版）

**现象**：S₀ 频率计算输出中出现 2 个虚频（频率值为负数）。

**原因分析**：见 1.5 节详细分析。核心问题：`freq=savenm td=(nstates=10,root=1)` 让频率计算在 S₁ 势能面上进行，而 S₀ 几何不是 S₁ 极小点。

**解决方案**：S₀ 频率计算必须拆分为 `--Link1--` 两步，Step 2 的 `freq=savenm` 不带 `td=`。

**为什么这样修改**：频率计算的势能面由 `td=` 决定。不加 `td=` 默认就是基态势能面，而输入的几何是基态极小点 → 不会有虚频。

---

### 错误 8：`ntran open failure`

**现象**：Gaussian 报 `ntran open failure` 错误。

**原因分析**：`ben s0 freq.gjf` 的 `%chk` 曾被错误配置为指向 `ben opt.chk`：
```
%chk=F:\gaussian\practice benzene\ben opt.chk    ← 错误！
```
这使得 S₀ 频率计算的输出被写入了基态优化的 chk 文件（覆盖了它），而 ReadFC 在 Step 2 中找不到正确的 chk 文件。

**解决方案**：修正 `%chk` 路径，指向正确的文件名：
```
%chk=F:\gaussian\practice benzene\ben s0 freq.chk
```

**另外**：由于 `ben opt.chk` 被覆盖了，需要重新跑 `ben opt.gjf` 来恢复它。

---

### 错误 9：`total intensity is null`（第 2 次，萘发射——最关键发现）

**现象**：萘发射 `naph emission.gjf` 报 `total intensity is null`，FC 模块明确报告：
```
No electronic transition dipole moment has been found in F:\gaussian\naphthalene\nai s0 freq.chk
```

**原因分析**（这是本项目最重要的技术发现）：

回顾错误 6 的解决方案：我们将 `--Link1--` 两步法的 Step 1 改为 TD-DFT（写入跃迁偶极矩），Step 2 再做纯频率计算。**逻辑上**这应该让 chk 保留跃迁偶极矩——但这里有一个**关键的时序问题**：

```
--Link1-- Step 1: td=(nstates=10,root=1)  →  写入: SCF波函数 + 跃迁偶极矩
--Link1-- Step 2: freq=savenm geom=check guess=read  →  写入: SCF波函数（覆盖Step 1的波函数）
                                                                 + 简正模信息
                                                        → 跃迁偶极矩？被覆盖了！
```

Step 2 需要重做 SCF（因为频率计算需要收敛的基态波函数作为 Hessian 求解的参考），而 SCF 计算会**写入**相同 chk 的波函数区域——**Gaussian 的 chk 文件中，SCF 波函数和 TD-DFT 跃迁偶极矩存在同一结构中**——后执行的 Step 2 SCF 覆盖了 Step 1 的 TD-DFT 结果。

**适用性限制**：
- **吸收谱**：末态 chk 是 `ben s1 freq.chk`，它来自 `freq=savenm td=(nstates=10,root=1)` 一步到位（S₁ 频率在 S₁ 几何下算，没有分步覆盖问题）→ **跃迁偶极矩完好保留** → ✅ 可用
- **发射谱**：末态 chk 是 `ben s0 freq.chk`，它来自 `--Link1--` 两步法，Step 2 SCF 覆盖了 Step 1 TD-DFT → **跃迁偶极矩丢失** → ❌ 不可用

**结论**：G16A03 内置 FC 模块的 `--Link1--` 方案**仅对吸收谱有效，对发射谱根本不可用**。这是 G16 早期版本的设计缺陷。

**解决方案**：弃用 G16 内置 FC 的发射谱计算，改用外部程序 **ezFCF**（见第二部分）。

---

### 错误 10：`ben opt.chk` 被覆盖

**现象**：`ben opt.chk` 的内容不再是基态优化结果。

**原因分析**：`ben s0 freq.gjf` 的 `%chk` 曾错误指向 `ben opt.chk`（见错误 8），导致该 chk 被 S₀ 频率计算覆盖。

**解决方案**：重跑 `ben opt.gjf` 来恢复 `ben opt.chk`。**已执行并完成。**

# 第二部分：ezFCF 工作流

## 2.1 为什么需要 ezFCF

经过 1.7 节的故障排除，我们得出以下结论：

| 能力 | G16A03 内置 FC | ezFCF v1.3 |
|------|:---:|:---:|
| 吸收谱（允许跃迁） | ✅ | ✅ |
| 吸收谱（禁阻跃迁，需 HT） | ❌ 不支持 HT | ✅ `-ht` |
| 发射谱（允许跃迁） | ❌ 跃迁偶极矩被覆盖 | ✅ |
| 发射谱（禁阻跃迁，需 HT） | ❌ 同上 | ✅ `-ht` |
| Duschinsky 变换 | 内置 | 自动处理 |

**ezFCF**（USC Krylov 组开发）是一个开源的 Franck-Condon / Herzberg-Teller 因子计算程序。与 G16 内置模块相比的额外优势：

- ~~支持 `--spec_type emission`~~（ezFCF v1.3 **不支持**此命令行参数，发射谱需用 `fix_emission_sticks.py` 手动翻转 stick 方向，见 2.5 节）
- 支持 Herzberg-Teller 修正（`-ht`），对禁阻跃迁（如苯 S₁ → S₀，f=0）可以获得非零强度
- 自动 Duschinsky 变换（将初始态和末态简正模互相投影），处理模式混合
- 独立于 Gaussian 的输出文件，不依赖 chk 二进制格式

> **注意**：ezFCF 仅支持 **Linux / Mac** 系统。Windows 用户需通过 **WSL**（Windows Subsystem for Linux）运行。

## 2.3 输入准备：make_xml.py

`make_xml.py` 是 ezFCF 提供的 Python 脚本（位于 `bin/make_xml.py`），功能是从 Gaussian 频率计算输出文件中提取以下信息并生成 XML 输入文件：

- 初始态和末态的简正模频率（cm⁻¹）
- 简正模坐标（原子位移矢量）
- 几何坐标
- 原子质量等

### 参数顺序（重要！）

```bash
python3 make_xml.py <输出.xml> <初态.out> <末态.out>
```

注意：**第一个参数是输出的 XML 文件名**，这与很多命令行工具的习惯相反（通常输出文件名是最后一个参数）。

### 初态/末态对应关系

| 光谱类型 | 初态（Initial State） | 末态（Target/Final State） |
|---------|----------------------|---------------------------|
| **发射谱** | S₁ 频率输出（`ben s1 freq.out`） | S₀ 频率输出（`ben s0 freq.out`） |
| **吸收谱** | S₀ 频率输出（`ben s0 freq.out`） | S₁ 频率输出（`ben s1 freq.out`） |

> 物理直觉：发射时，分子从 S₁ 出发 → 到达 S₀——所以 S₁ 是初态、S₀ 是末态。吸收时相反。

### 读取 `--Link1--` 输出的注意事项

当输入文件包含 `--Link1--` 多步输出时，`make_xml.py` 取**最后一步**（频率部分）的数据。确保频率步骤没有被中断——如果 `--Link1--` 输出中频率步骤因超时或崩溃而未完成，该文件不可用于 `make_xml.py`。

### 手动设置激发能

`make_xml.py` **不会**设置激发能——它只在 XML 中写入占位符 `1.0 eV`。必须在运行 ezFCF 前手动修改：

```bash
# 使用 sed 替换激发能
sed -i 's|<excitation_energy units="eV"> 1 </excitation_energy>|<excitation_energy units="eV"> 3.9025 </excitation_energy>|' naph_emission.xml
```

**激发能的来源**：S₁ 优化最后一步的 TD-DFT 输出中的绝热激发能。

| 分子 | 发射激发能（S₁→S₀） | 吸收激发能（S₀→S₁） |
|------|:-----------------:|:-----------------:|
| 苯 | 5.2715 eV | 5.2715 eV（绝热）= 垂直吸收同（S₁ 态几何位移极小、重组能很低，导致 Stokes shift 可忽略，绝热激发能 ≈ 垂直吸收能）|
| 萘 | 3.9025 eV | 4.0593 eV（垂直吸收，基态几何）|

### 四组完整命令

#### (1) 萘发射谱（允许跃迁，FC 主导，可选 HT）

## 2.5 发射 stick 翻转：fix_emission_sticks.py

### 问题

**ezFCF v1.3 不支持 `spectrum_type` 属性**——XML 中设置无效，命令行 `--spec_type` 也不支持。无论输入文件表示的是发射还是吸收，ezFCF 内部默认按**吸收方向**输出 stick spectrum：即所有振动伴线的能量位于 **0-0 跃迁的高能侧**（E ≥ E₀₀）。

但物理上，**发射光谱**的振动伴线应该位于 0-0 的**低能侧**（E ≤ E₀₀）——分子从 S₁ 的 v'=0 水平发射光子后，到达 S₀ 的 v"≥0 的振动激发态，释放的光子能量 = 0-0 能量 - 末态振动能量 < 0-0 能量。

### 解决方案

将发射 stick energy 关于 E₀₀ 做**镜像翻转**：

```
E_new = 2 × E₀₀ - E_old
```

例如：如果 E₀₀ = 3.9025 eV，某条 stick 的原始能量是 3.9650（位于高能侧），翻转后变为 2×3.9025 - 3.9650 = 3.8400 eV（低能侧）。

### 脚本用法

```bash
python3 fix_emission_sticks.py <输入> <0-0_eV> [输出]
```

参数：
- `<输入>`：ezFCF 输出的 `spectrum_parallel` 文件
- `<0-0_eV>`：0-0 跃迁能量（单位 eV），即激发能
- `[输出]`：可选，默认覆盖输入文件

示例：
```bash
python3 fix_emission_sticks.py naph_emission.xml.spectrum_parallel 3.9025
```

### 脚本原理

`fix_emission_sticks.py` 读取 ezFCF 输出的 stick spectrum 文件，对每行第一个数值（能量 eV）执行镜像翻转：

```python
E_new = 2 * e00 - E  # 关于 0-0 镜像翻转
```

以下能量范围的 stick 被保留：
- `E_new < e00` → 发射红侧（光子能量低于 0-0）
- `E_new == e00` → 恰好是 0-0 跃迁（0-0 本身关于自己对称）

## 2.6 高斯展宽：broaden_spectrum.py

### 展宽参数

- **FWHM**（Full Width at Half Maximum，半峰全宽）= **400 cm⁻¹**
- 对应的标准差 σ = FWHM / (2√(2 ln 2)) = 400 / 2.35482 = **169.9 cm⁻¹**

> **为什么选择 400 cm⁻¹？**
>
> 实验上，室温下有机分子在溶液中的电子光谱的振动展宽通常在 300-500 cm⁻¹ 范围内（主要是溶剂分子的不均匀展宽和低频模式的热占据）。400 cm⁻¹ 是一个合理的中间值。如果需要模拟气相高分辨光谱，可以降低到 50-100 cm⁻¹。

### 自动格式识别

`broaden_spectrum.py` 自动检测吸收 stick 文件的格式：

```python
if abs(abs_raw[0][0]) > 0.1:
    # 第一个值 > 0.1 → ezFCF 格式（绝对 eV）
    abs_cm = [(e * EV_TO_CM, i) for e, i in abs_raw]
else:
    # 第一个值很小 → G16 格式（相对 cm⁻¹）
    g16_00_rel = abs_raw[0][0]  # G16 自身的 0-0 位置（相对值）
    # 用共享 0-0 重新对齐
    abs_cm = [((e00_ev + (rel_cm - g16_00_rel) / EV_TO_CM) * EV_TO_CM, i)
              for rel_cm, i in abs_raw]
```

**格式判定阈值**：第一个 stick 的绝对值 > 0.1 → ezFCF 绝对 eV 格式；否则 → G16 相对 cm⁻¹ 格式。

**G16 格式的重对齐**：
- G16 吸收 stick 的"相对能量"是相对于 G16 自身计算的 0-0 位置
- 但 G16 计算的 0-0 可能与绝热激发能不完全一致（原因：FC 计算中的 0-0 位置基于频率差 ΔZPE 而 shift）
- 脚本用**共享的 0-0 能量**（从命令行参数传入）替代 G16 自身的 0-0，确保发射和吸收曲线在同一个 0-0 参考下对齐

### 输出 CSV 格式

输出文件 `<前缀>_broadened.csv`，包含 5 列：

| 列 | 名称 | 含义 |
|----|------|------|
| A | `Wavelength_nm` | 波长 (nm)，λ = 1240/E(eV) |
| B | `Energy_eV` | 能量 (eV) |
| C | `Wavenumber_cm-1` | 波数 (cm⁻¹)，E(eV) × 8065.544 |
| D | `Emission_Intensity` | 发射展宽强度（归一化前） |
| E | `Absorption_Intensity` | 吸收展宽强度（归一化前） |

### 运行命令

```bash
cd /mnt/f/gaussian

# 苯 (0-0 = 5.2715 eV)
python3 broaden_spectrum.py "practice benzene/ben_emission_stick.txt" \
    "practice benzene/ben_abs_sticks.txt" 5.2715 ben

# 萘 (0-0 = 3.9025 eV)
python3 broaden_spectrum.py "naphthalene/naph_emission_stick.txt" \
    "naphthalene/naph_abs_sticks.txt" 3.9025 naph
```

## 2.7 苯 vs 萘的关键物理差异

这是本项目最重要的物理洞察。

### 对称性与跃迁选择定则

**苯**：点群 = **D₆h**（平面正六边形）

- 基态 S₀：电子组态 ...(a₂u)²(e₁g)⁴，总对称性 = **A₁g**（全对称表示）
- 第一激发态 S₁：HOMO(e₁g) → LUMO(e₂u) 单电子激发，总对称性 = **B₂u**
- **S₁ (B₂u) → S₀ (A₁g) 跃迁**：跃迁算符（电偶极矩）的三个分量在 D₆h 中属于 (E₁u 和 A₂u)。B₂u ⊗ A₁g = B₂u，而 (E₁u, A₂u) 中不含 B₂u → **f = 0，严格禁阻**
- **Condon 近似下的零强度**：即使考虑 Franck-Condon 振动耦合，FC 框架中跃迁偶极矩仍是对称性禁阻的常数 → 所有 FC-only 的 stick 强度必为零

**萘**：点群 = **D₂h**（平面矩形）

- 基态 S₀：A_g
- 第一激发态 S₁：B₂u
- S₁ (B₂u) → S₀ (A_g) 跃迁：B₂u ⊗ A_g = B₂u，而电偶极矩分量包含 B₂u 表示 → **f ≠ 0，允许跃迁**

### FC 与 HT 的本质区别

| 机制 | 数学表述 | 物理图像 | 适用条件 |
|------|---------|---------|---------|
| **Franck-Condon (FC)** | μ₀₀ · |⟨ψ_v'|ψ_v"⟩|² | 跃迁偶极矩 μ 视为常数（Condon 近似），强度源于振动波函数重叠 | μ ≠ 0（允许跃迁）|
| **Herzberg-Teller (HT)** | Σ_k (∂μ/∂Q_k) · ⟨ψ_v'|Q_k|ψ_v"⟩ | 跃迁偶极矩对核坐标的一阶导数，允许"借用"邻近允许跃迁的强度 | 任何跃迁（即使 μ = 0），μ=0 时是唯一贡献 |

### HT 打破镜像对称

Franck-Condon 近似假设跃迁偶极矩是常数 → **吸收和发射关于 0-0 跃迁必须呈镜像对称**（这是 FC 框架的形式推论）。

HT 修正引入 ∂μ/∂Q：它对**不同振动模式的选择规则不同**。某些模式在吸收中贡献显著而在发射中不显著（或反之），因为 ∂μ/∂Q 的正负号在初态和末态简正模投影中的"投影方向"不同。

### 苯的实际表现

吸合 HT 计算的苯吸收 stick spectrum 显示：

- **0-0 跃迁**（5.2715 eV）：强度 2.0×10⁻³（极弱，因为它本身禁阻）
- **吸收最强峰**：5.7496 eV（4v11 泛频），强度 1.04×10⁻¹——偏离 0-0 达 **0.48 eV**！

| 能量 (eV) | 相对强度 | 归属 | 距 0-0 |
|----------:|:-------:|------|:-----:|
| 5.2715 | 0.0020 | 0-0 | 0 |
| 5.3910 | 0.0121 | 1v11 | +0.12 eV |
| 5.5106 | 0.0361 | 2v11 | +0.24 eV |
| 5.6301 | 0.0713 | 3v11 | +0.36 eV |
| **5.7496** | **0.1045** | **4v11** | **+0.48 eV** |

模式 11（ν11）的 4 量子泛频是苯吸收谱中最强的特征峰——这是 HT 机制在该模式上选择性"借用"邻近态强度的结果。发射谱则完全不同：0-0 是最强峰（0.403），振动伴线弱得多。

> **这是真实物理特征，不是计算错误。** HT 不对称性是苯 S₁ 禁阻跃迁的本质属性，也已被实验验证（见文献中苯 UV 光谱的 ν11 振电序列）。

### 萘的对照

萘是允许跃迁（f=0.0748），FC 主导。吸收/发射关于 0-0 高度镜像对称，0-0 是谱中最强峰——这是教科书级的 FC 镜像对称案例。

## 3.2 X 轴设置

### 为什么用 Energy_eV 而非 Wavelength_nm？

- **波长 λ = 1240 / E** 是非线性变换。如果直接在 nm 空间做镜像对称，同一个能量差 δE 在不同波长处对应的 δλ 不同 → 对称性在波长空间被扭曲
- **eV 空间是线性的**：δE 是常数变换（δE = δE） → FC 框架下的镜像对称性（如果有的话）在 eV 空间完美呈现

### 操作步骤

1. 右键 Col(B) "Energy_eV" → **设置为 → X**
2. 双击 X 轴 → **刻度** → 勾选 **反转**（勾选后高能在左、低能在右）

> **为什么反转 X 轴？**
>
> 光谱学常规是**高能量（短波长）在左、低能量（长波长）在右**。反转 X 轴后，能量从左到右降低，波长从左到右增加，符合典型光谱图的阅读习惯。

## 3.3 双 Y 轴叠加

1. 选中 Col(D) "Emission_Intensity" + Col(E) "Absorption_Intensity"
2. **绘图 → 多面板/多轴 → 双Y轴**

> **为什么用双 Y 轴而非单 Y 轴？**
>
> 发射和吸收的绝对强度量级可能相差很大（取决于计算条件、分子跃迁特性等）。双 Y 轴让两个谱各自独立缩放，可以并排比较谱形（如镜像对称性），而不受绝对强度的影响。如果两个谱放在同一个 Y 轴上，较弱的谱会被"压扁"到无法辨认。

## 3.4 样式设置

- 发射曲线 (Emiss)：**红色**，线宽 1.5-2
- 吸收曲线 (Abs)：**蓝色**，线宽 1.5-2
- 双击曲线 → 线 → 颜色和宽度

样式建议：
- 颜色使用"红-蓝"对比色，直观区分发射/吸收

- 可添加轻微的 anti-aliasing（抗锯齿）

- 结论：苯是教科书的"HT 诱导"禁阻跃迁案例。HT 打破了镜像对称，揭示了电子态耦合效应

### 泛函/基组误差提醒

B3LYP/6-31G(d) 是常用组合，但有已知系统误差：
- 有机分子的激发能倾向于被**低估** 0.3-0.5 eV（B3LYP 的 CT 误差）
- 苯的 S₁ 实验值是 ~4.9 eV（而非我们算的 5.27 eV），萘的 S₁ 实验值是 ~3.97 eV（而非 3.90 eV），差异在 TD-DFT 预期范围内
- 如需更高精度，可考虑双杂化泛函（如 ωB97X-D）或 ADC(2)/CC2 等波函数方法
