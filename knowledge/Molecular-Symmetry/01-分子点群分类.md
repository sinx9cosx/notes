# 分子点群分类

## 点群

<mark style="background: #ADCCFFA6;">点群</mark>：分子全部对称操作构成的集合，以一个 Schoenflies 符号命名。

分子的全部对称元素（$C_n$、$\sigma$、$i$、$S_n$）都通过同一个点；有时还共有一条线或一个面，但总有一个公共点，故称点群。

符号只由对称元素决定，与分子组成无关：$BCl_3$ 与 $BF_3$ 同为 $D_{3h}$，$XeF_4$ 与 $[PtCl_4]^{2-}$ 同为 $D_{4h}$。

公共点落在分子中的位置随构型而定：富马酸（$C_{2h}$）在 $C=C$ 键中点，夹心结构（$D_{5d}$）在中心金属原子上。

五种对称元素与对称操作的定义见 [[0-对称操作]]。

## Schoenflies 符号

符号由三段拼成，$n$ 与 $y$ 同作下标：$C_{2v}$、$D_{3h}$、$D_{3}$。

| 位置 | 取值 | 判据 |
| --- | --- | --- |
| 数字 | $n$ | 主轴（最高阶 $C_n$）的阶，约定竖直 |
| 大写字母 | $C$、$D$ | 主轴外无 $n$ 个垂直 $C_2$ 取 $C$，有取 $D$ |
| 小写字母 | $h$、$v$、$d$、省略 | 有 $\sigma_h$ 取 $h$；$C$ 群有 $n\sigma_v$ 取 $v$；$D$ 群有 $n\sigma_d$ 取 $d$；无面省略 |

$n$ ：主轴的阶，无单位
$\sigma_h$ ：垂直于主轴的水平面
$\sigma_v$ ：含主轴的竖直面，共 $n$ 个，只用于 $C$ 群
$\sigma_d$ ：含主轴、夹在相邻 $C_2$ 之间的对角面，共 $n$ 个，只用于 $D$ 群

$h$ 优先于 $v$ 与 $d$：重叠式乙烷有 $\sigma_h$ 与含主轴的竖直面，小写字母取 $h$，记 $D_{3h}$，不记 $D_{3d}$。

三段读法要求唯一最高阶的主轴：$C_{\infty v}$、$D_{\infty h}$ 的轴无限阶，$T_d$、$O_h$、$I_h$ 有多组等阶轴，均单列。

## C 群

主轴外无 $n$ 个垂直 $C_2$，首位字母取 $C$。

$$\begin{aligned}
\sigma_h\ \text{存在} &: \quad C_{nh}\\
\sigma_h\ \text{不存在},\ n\sigma_v\ \text{存在} &: \quad C_{nv}\\
\text{两种面都不存在} &: \quad C_{n}
\end{aligned}$$

例：$H_2O$ 为 $C_{2v}$；$NH_3$ 为 $C_{3v}$；平面 $B(OH)_3$ 为 $C_{3h}$；富马酸为 $C_{2h}$；$H_2O_2$ 与顺式 $[Co(en)_2Cl_2]^+$ 只有 $E$ 与一个 $C_2$，为 $C_2$。

平面分子必有分子平面这一镜面。主轴垂直于分子平面时该面为 $\sigma_h$：$B(OH)_3$ 的 $C_3$ 轴垂直于分子平面，归 $C_{3h}$；$H_2O$ 的 $C_2$ 轴在分子平面内，该面为 $\sigma_v$，归 $C_{2v}$。

## D 群

主轴外有 $n$ 个与主轴垂直的 $C_2$，首位字母取 $D$。

$$\begin{aligned}
\sigma_h\ \text{存在} &: \quad D_{nh}\\
\sigma_h\ \text{不存在},\ n\sigma_d\ \text{存在} &: \quad D_{nd}\\
\text{两种面都不存在} &: \quad D_{n}
\end{aligned}$$

例：$BCl_3$ 为 $D_{3h}$；平面四方分子为 $D_{4h}$；苯为 $D_{6h}$；$[Co(en)_3]^{3+}$ 为 $D_3$；交错式乙烷为 $D_{3d}$。

$n$ 重交错结构一律归 $D_{nd}$：$C_2H_6$ 为 $D_{3d}$，$Mn_2(CO)_{10}$ 为 $D_{4d}$。

$D_{nd}$ 的 $C_2$ 轴穿行于原子之间，不沿键轴，需模型或沿主轴俯视的图才易看出。

## 特殊点群

高对称分子的点群单列，不按三段符号拆读。

| 点群 | 结构 | 例 |
| --- | --- | --- |
| $C_{\infty v}$ | 直线形，无 $\sigma_h$ | $HCl$、$CO$ |
| $D_{\infty h}$ | 直线形，有 $\sigma_h$ | $H_2$、$CO_2$ |
| $T_d$ | 正四面体 | $CH_4$、$CCl_4$ |
| $O_h$ | 正八面体 | $SF_6$ |
| $I_h$ | 正二十面体 | $C_{60}$ |

$T_d$ 指整个分子的对称性：$CH_4$、$CCl_4$ 为 $T_d$，$CHCl_3$ 为 $C_{3v}$。

直线形分子的 $\sigma_h$ 垂直于分子轴，只在两端原子相同时存在。

## 低对称群

只有一两个对称元素的分子单列符号。

| 对称元素 | 点群 |
| --- | --- |
| $E$、$i$ | $C_i$ |
| $E$、$\sigma$ | $C_s$ |
| $E$、$S_{2n}$ | $S_{2n}$ |
| 仅 $E$ | $C_1$ |

$S_{2n}$ 一行指除该轴的幂所生元素外无别的元素：$S_4$ 的幂为 $S_4$、$C_2$、$S_4^3$、$E$，点群记 $S_4$。

$S_6$ 的幂含 $C_3$ 与 $i$（$S_6^2\equiv C_3$，$S_6^3\equiv i$），$S_6$ 与 $C_{3i}$ 是同一个点群。

## 点群判定流程

只检验少数关键元素，命中即停。

$$\begin{aligned}
&\text{1. 特殊点群}\\
&\quad \text{直线形，无 }\sigma_h\Rightarrow C_{\infty v};\quad \text{有 }\sigma_h\Rightarrow D_{\infty h}\\
&\quad \text{正四面体}\Rightarrow T_d;\quad \text{正八面体}\Rightarrow O_h;\quad \text{正二十面体}\Rightarrow I_h\\
&\text{2. } C_n\\
&\quad \text{无 } C_n:\ \sigma\Rightarrow C_s;\quad i\Rightarrow C_i;\quad \text{皆无}\Rightarrow C_1\\
&\quad \text{有 } C_n:\ \text{最高阶者为竖直主轴，其阶记为 } n\\
&\text{3. } S_{2n}\ \text{与主轴共轴}\\
&\quad \text{无 } S_{2n}\ \text{或另有元素}\Rightarrow\text{续判};\quad \text{轴外无元素}\Rightarrow S_{2n}\\
&\text{4. 主轴外 } nC_2\\
&\quad \text{有}:\ \sigma_h\Rightarrow D_{nh};\quad n\sigma_d\Rightarrow D_{nd};\quad \text{无面}\Rightarrow D_n\\
&\quad \text{无}:\ \sigma_h\Rightarrow C_{nh};\quad n\sigma_v\Rightarrow C_{nv};\quad \text{无面}\Rightarrow C_n
\end{aligned}$$

第 2 步定下的 $n$ 贯穿第 3、4 步，第 4 步的 $nC_2$、$n\sigma$ 都用这个 $n$。

流程不列全部对称操作，只查足以定群的关键元素。

## 例题

判定交错式乙烷 $C_2H_6$ 的点群。

$$\begin{aligned}
&\text{1. 非直线形、非正多面体，不入特殊点群}\\
&\text{2. 有 } C_3,\ n=3\\
&\text{3. } S_6\ \text{与 } C_3\ \text{共轴，另有 } 3C_2,\ 3\sigma_d\Rightarrow\text{续判}\\
&\text{4. 有 } 3C_2\Rightarrow D\ \text{群；无 }\sigma_h,\ \text{有 } 3\sigma_d\Rightarrow D_{3d}
\end{aligned}$$

结果：$D_{3d}$。
