# 直积

## 定义

<mark style="background: #ADCCFFA6;">直积</mark>：取 $\Gamma_1$ 的基 $f_1,\dots,f_m$ 与 $\Gamma_2$ 的基 $g_1,\dots,g_n$，全部 $mn$ 个积函数 $f_ig_j$ 在群操作下张成的表示（即积函数张成的空间），记为 $\Gamma_1\otimes\Gamma_2$。维数相乘：
$$
\dim(\Gamma_1\otimes\Gamma_2)=\dim\Gamma_1\cdot\dim\Gamma_2=mn
$$

$m$ ：$\Gamma_1$ 的维数
$n$ ：$\Gamma_2$ 的维数

特征标<mark style="background: #FFF3A3A6;">逐类相乘</mark>：
$$
\chi(R)=\chi_1(R)\chi_2(R)
$$

$\chi(R)$ ：直积在操作 $R$ 上的特征标，量纲一
$\chi_1(R)$、$\chi_2(R)$ ：两因子表示在 $R$ 上的特征标

缘由：直积的表示矩阵是两因子矩阵的 Kronecker 积（分块矩阵），迹等于两迹之积（[[03-特征标#特征标的迹定义]]）。全对称表示的特征标全为 $1$，在直积中相当于 $1$：$A_1\otimes\Gamma=\Gamma$。

## 与直和的对比

| 项目  | 直和 $\Gamma_1\oplus\Gamma_2$ | 直积 $\Gamma_1\otimes\Gamma_2$ |                 |              |
| --- | --------------------------- | ---------------------------- | --------------- | ------------ |
| 作用  | 两组基拼成更大的基                   | 两组基两两相乘生成积函数基                |                 |              |
| 维数  | $m+n$，相加                    | $mn$，相乘                      |                 |              |
| 特征标 | $\chi_1(R)+\chi_2(R)$       | $\chi_1(R)\chi_2(R)$         |                 |              |
| 记号  | $\oplus$                    | $\otimes$                    |                 |              |


## 直积的约化

直积一般可约，约化公式与 [[04-可约和不可约表示#约化|约化]] 相同，只把 $\chi_R(k)$ 换成乘积 $\chi_1(k)\chi_2(k)$：
$$
a_i=\frac{1}{h}\sum_k N_k\,\chi_1(k)\chi_2(k)\chi_i(k)
$$

$a_i$ ：不可约表示 $i$ 在直积中出现的次数，非负整数
$h$ ：群阶
$N_k$ ：类 $k$ 中的操作数
$\chi_1(k)\chi_2(k)$ ：两因子表示的特征标在类 $k$ 上的乘积

一维×一维仍是一维，必不可约，直接查表相乘（如 $C_{2v}$ 中 $A_2\otimes B_1=B_2$）；只要有一个因子是一维表示，直积就仍不可约；两个因子都非一维时直积必可约，须按上式分解。

## 核心性质

<mark style="background: #ADCCFFA6;">含全对称表示的充要条件</mark>：$\Gamma_1$、$\Gamma_2$ 为不可约表示时
$$
\Gamma_1\otimes\Gamma_2\supset\Gamma_{\text{全对称}}\iff\Gamma_1=\Gamma_2
$$

$\Gamma_{\text{全对称}}$ ：全对称不可约表示，如 $C_{2v}$ 的 $A_1$、$D_{4h}$ 的 $A_{1g}$

依据：不可约表示的特征标满足正交关系 $(1/h)\sum_k N_k\chi_i(k)\chi_j(k)=\delta_{ij}$，取 $i$ 为全对称表示（$\chi_i=1$）即得。

07 的判据「$\Gamma_{\text{vib}}\otimes\Gamma_q\supset\Gamma_{\text{全对称}}\iff\Gamma_{\text{vib}}=\Gamma_q$」正是本性质取 $\Gamma_1=\Gamma_{\text{vib}}$、$\Gamma_2=\Gamma_q$（[[07-红外和拉曼活性的判据#判据来源]]）。

该性质只对<mark style="background: #FFF3A3A6;">不可约表示</mark>成立：可约表示之间相乘也可含全对称表示而不相等。

## 对称直积与反对称直积

### 泛频

泛频：指一个振动模式被激发**超过一个量子**的跃迁喵。基频 $\nu_i$ 是模式 $\nu_i$ 吸收一个量子（0→1）；第一泛频 $2\nu_i$ 是同一模式吸收两个量子（0→2），频率约为基频的两倍，故称泛频（还有 $3\nu_i$ 等）。对称性为 $\Gamma_1\otimes\Gamma_1$（$\Gamma_1$ 简并时取对称直积）

同一简并模的两个量子的泛频 $2\nu$ ，波函数须对两个量子的交换对称。

组合频$\nu_{1}+\nu_{2}$：两个不同模式各吸收一个量子，对称性为 $\Gamma_1\otimes\Gamma_2$

### 特征标

设交换算子P，则$p^2=1$，本征值为$\pm 1$ 。直积空间是对称部分p=1的子空间和不对称部分p=-1的子空间两部分。因此只取直积的对称部分。

P与所有群操作对易，这两部分各自对群操作封闭，所以各是一个子表示，即$\Gamma\otimes\Gamma$ 分解为对称直积 $[\Gamma\otimes\Gamma]^+$ 与反对称直积 $[\Gamma\otimes\Gamma]^-$：
$$
\chi^+(R)=\frac{1}{2}\left[\chi(R)^2+\chi(R^2)\right],\qquad
\chi^-(R)=\frac{1}{2}\left[\chi(R)^2-\chi(R^2)\right]
$$

$\chi^+$、$\chi^-$ ：对称、反对称直积在 $R$ 上的特征标，量纲一
$\chi(R^2)$ ：先判 $R^2$ 所属的类，再取该类的特征标

### 推导

完整直积 $\Gamma\otimes\Gamma$ 的特征标
$$
\chi(R)^2=\chi(R)\chi(R)
$$ 
<mark style="background: #FFF3A3A6;">对称直积特征标：</mark>
对称部分是交换算子 $P$ 的本征值 $+1$ 的子空间，投影算子是 $\frac{1+P}{2}$ 。
反对称部分对应 $\frac{1-P}{2}$ 。

$P$ 与群作用对易，所以「对称部分的迹」
$$
\begin{aligned}
\mathrm{tr}\big(\tfrac{1+P}{2}(R\otimes R)\big)&=\frac{1}{2}\big[\mathrm{tr}(R\otimes R)+\mathrm{tr}(P(R\otimes R))\big]\\ \\
&=\frac{1}{2}[\chi(R)^2+\chi(R^2)]
\end{aligned}
$$

$P$ 把两个因子对调，在积基 $f_if_j$ 下它把 $D_{ij}$ 和 $D_{ji}$ 配成对，全部求和得 $\mathrm{tr}(P(R\otimes R))=\sum_{ij}D_{ij}D_{ji}=\mathrm{tr}(D(R)\cdot D(R))$ 。
$D$ 是表示，满足 $D(R)\cdot D(R)=D(R^2)$（连续操作两次），所以第二项 $=\mathrm{tr}(D(R^2))=\chi(R^2)$ 喵。

<mark style="background: #FFF3A3A6;">反对称部分</mark>把 $P$ 换成 $-P$，即 $\chi^-(R)=\frac12[\chi(R)^2-\chi(R^2)]$ 。


### 维数

$n^2$个积函数中，对称部分是 𝑖 ≤𝑗 的对角+上三角共 $\frac{n(n+1)}{2}$ 个，反对称是 𝑖 <𝑗 共 $\frac{n(n-1)}{2}$个，
$$
\dim[\Gamma\otimes\Gamma]^+=\frac{n(n+1)}{2},\qquad
\dim[\Gamma\otimes\Gamma]^-=\frac{n(n-1)}{2}
$$

$n$ ：$\Gamma$ 的维数

$C_{3v}$ 的 $E$ 表示（$\chi=(2,-1,0)$，列序 $E$、$2C_3$、$3\sigma_v$）：$[E\otimes E]^+=A_1+E$、$[E\otimes E]^-=A_2$、$E\otimes E=A_1+A_2+E$。

一维表示中 $\chi(R^2)=\chi(R)^2$、$\chi^-=0$。
自直积即全对称表示，非简并模的泛频$2n\nu$恒全对称。

## 应用

### 07 判据的推导链

跃迁矩积分非零 $\iff$ 被积函数含全对称分量，即 $\Gamma_f\otimes\Gamma_q\otimes\Gamma_i\supset\Gamma_{\text{全对称}}$；基态 $\Gamma_i=\Gamma_{\text{全对称}}$、基频终态 $\Gamma_f=\Gamma_{\text{vib}}$，用 $A_1\otimes\Gamma=\Gamma$ 化简为 $\Gamma_{\text{vib}}\otimes\Gamma_q\supset\Gamma_{\text{全对称}}$；再由核心性质得 $\Gamma_{\text{vib}}=\Gamma_q$。

### 泛频与组合频

泛频 $2\nu_1$ 的终态对称性为 $\Gamma_1\otimes\Gamma_1$（$\Gamma_1$ 简并时取对称直积）；组合频 $\nu_1+\nu_2$ 为 $\Gamma_1\otimes\Gamma_2$。得 $\Gamma_f$ 后须重新套判据，基频判据不直接适用（[[07-红外和拉曼活性的判据]]）。
