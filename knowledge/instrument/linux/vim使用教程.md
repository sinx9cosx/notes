# 模式

`vim`打开，默认命令模式。

![[vim.png]]

打开/创建文件：

``` linux
vi hello.txt
```

默认进入命令模式

# 命令

## 尾行模式

`:q`退出

`:wq`保存并退出

`:set number`显示行号 `:set nonumber`关闭行号的显示

`:set ic`设置全局查找忽略大小写

替换`:n1,n2s(替换范围，从第n1行到第n2行)/old/new/g`

`:q!`强制推出

## 插入模式

命令模式下，通过i/I，a/A，o/O进入插入模式

i：光标前面插入 I：行首插入

a：光标后面插入 A：行尾插入

o：当前行的下一行 O：当前行的上一行

## 命令模式

`^`行首

`$`行尾

`yy`复制 `2yy`复制两行内容

`p`粘贴 `3p`粘贴三次

`dd`删除

`ctrl+f`向前翻页

`ctrl+b`向后翻页

`ctrl+u`向上翻半页

`ctrl+d`向下翻半页

`G`跳转文件最后一行

`gg`跳转文件第一行

`100G`跳转文件第100行

`/+要查找的内容`向下查找

`/+要查找的内容`向上查找 `n`下一个 `N`方向相反

查找的时候区分大小写 `/+查找内容+\c`不区分大小写

`u`撤销

# 重要

输入完记得按`Esc`退出到命令模式！
