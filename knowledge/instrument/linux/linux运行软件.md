# 安装软件


**更新**
   
   ```bash
   sudo apt update
   ```
   

**安装**

   ```bash
   sudo apt install 软件名字
   ```


# 运行软件 


- **场景一：运行已安装的系统软件（最常见）**
直接在终端输入**软件包名**，按回车。比如运行火狐浏览器或VLC播放器：
`firefox`
`vlc`
（原理是系统会在 `$PATH` 环境变量指定的文件夹里自动找这个命令）

- **场景二：运行当前目录下的软件（你刚下载或编译的）**
Linux默认**不**查当前文件夹，必须加 `./` 前缀。比如你下载了一个叫 `app` 的文件：
`./app`
如果提示“权限不够”，先给它执行权限再跑：
`chmod +x ./app` 然后 `./app`

- **场景三：运行脚本（Python/Shell等）**
用对应的解释器命令加上文件路径：
`python3 /home/你/script.py`
`bash /home/你/test.sh`

**最实用的万能法则**：如果你是用 `apt` 或 `yum` 装的，基本直接输名字就行；如果是网上下载的 `.run` 或二进制文件，基本就是 `./文件名`。
