哈哈，你这个问题问得非常关键，因为这里正好是**“一个计算任务产生很多结果，但report到底放什么”**的分水岭。

你现在实际上有三个不同阶段：

1. **S₀优化 + freq** → 得到基态结构
    
2. **S₁优化** → 得到激发态最低点结构
    
3. **S₁结构上的单点TD计算** → 得到荧光发射数据
    

这三个阶段整理的数据是不一样的。

---

# ① S₁优化（TD-DFT Opt）需要整理什么？

你的输入大概是：

```text
TD(NStates=10,Root=1) Opt
```

这一部分的目标：

> 找到 S₁ 势能面的最低点。

所以report重点不是光谱，而是证明：

“我成功得到了一个S₁优化结构。”

---

## （1）优化是否收敛 ✅

这个必须写。

找：

```
Optimization completed.
```

或者：

```
Stationary point found.
```

如果有：

```
Optimization completed
```

说明优化完成。

另外可以看：

```
Maximum Force
RMS Force
Maximum Displacement
RMS Displacement
```

它们是否满足阈值。

Gaussian最后一般会给：

```
Item               Value     Threshold
Maximum Force      xxx       0.000450
RMS Force          xxx       0.000300
```

如果满足，就是收敛。

report里不用全部抄，可以写：

> The S₁ geometry optimization converged successfully.

---

## （2）S₁能量

找：

```
Excited State 1:
```

附近。

比如：

```
Excited State 1: Singlet-B3LYP
3.50 eV
354 nm
```

记录：

- S₁ excitation energy
    
- wavelength
    
- oscillator strength
    

不过注意：

**这个不是最终荧光波长！**

这是在S₁优化过程中每一步计算的激发能，最终一步可以参考，但真正的发射还看第三步。

---

## （3）虚频要不要检查？

这里是一个很好的问题。

### 严格来说：

**激发态优化后的结构也应该检查频率。**

因为你想证明：

它是：

[  
S_1 \text{ minimum}  
]

而不是：

[  
S_1 \text{ transition state}  
]

所以理论上应该：

```
TD(NStates=10,Root=1) Freq
```

检查有没有虚频。

---

但是！

你现在这个阶段，老师让你“先把S₁到S₀算出来”，我觉得她大概率不会要求你马上做S₁ freq。

因为：

- S₁ freq计算更贵；
    
- 初学阶段先跑通流程更重要。
    

所以你的report可以写：

> S₁ geometry optimization was completed. Frequency verification of the excited-state minimum will be performed in further calculations.

这样比较稳。

---

# ② 为什么S₁优化后还是有10个excited states？

这个也很正常！

因为你的关键词：

```
NStates=10
```

告诉Gaussian：

“每次计算的时候，请给我前10个激发态。”

包括优化过程中。

所以每一步都会输出：

```
Excited State 1
Excited State 2
...
Excited State 10
```

但是你的优化目标：

只有：

```
Root=1
```

也就是：

S₁。

所以report：

主要放：

✅ Excited State 1

不用放S2-S10。

---

# ③ 第二次删掉Opt和Freq重新计算是什么？

这个就是你老师真正想要的：

**Emission calculation**

你现在：

S₁优化得到结构：

```
S1 minimum geometry
```

然后：

重新计算：

```
TD(NStates=10,Root=1)
```

没有：

```
Opt
Freq
```

因为：

结构已经好了。

现在只是问：

> 在这个S₁结构上，S₁和S₀之间能量差是多少？

---

这个计算report应该放：

## （1）S₁→S₀发射波长 ⭐⭐⭐

最重要。

找：

```
Excited State 1:
```

例如：

```
Excited State 1: Singlet-B3LYP
2.85 eV
435 nm
f=0.20
```

整理：

|Transition|Energy|Wavelength|Oscillator strength|
|---|---|---|---|
|S₁→S₀|2.85 eV|435 nm|0.20|

---

## （2）不用放SCF能量？

可以放，但不是重点。

因为这个计算不是为了优化结构。

核心结果：

不是：

```
SCF Done
```

而是：

```
Excited State 1
```

---

# 所以你的report可以这样整理：

## S₀ optimization

放：

- E(S₀)
    
- 无虚频
    
- 收敛
    

---

## S₁ optimization

放：

- 使用 TD-DFT Root=1 Opt
    
- Optimization completed
    
- S₁ excitation energy（最后一步）
    
- （如果做了freq）虚频情况
    

---

## Emission calculation

放：

- S₁→S₀ transition energy
    
- emission wavelength
    
- oscillator strength
    

---

你现在其实已经遇到了计算化学里非常典型的问题：

> 一个log文件里面有无数数据，哪些才是物理上有意义的数据？

判断标准就是：

**这个计算的目的是什么？**

- Opt → 看结构和能量
    
- Freq → 看是不是最低点
    
- TD单点 → 看激发能和光谱
    

所以不要被10个激发态、几十个SCF、几百行频率吓到 😂

对于你现在这个苯的report，核心数据可能最后也就一张表：

|计算|结果|
|---|---|
|S₀优化|E(S₀)，无虚频|
|S₁优化|收敛，E(S₁)|
|S₁→S₀|λ_em，f|

这已经是一个完整的小型激发态计算流程了。你现在问的这些细节，已经是在做真正的计算整理工作了。
