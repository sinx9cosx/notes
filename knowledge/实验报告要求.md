# 实验报告要求：有机分子沸点预测（标准机器学习流程实践）

> 本实验以"用分子描述符预测有机分子沸点"为案例，要求完整走通一个**标准的机器学习项目生命周期**，并把每一步的思考、操作、结果写进实验报告。报告应体现 **"数据 → 特征 → 建模 → 验证 → 诊断 → 迭代"** 的闭环，而非只堆模型。

---

## 一、总体要求

| 项目 | 要求 |
|---|---|
| 报告结构 | 必须按下面的 **9 个步骤** 分节，顺序不得打乱 |
| 内容形式 | 每节须同时有 **文字说明 + 关键结果（表/图）**，禁止只贴代码或只放截图 |
| 图表规范 | 所有图必须带标题、坐标轴标签、图例；中文图表须确保字体正常（不得出现方块/乱码） |
| 数据范围 | 有机分子（含碳）沸点数据集；报告须说明数据来源、样本量、字段含义 |
| 复现性 | 关键数字（R²、MAE、RMSE 等）须可复现，并注明随机种子、划分方式、CV 折数 |
| 篇幅 | 正文建议 3000–5000 字 + 不少于 8 张图/表 |

## 二、分步骤要求

### 步骤 1 · 问题定义（必须写）
- 明确任务是**回归**还是分类，预测目标是什么（沸点，单位 K / °C）。
- 给出**评估指标**及选择理由（至少包含 R²、MAE、RMSE）。
- 说明应用场景与"可接受误差"的初步判断。

### 步骤 2 · 数据获取与整理（必须写 + 交 1 张表）
- 说明原始数据来源、表结构（如 23 张表 → 抽取有机表）。
- 给出**数据清洗规则**：如何区分有机/无机、缺失值如何处理、单位是否统一。
- 提交一张整理后的数据样例表（含 ID、分子式、名称、CAS、沸点）。
- **禁止**把无机物/元素混入"有机分子"训练集而不说明。

### 步骤 3 · 特征工程（必须写 + 交特征清单）
- 说明分子表示方式（本案例为 SMILES）与补全来源（如 PubChem，CAS 优先、名称兜底）。
- 列出所使用的描述符（建议 ≥20 个，须覆盖：分子量/体积、氢键、拓扑、形状/支化、环系等维度）。
- **硬性要求**：必须包含氢键相关描述符（供体、受体、总氢键数 / Lipinski 口径），并说明为何需要它。
- 标注每个分子的 SMILES 来源（cas / name / 缺失），便于后续追溯。

### 步骤 4 · 探索性分析 EDA（必须写 + 交 ≥1 张图）
- 画**描述符间相关热力图**，识别共线簇（如 MolWt–LabuteASA、TPSA–氢键数）。
- 指出哪些描述符彼此近似正交、哪些高度冗余。
- **硬性要求**：必须基于相关性给出"建模时是否去冗余 / 降维"的初步方案，不得跳过。

### 步骤 5 · 模型选择（必须写 + 交对比表）
- 至少对比 **4 类方法**：手工精选正交集（如 Ridge）、PCA+线性、PLS（监督降维）、树模型（如 XGBoost）。
- 说明为何要做**同一测试集 + 同一随机种子**的公平对比。
- 提交一张模型对比表（R²、MAE、RMSE、CV R²）。

### 步骤 6 · 模型评估（必须写 + 交 ≥2 张图）
- 除汇总指标外，必须画 **预测值 vs 实际值散点图**（含 y=x 参考线）与 **残差分布图**。
- 报告**偏倚（残差均值）**，说明模型是否系统性高估/低估。
- 解释误差分布形态（是否长尾、是否在高沸点区发散）。

### 步骤 7 · 过拟合诊断（必须写 + 交 ≥1 张图）
- 使用 **三件套**：① Train/Test gap；② 交叉验证（CV≈Test？）；③ 学习曲线（随数据量是否收敛）。
- **⚠️ 硬性要求（本项目踩坑点）**：交叉验证必须 `shuffle`（如 `KFold(shuffle=True)`）。若数据本身**按 ID/类别有序**，不 shuffle 会导致各折分布错配，CV 分数会崩到接近 0——这是假阴性，不是模型不行。报告须证明自己已处理此问题。
- 区分"模型容量大（train 高但 test 稳）"与"真过拟合（test 明显回落）"。

### 步骤 8 · 误差分析（必须写 + 交 1 张图 + 1 张表）
- 找出**大误差样本**（如 |残差| > 100 K），不要只看平均误差。
- **关键方法**：检验误差是否**跨模型稳定出现**——稳定出错多为"结构/物理共性难点或数据问题"，单模型出错多为"方法局限"。
- 必须区分两类原因：
  - **模型盲区**：极小分子（如 CO）、强氢键多官能团（糖、二醇、磺酸）落在线性模型能力边界；
  - **数据质量问题**：如某些"沸点"实为**分解温度/熔点**（常压下不沸腾）、CAS 字段被错填为日期等。
- 提交大误差样本清单（含分子式、沸点、各模型残差、可能原因）。

### 步骤 9 · 迭代与数据补全（必须写）
- 说明是否通过补数据 / 换特征 / 调参进行了**至少一轮迭代**。
- 对比迭代前后指标变化，论证"数据量是天花板还是过拟合是瓶颈"。
- 给出尚未解决的限制与后续改进方向。

## 四、常见错误清单（报告中出现即扣分）

1. **交叉验证忘了 shuffle**，且数据有序 → CV 崩塌却误判"模型差"。
2. 直接用**高度共线**的描述符喂线性模型却不处理（应去冗余 / 用 PLS）。
3. **遗漏氢键描述符**，却声称已覆盖物性维度。
4. 只报平均指标，**不分析大误差样本**，掩盖了数据质量问题（分解温度当沸点等）。
5. 把**无机物/盐类**混入有机分子集而不说明。
6. 图无标题/坐标轴/图例，或中文显示为方块。
7. 随机种子、划分比例、CV 折数缺失，结果不可复现。
